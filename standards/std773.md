# #std773 Использование признака ОбменДанными.Загрузка в обработчиках событий объекта

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Основное правило

Все действия в обработчиках событий `ПередЗаписью`, `ПриЗаписи`, `ПередУдалением` должны выполняться **после проверки** на `ОбменДанными.Загрузка`:

```1c
Процедура ПередЗаписью(Отказ)

    Если ОбменДанными.Загрузка Тогда
        Возврат;
    КонецЕсли;

    // Код обработчика
    // ...

КонецПроцедуры
```

---

## 2. Причина проверки

Бизнес-логика объекта **не должна** выполняться при записи через механизм обмена данными, поскольку:
- Она уже была выполнена в том узле, где объект был создан
- Данные должны загружаться **«как есть»**, без искажений, проверок или дополнительных действий

---

## 3. Общий принцип

Механизмы, не рассчитанные на особенности конкретных конфигураций, должны иметь возможность загрузить данные при установленном флаге так, **как будто текста обработчика нет вообще**:

```1c
Объект.ОбменДанными.Загрузка = Истина;
Объект.Записать();
```

**Пример:** Загрузка всей базы из XML «как есть» — достаточно установить `ОбменДанными.Загрузка = Истина`, и данные загрузятся без искажений.

---

## 4. Исключение: регистрация к выгрузке

Механизм обмена данными, который в ходе загрузки **регистрирует данные к выгрузке** на других узлах плана обмена — исключение из правила.

### 4.1. Отключение регистрации (БСП)

При использовании подсистемы «Обмен данными» БСП для отключения регистрации:

```1c
Объект.ОбменДанными.Загрузка = Истина;
Объект.ДополнительныеСвойства.Вставить("ОтключитьМеханизмРегистрацииОбъектов");
Объект.Записать();
```

### 4.2. Другие исключения

Причина исключения из правила **должна быть описана** в комментарии к выполняемым действиям.

---

## 5. Подписки на события

Требования **также распространяются** на обработчики подписок на события `ПередЗаписью`, `ПриЗаписи`, `ПередУдалением`.

---

## 6. Ответственность за целостность данных

⚠️ Вызывающая сторона, устанавливая `ОбменДанными.Загрузка = Истина`, **берёт на себя ответственность** за целостность данных объекта.

| Сценарий | Как обеспечивается целостность |
|----------|-------------------------------|
| РИБ | Корректное состояние объекта в исходном узле |
| Правила конвертации | Вызывающая сторона дозаполняет объект |
| EnterpriseData | Экспортные процедуры объекта для дозаполнения |

**Рекомендация:** Действия по дозаполнению объекта размещать в **экспортных процедурах** самого объекта.
