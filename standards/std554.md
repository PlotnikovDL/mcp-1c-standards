# #std554 Переопределение общих модулей в условиях иерархии библиотек

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

> *Методическая рекомендация (полезный совет)*

---

При разработке нескольких библиотек, стоящих на поддержке друг у друга, следует минимизировать трудоёмкость по обновлению кода [переопределяемых общих модулей](#std553) в каждой из библиотек.

---

## 1. Переопределяемый модуль в базовой библиотеке

В библиотеке **нижнего уровня иерархии** (самой базовой) объявляется переопределяемый модуль по [правилам создания общих модулей](#std469).

**Пример:** `БазоваяБиблиотекаПереопределяемый`

---

## 2. Доопределение в библиотеках верхнего уровня

В библиотеках более высокого уровня реализация процедур и функций переопределяемого модуля базовой библиотеки может быть при необходимости доопределена.

**Важно:** в переопределяемом модуле размещается **не сама реализация** (её код), а **только один вызов**.

### Пример в «Базовой библиотеке»

Модуль **БазоваяБиблиотекаПереопределяемый** — реализация фактически в модуле **МодульБазовойБиблиотеки**:

```1c
Процедура НастроитьИнтерфейс(Знач ПараметрыРаботы) Экспорт

    // Начало: Базовая библиотека
    МодульБазовойБиблиотеки.НастроитьИнтерфейс(ПараметрыРаботы);
    // Конец: Базовая библиотека

КонецПроцедуры
```

### Пример в «Библиотеке второго уровня»

Тот же модуль **БазоваяБиблиотекаПереопределяемый**:

```1c
Процедура НастроитьИнтерфейс(Знач ПараметрыРаботы) Экспорт

    // Начало: Базовая библиотека
    МодульБазовойБиблиотеки.НастроитьИнтерфейс(ПараметрыРаботы);
    // Конец: Базовая библиотека

    // Начало: Библиотека второго уровня
    МодульБиблиотекиВторогоУровня.НастроитьИнтерфейс(ПараметрыРаботы);
    // Конец: Библиотека второго уровня

КонецПроцедуры
```

---

## 3. Итоговый вид в конфигурации-потребителе

В конечной конфигурации-потребителе реализация переопределяемого модуля имеет вид:

```1c
Процедура НастроитьИнтерфейс(Знач ПараметрыРаботы) Экспорт

    // Начало: Базовая библиотека
    МодульБазовойБиблиотеки.НастроитьИнтерфейс(ПараметрыРаботы);
    // Конец: Базовая библиотека

    // Начало: Библиотека второго уровня
    МодульБиблиотекиВторогоУровня.НастроитьИнтерфейс(ПараметрыРаботы);
    // Конец: Библиотека второго уровня

    // а теперь выполняем настройки так, как это надо нашей конфигурации
    // ...

КонецПроцедуры
```

---

## Преимущества подхода

| Преимущество | Описание |
|--------------|----------|
| Сокрытие деталей реализации | Библиотеки верхнего уровня и конфигурации-потребители не видят детали реализации библиотек нижнего уровня |
| Минимизация риска ошибок | Снижается вероятность ошибки при обновлении кода переопределяемого общего модуля |
| Гибкость | Остаётся возможность выбора: воспользоваться реализацией или отказаться от неё |

---

## Сводка

| Уровень иерархии | Что размещается в переопределяемом модуле |
|------------------|-------------------------------------------|
| Базовая библиотека | Объявление переопределяемого модуля |
| Библиотека верхнего уровня | Вызов модуля базовой библиотеки + вызов своего модуля |
| Конфигурация-потребитель | Все вызовы библиотек + собственная реализация |
