# #std640 Параметры процедур и функций

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Именование параметров

Имена параметров должны соответствовать общим правилам образования имен переменных (#std454) и образовываться от **терминов предметной области**.

---

## 2. Не использовать вместо параметров другие средства

❌ Не использовать вместо параметров:
- Переменные модулей
- Реквизиты формы
- Другие средства конфигурирования

---

## 3. Порядок параметров

Параметры должны идти в **логической последовательности** — от общего к частному.

**❌ Неправильно:**

```1c
Процедура ПересчитатьСуммуДокумента(ИмяПоляСумма, ДокументОбъект, СуммаВключаетНДС = Истина)

Процедура ПоменятьЦветПоляФормы(Цвет, ИмяПоля, Форма)
```

**✅ Правильно** — сначала основные параметры:

```1c
Процедура ПересчитатьСуммуДокумента(ДокументОбъект, ИмяПоляСумма, СуммаВключаетНДС = Истина)

Процедура ПоменятьЦветПоляФормы(Форма, ИмяПоля, Цвет)
```

---

## 4. Необязательные параметры — в конце

Параметры со значениями по умолчанию должны располагаться **после** обязательных параметров.

```1c
Функция КурсВалютыНаДату(Валюта, Дата = Неопределено) Экспорт
```

---

## 5. Количество параметров

| Рекомендация | Значение |
|--------------|----------|
| Максимум параметров | **7** |
| Максимум необязательных | **3** |

При большом количестве параметров:
- Группировать однотипные в **Структуру** (`ДанныеЗаполнения`, `ПараметрыПроведения`, `ДанныеФайла`)
- Пересмотреть логику — разделить на несколько простых функций

### Пример: много параметров

**❌ Неправильно:**

```1c
Функция ДобавитьПолеФормы(ИмяПоля, Заголовок = Неопределено, ОбработчикПриИзменении = "",
      ОбработчикНачалоВыбора = "", ШиринаПоля, ЦветФона = Неопределено,
      ЦветФонаЗаголовка = Неопределено, Родитель = Неопределено,
      КартинкаШапки = Неопределено, ПутьКДанным = Неопределено,
      ТолькоПросмотрПоля = Ложь, СвязиПараметровВыбора = Неопределено)

// вызывающий код
НовоеПоле = ДобавитьПолеФормы("СтараяЦена", НСтр("ru='Цена'"),,, 12, ЦветФона, ЦветЗаголовка, НоваяГруппа,,,Истина);
```

**✅ Правильно** — один ключевой параметр, остальное через свойства:

```1c
Функция НовоеПолеФормы(ИмяПоля)
…
КонецФункции

// вызывающий код
НовоеПоле = НовоеПолеФормы("СтараяЦена");
НовоеПоле.Заголовок  = НСтр("ru='Цена'");
НовоеПоле.ЦветФона   = ЦветФона;
НовоеПоле.ЦветТекста = WebЦвета.Серый;
```

### Пример: группировка в структуру

**❌ Неправильно:**

```1c
Процедура СоздатьЭлементНоменклатуры(Наименование, ТоварУслуга, ЕдиницаИзмерения, ВесНетто, ПроверятьУникальность = Истина)
```

**✅ Правильно:**

```1c
Процедура СоздатьЭлементНоменклатуры(ЗначенияРеквизитов, ПроверятьУникальность = Истина)
```

## 6. Громоздкие конструкции при вызове

### 6.1. Вложенные вызовы функций

❌ Не рекомендуется вкладывать вызовы функций в параметры.

**❌ Неправильно:**

```1c
СтруктураВложений.Вставить(ПрисоединенныйФайл.Наименование,
 Новый Картинка(ПолучитьИзВременногоХранилища(ПрисоединенныеФайлы.ПолучитьДанныеФайла(ПрисоединенныйФайл.Ссылка).СсылкаНаДвоичныеДанныеФайла)));
```

**✅ Правильно** — разбить на отдельные операторы:

```1c
АдресФайлаИзображения = ПрисоединенныеФайлы.ПолучитьДанныеФайла(ПрисоединенныйФайл.Ссылка).СсылкаНаДвоичныеДанныеФайла;
ДанныеИзображения = Новый Картинка(ПолучитьИзВременногоХранилища(АдресФайлаИзображения));
СтруктураВложений.Вставить(ПрисоединенныйФайл.Наименование, ДанныеИзображения);
```

**Исключение:** компактный и легко читаемый код допустим:

```1c
Предупреждение(НСтр("ru='Для выполнения операции необходимо установить расширение работы с файлами.'"));

ПеречитатьСуммуПоКурсу(Сумма, КурсВалютыНаДату(Валюта));
```

### 6.2. Вложенный конструктор структуры

❌ Не рекомендуется использовать `Новый Структура(...)` в параметрах вызова.

**Допустимо** только при небольшом количестве свойств (не более 3).

**❌ Неправильно:**

```1c
ЗаполнитьЦены(Объект.Товары, , Новый Структура("Дата, Валюта, Соглашение, ПоляЗаполнения",
   Объект.Дата, Объект.Валюта, Объект.Соглашение, "Цена, СтавкаНДС, ВидЦены, СрокПоставки"),
  Новый Структура("ПересчитатьСумму, ПересчитатьСуммуСНДС, ПересчитатьСуммуНДС...",
   "КоличествоУпаковок", СтруктураПересчетаСуммы, ...));
```

**✅ Правильно:**

```1c
ПараметрыЗаполнения = Новый Структура;
ПараметрыЗаполнения.Вставить("Дата", Объект.Дата);
ПараметрыЗаполнения.Вставить("Валюта", Объект.Валюта);
ПараметрыЗаполнения.Вставить("Соглашение", Объект.Соглашение);
ПараметрыЗаполнения.Вставить("ПоляЗаполнения", "Цена, СтавкаНДС, ВидЦены, СрокПоставки");

ДействияСИзмененнымиСтроками = Новый Структура;
ДействияСИзмененнымиСтроками.Вставить("ПересчитатьСумму", "КоличествоУпаковок");
ДействияСИзмененнымиСтроками.Вставить("ПересчитатьСуммуСНДС", ПараметрыПересчетыСуммы);
// ...

ЗаполнитьЦены(Объект.Товары, ПараметрыЗаполнения, ДействияСИзмененнымиСтроками);
```

### 6.3. Пробелы при вызове

❌ **Не допускаются пробелы:**
- Перед открывающей скобкой
- После открывающей скобки
- Перед закрывающей скобкой
- Перед запятыми

**❌ Неправильно:**

```1c
НовоеПоле = НовоеПолеФормы ( ИмяПоля , ТипПоля );
```

**✅ Правильно:**

```1c
НовоеПоле = НовоеПолеФормы(ИмяПоля, ТипПоля);
```

---

## 7. Не пропускать обязательные параметры

❌ Пропуск обязательного параметра передаёт `Неопределено`, на которое функция может быть не рассчитана.

Если `Неопределено` допустимо:
- Передавать явно
- Или сделать параметр необязательным со значением по умолчанию `Неопределено`

**Для процедуры:**

```1c
Процедура ПоменятьЦветПоляФормы(Форма, ИмяПоля, Цвет)
```

**❌ Неправильно:**

```1c
ПоменятьЦветПоляФормы(,"РезультатПроверки", ЦветаСтиля.ПоясняющийОшибкуТекст); // пропущен Форма
ПоменятьЦветПоляФормы(,,); // пропущены все обязательные параметры
```

**✅ Правильно:**

```1c
ПоменятьЦветПоляФормы(ЭтотОбъект, "РезультатПроверки", Цвет);
```

## Сводка

| Правило | Требование |
|---------|------------|
| Именование | Термины предметной области |
| Порядок | От общего к частному |
| Необязательные | После обязательных |
| Количество | Максимум 7 (необязательных — 3) |
| Много параметров | Группировать в Структуру |
| Вложенные вызовы | ❌ Избегать |
| Вложенные структуры | ❌ Избегать (допустимо ≤3 свойств) |
| Пробелы при вызове | ❌ Запрещены |
| Пропуск параметров | ❌ Не пропускать обязательные |
