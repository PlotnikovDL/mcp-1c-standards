# #std726 Особенности использования в запросах оператора ПОДОБНО

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Формирование шаблона

Оператор `ПОДОБНО` используйте **только**:
- С константным строковым литералом
- С параметром запроса

**Не формируйте** шаблон вычислениями или конкатенацией.

✅ **Правильно:**
```1c
Реквизит ПОДОБНО "123%"
Реквизит ПОДОБНО &Шаблон
```

❌ **Неправильно:**
```1c
Реквизит ПОДОБНО "123" + "%"
Реквизит ПОДОБНО &Шаблон + "%"
Реквизит ПОДОБНО Таблица.Шаблон
```

---

## 2. Переносимые шаблоны

Используйте только шаблоны, работающие на **всех СУБД**:

| Символ | Значение |
|--------|----------|
| `%` | Любое количество произвольных символов |
| `_` | Один произвольный символ |

### 2.1. Недопустимо (не работает на IBM DB2)

| Символ | Значение |
|--------|----------|
| `[...]` | Любой символ из перечисленных |
| `[^...]` | Любой символ кроме перечисленных |

### 2.2. Ограничения

- Максимальная длина шаблона: **1024 символа** (ограничение MS SQL 2005)

---

## 3. Экранирование спецсимволов

**Обязательно** экранируйте спецсимволы (`_ % [ ] ^`), чтобы они искались как текст.

⚠️ Без экранирования ввод пользователем `[]` вызовет ошибку PostgreSQL:
```
ERROR: invalid regular expression: invalid character range
```

### 3.1. Правила экранирования

1. Выберите символ экранирования (например `~`)
2. Поставьте его перед спецсимволами: `~%`, `~_`, `~[`, `~]`, `~^`
3. Для экранирования самого символа — задвойте: `~~`
4. Добавьте `СПЕЦСИМВОЛ "~"` в запрос

### 3.2. Пример поиска "100%"

```1c
"100~%" СПЕЦСИМВОЛ "~"
```

### 3.3. Использование с БСП

⚠️ `Запрос.УстановитьПараметр` **не экранирует** спецсимволы!

✅ **Правильно (с БСП):**

```1c
ВЫБРАТЬ
    Номенклатура.Ссылка КАК Ссылка
ИЗ
    Справочник.Номенклатура КАК Номенклатура
ГДЕ
    Номенклатура.Наименование ПОДОБНО &Шаблон СПЕЦСИМВОЛ "~"
```

```1c
Запрос.УстановитьПараметр("Шаблон",
    "%" + ОбщегоНазначения.СформироватьСтрокуДляПоискаВЗапросе(ИскомыйТекст) + "%");
```

### 3.4. Реализация без БСП

```1c
Функция СформироватьСтрокуДляПоискаВЗапросе(Знач СтрокаПоиска) Экспорт

    Результат = СтрокаПоиска;
    Результат = СтрЗаменить(Результат, "~", "~~");
    Результат = СтрЗаменить(Результат, "%", "~%");
    Результат = СтрЗаменить(Результат, "_", "~_");
    Результат = СтрЗаменить(Результат, "[", "~[");
    Результат = СтрЗаменить(Результат, "]", "~]");
    Результат = СтрЗаменить(Результат, "^", "~^");

    Возврат Результат;

КонецФункции
```

---

## 4. Регистр

Сравнение выполняется **без учёта регистра** символов.

---

## 5. Сводка

| Правило | Описание |
|---------|----------|
| Источник шаблона | Литерал или параметр, не конкатенация |
| Допустимые символы | `%` и `_` |
| Недопустимые | `[...]`, `[^...]` (IBM DB2) |
| Длина шаблона | ≤ 1024 символов |
| Пользовательский ввод | **Экранировать** через `СПЕЦСИМВОЛ` |
| БСП | `ОбщегоНазначения.СформироватьСтрокуДляПоискаВЗапросе` |
