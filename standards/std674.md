# #std674 Заголовок отчета

> Область применения: управляемое приложение.
>
> Раздел ИТС: Проектирование интерфейсов для 8.2 / Отчеты
>
> Источник: https://its.1c.ru/db/v8std/content/674/hdoc
>
> Проверено по источнику: 2026-10-07

<a id="1"></a>1\. Заголовок отчета должен четко отражать цель анализа и содержание отчета. Заголовок должен быть узнаваемым и понятным.

<a id="2"></a>2\. Если используются варианты отчета, то заголовок каждого варианта всегда должен быть заполнен и соответствовать наименованию варианта отчета. Это необходимо для быстрого поиска отчета в системе по заголовку напечатанного отчета.<br>

<span style="color: #2e8b57">Правильно </span>– в таблице отчета есть заголовок, который соответствует наименованию варианта отчета:

![Иллюстрация 1 к стандарту #std674](assets/std674/01.png)

<span style="color: #b22222">Неправильно</span> – в таблице отчета нет заголовка:

![Иллюстрация 2 к стандарту #std674](assets/std674/02.png)

<a id="3"></a>3\. Если используются однотипные варианты отчета с различными группировками, то уточнение по группировке следует писать во множественном числе без использования разделителей (тире, скобок и т.п.), таким образом чтобы все слова названия были согласованы.

<span style="color: #4682b4">*Например:*</span>

<table><tbody><tr><td><span style="color: #2e8b57">Правильно</span></td><td><span style="color: #b22222">Неправильно</span></td></tr>

<tr><td>Анализ расчетов с клиентами по договорам</td><td>Анализ расчетов с клиентами (по договорам)</td></tr></tbody></table>

В исключительных случаях можно использовать разделители или иные специальные знаки, например, для стандартизованной отчетности.

4\. Запрещается использование названия "Основной" для варианта отчета, т.к. для новичков не понятно, что кроется за этим определением. Лучше давать осмысленные названия.<br>

<span style="color: #4682b4">*Например, для отчета "Анализ причин проигрыша сделок" варианты могут называться:*</span>

- *Анализ причин проигрыша сделок по партнерам*

- *Анализ причин проигрыша сделок по ответственным*

- Анализ причин проигрыша сделок по причинам<br>

5\. Следует избегать слова "отчет" в синониме и заголовках отчетов.

6\. Если в отчете несколько элементов (например, гистограмма и список), то для каждого рекомендуется устанавливать заголовок. Общий заголовок отчета в этом случае не обязателен. <br>
