# #std705 Отнесение объектов библиотек к подсистемам

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Корневая подсистема библиотеки

Все объекты библиотеки должны быть отнесены к **одной корневой подсистеме**, которая **не содержит командного интерфейса**.

**Пример:** для объектов БСП — подсистема **СтандартныеПодсистемы**.

---

## 2. Дополнительные корневые подсистемы

Допустимо наличие **нескольких корневых подсистем** (помимо упомянутой в п.1), содержащих командный интерфейс.

---

## Сводка

| Тип подсистемы | Назначение | Командный интерфейс |
|----------------|------------|---------------------|
| Корневая подсистема библиотеки | Содержит все объекты библиотеки | ❌ Не содержит |
| Дополнительные корневые подсистемы | Организация командного интерфейса | ✅ Содержит |
