# #std752 Обработчик события ПередУдалением

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Назначение обработчика

В обработчике `ПередУдалением` модуля объекта выполняются действия, которые необходимо выполнить **перед удалением объекта**.

**Пример:** Перед удалением присоединённого файла — очистка ссылок на этот файл в объекте-владельце.

---

## 2. Проверка ОбменДанными.Загрузка

⚠️ **Обязательно:** Все действия в обработчике `ПередУдалением` должны выполняться **после проверки** на `ОбменДанными.Загрузка`.

```1c
Процедура ПередУдалением(Отказ)

    Если ОбменДанными.Загрузка Тогда
        Возврат;
    КонецЕсли;

    // Действия перед удалением объекта
    // ...

КонецПроцедуры
```

---

## 3. Почему важна проверка

Действия **не должны** выполняться перед удалением объекта через механизм обмена данными — это может привести к ошибкам.

| Проблема | Пример |
|----------|--------|
| Обращение к несуществующим данным | Обращение к предопределённым объектам после очистки области данных |

---

## 4. Типичные задачи

| Задача | Пример |
|--------|--------|
| Очистка ссылок | Удаление ссылок на удаляемый объект в связанных объектах |
| Каскадное удаление | Удаление подчинённых объектов |
| Логирование | Запись информации об удалении |
