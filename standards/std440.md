# #std440 Использование дублирующего кода

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Что такое дублирование кода

**Дублирование кода** — копирование существующих фрагментов кода или целых процедур/функций без изменений, когда копируемый функционал по логике должен быть одинаковым.

### Проблемы дублирования

- В копию попадают **все ошибки** из оригинала
- При исправлении ошибок можно **пропустить вхождения**
- Затраты на исправление **увеличиваются**
- **Усложняется** понимание структуры программы

### Причины дублирования

Часто возникает из-за невозможности доступа к написанному прежде коду (например, код в модуле формы, а нужен в другой форме).

### Решение

**Переработать код** — вывести процедуры и функции из модулей объектов и форм в **общие модули**.

---

## 2. Когда дублирование оправдано

Дублирование **допустимо**, если развитие функционала в будущем может привести к **значительному расхождению** двух вариантов кода.

## Пример: клиент-серверные функции

### ❌ Неправильно — инструкции препроцессора

```1c
Процедура СообщитьПользователю(...) Экспорт

  Сообщение = Новый СообщениеПользователю;
  Сообщение.Текст = ТекстСообщенияПользователю;

  ЭтоОбъект = Ложь;

#Если НЕ ТонкийКлиент И НЕ ВебКлиент Тогда
  Если КлючДанных <> Неопределено
      И XMLТипЗнч(КлючДанных) <> Неопределено Тогда
    ТипЗначенияСтрокой = XMLТипЗнч(КлючДанных).ИмяТипа;
    ЭтоОбъект = СтрНайти(ТипЗначенияСтрокой, "Object.") > 0;
  КонецЕсли;
#КонецЕсли

  Если ЭтоОбъект Тогда
    Сообщение.УстановитьДанные(КлючДанных);
  Иначе
    Сообщение.КлючДанных = КлючДанных;
  КонецЕсли;

КонецПроцедуры
```

### ✅ Правильно — разделить на модули

**1) Серверная функция** (модуль `ОбщегоНазначенияСервер`):

```1c
Процедура СообщитьПользователю(...) Экспорт

  ЭтоОбъект = Ложь;
  Если КлючДанных <> Неопределено
      И XMLТипЗнч(КлючДанных) <> Неопределено Тогда
    ТипЗначенияСтрокой = XMLТипЗнч(КлючДанных).ИмяТипа;
    ЭтоОбъект = СтрНайти(ТипЗначенияСтрокой, "Object.") > 0;
  КонецЕсли;

  ОбщегоНазначенияСлужебныйКлиентСервер.СообщитьПользователю(
      ТекстСообщенияПользователю, КлючДанных, Поле, Отказ, ЭтоОбъект);

КонецПроцедуры
```

**2) Клиентская функция** (модуль `ОбщегоНазначенияКлиент`):

```1c
Процедура СообщитьПользователю(...) Экспорт

  ОбщегоНазначенияСлужебныйКлиентСервер.СообщитьПользователю(
      ТекстСообщенияПользователю, КлючДанных, Поле, Отказ);

КонецПроцедуры
```

**3) Общая реализация** (модуль `ОбщегоНазначенияСлужебныйКлиентСервер`):

```1c
Процедура СообщитьПользователю(Знач ТекстСообщенияПользователю,
    Знач КлючДанных, Знач Поле, Отказ = Ложь, ЭтоОбъект = Ложь) Экспорт

  Сообщение = Новый СообщениеПользователю;
  Сообщение.Текст = ТекстСообщенияПользователю;
  Сообщение.Поле = Поле;

  Если ЭтоОбъект Тогда
    Сообщение.УстановитьДанные(КлючДанных);
  Иначе
    Сообщение.КлючДанных = КлючДанных;
  КонецЕсли;

  Сообщение.Сообщить();
  Отказ = Истина;

КонецПроцедуры
```

## Сводка

| Ситуация | Рекомендация |
|----------|--------------|
| Код в модуле формы нужен в другой форме | Вынести в общий модуль |
| Одинаковая логика в разных местах | Создать общую процедуру |
| Клиент-серверный код с различиями | Разделить на модули + общая реализация |
| Функционал будет расходиться | Дублирование допустимо |

---

## Как избежать дублирования

1. **Общие модули** — выносить повторно используемый код
2. **Служебные КлиентСервер-модули** — для общей логики
3. **Рефакторинг** — переработка существующего кода
4. **Не использовать препроцессор** для различий клиент/сервер
