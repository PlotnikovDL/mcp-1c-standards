# #std629 Минимизация кода, выполняемого на клиенте

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Основное правило

### 1.1. Минимизация клиентского кода

Необходимо **минимизировать** объем кода, который выполняется на стороне клиентского приложения.

**Не следует** выполнять на клиенте сложные алгоритмы, требующие значительных ресурсов. Выполнение алгоритма на клиенте может занимать **гораздо больше времени**, чем:
- передача управления с клиента на сервер
- выполнение алгоритма на сервере
- возврат результата обратно на клиент

**Рекомендация:** размещать такие алгоритмы в серверном коде с минимально необходимым числом обращений с клиента.

**Причины:**
- Клиентский компьютер, как правило, **менее производительный**, чем серверный
- В **веб-клиенте** интерпретатор встроенного языка работает заметно медленнее, чем в тонком или толстом клиенте

### 1.2. Исключение — быстрые алгоритмы

Рекомендуется **оставлять на клиенте** алгоритмы, скорость работы которых заведомо быстрее затрат на вызов серверной функции.

**Пример:** перерасчет доступности элементов управления в форме при изменении данных пользователем — выполняется на клиенте, т.к. контекстный серверный вызов для сложной формы может сделать работу пользователя неприемлемой.

---

## 2. Исключения

### 2.1. Работа с клиентским ПО

Исключение составляют случаи, когда функциональная подсистема предназначена для работы с программным обеспечением, установленным на **клиентском компьютере**:
- Работа с торговым оборудованием
- Интеграция с клиент-банком
- Формирование печатных форм в офисные программы
- и т.п.

### 2.2. Директивы препроцессора

Если подсистема предназначена для работы с клиентским ПО только в определенных режимах, следует использовать **директивы препроцессора**.

**Пример** (код, недоступный в веб-клиенте):

```1c
#Если ВебКлиент Тогда
  Предупреждение(НСтр("ru = 'Загрузка адресного классификатора не доступна в веб-клиенте.'"));
#Иначе
  ОткрытьФорму("РегистрСведений.АдресныйКлассификатор.Форма.ФормаЗагрузкиАдресногоКлассификатора");
#КонецЕсли
```

## Сводка

| Где выполнять | Когда |
|---------------|-------|
| На сервере | Сложные алгоритмы, ресурсоёмкие вычисления |
| На клиенте | Быстрые операции (быстрее серверного вызова) |
| На клиенте | Работа с клиентским ПО (оборудование, офисные программы) |

| Клиент | Производительность интерпретатора |
|--------|----------------------------------|
| Толстый клиент | Высокая |
| Тонкий клиент | Высокая |
| Веб-клиент | Низкая |
