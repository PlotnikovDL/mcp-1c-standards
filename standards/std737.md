# #std737 Проверка прав доступа

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Ролевая настройка видимости в формах

При большом количестве ролей в конфигурации (от нескольких десятков) **не рекомендуется** использовать ролевую настройку видимости в элементах форм:
- Просмотр и редактирование реквизитов по ролям
- Пользовательская видимость полей формы по ролям
- Использование команд по ролям

### Рекомендуемые подходы

| Ситуация | Решение |
|----------|---------|
| Сильные различия внешнего вида и функциональности | Отдельные формы для конкретного набора прав |
| Незначительные отличия | Проверка прав в коде |

⚠️ Программное управление видимостью может снизить скорость открытия формы.

### Преимущества

- Упрощение работы из кода с элементами управления (элементы не пропадают из коллекции `Элементы`)
- Повышение устойчивости кода к пересмотру состава ролей
- Организация контроля использования ролей в конфигурации

---

## 2. Ролевая настройка видимости в интерфейсе

**Не рекомендуется** использовать ролевую настройку видимости в:
- Командном интерфейсе конфигурации
- Командном интерфейсе основного раздела
- Рабочей области начальной страницы

**Вместо этого:** настройка прав на разделы командного интерфейса, общие формы и объекты, включённые в командный интерфейс или рабочую область.

**Преимущества:**
- Повышение предсказуемости поведения интерфейса
- Упрощение расследования ошибок

---

## 3. Проверка прав доступа в коде

Для проверки прав доступа использовать метод **`ПравоДоступа`**.

❌ **Неправильно:**

```1c
Если РольДоступна("ДобавлениеИзменениеСтранМира") Тогда ...
Если РольДоступна("ПросмотрОтчетаПопулярныеСтраны") Тогда ...
```

✅ **Правильно:**

```1c
Если ПравоДоступа("Редактирование", Метаданные.Справочники.СтраныМира) Тогда ...
Если ПравоДоступа("Просмотр", Метаданные.Отчеты.ПопулярныеСтраны) Тогда ...
```

**Преимущество:** повышение устойчивости кода к пересмотру состава ролей.

---

## 4. Роли для дополнительных прав

### 4.1. Когда использовать РольДоступна

Если роль **не даёт никаких прав на объекты метаданных**, а служит только для определения дополнительного права — использовать метод **`РольДоступна`**.

**Без использования БСП:**

```1c
Если РольДоступна(...) Или <ЭтоПолноправныйПользователь> Или ПривилегированныйРежим() Тогда ...
```

**С использованием БСП:**

```1c
Если Пользователи.РолиДоступны(...) Тогда ...
```

### 4.2. Роли с привилегированным режимом

Следует проектировать роли с учётом их влияния на командный интерфейс. Если чтение или запись данных ведётся в привилегированном режиме — **не следует** указывать в роли права с условием ограничения `ГДЕ ЛОЖЬ`.

**Пример:** права на общую форму `Заметка` дают роли `ДобавлениеИзменениеЗаметок` и `ЧтениеЗаметок`. Обращение к данным заметок выполняется в привилегированном режиме.

❌ **Неправильно:**

Добавить в роль фиктивные права на регистр сведений `Заметки` (с условием `ГДЕ ЛОЖЬ`):

```1c
Если ПравоДоступа("Редактирование", Метаданные.РегистрыСведений.Заметки) Тогда
```

✅ **Правильно (без БСП):**

```1c
Если РольДоступна("ДобавлениеИзменениеЗаметок") Или <ЭтоПолноправныйПользователь> Или ПривилегированныйРежим() Тогда
```

✅ **Правильно (с БСП):**

```1c
// АПК:515-выкл - №737.4.2 – Допустимо проверять роль, так как в ней нет прав,
// позволяющих определить может ли пользователь добавлять заметки.
Если Пользователи.РолиДоступны("ДобавлениеИзменениеЗаметок") Тогда
// АПК:515-вкл
```

## Сводка

| Ситуация | Метод проверки |
|----------|----------------|
| Права на объекты метаданных | `ПравоДоступа()` |
| Дополнительные права (роль без прав на объекты) | `РольДоступна()` или `Пользователи.РолиДоступны()` |
| Привилегированный режим, роль без реальных прав | `РольДоступна()` или `Пользователи.РолиДоступны()` |

| ❌ Не использовать | ✅ Использовать вместо |
|--------------------|------------------------|
| Ролевая видимость в формах | Отдельные формы или проверка в коде |
| Ролевая видимость в командном интерфейсе | Права на разделы и объекты |
| `РольДоступна()` для проверки прав на объекты | `ПравоДоступа()` |
| Фиктивные права с `ГДЕ ЛОЖЬ` | Проверка роли напрямую |
