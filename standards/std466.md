# #std466 Обработчик события ПриКопировании

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Назначение обработчика

В обработчике `ПриКопировании` модуля объекта выполняются действия, связанные с **созданием нового объекта путём копирования**.

---

## 2. Типичные задачи

| Задача | Описание |
|--------|----------|
| Очистка реквизитов | Очистка значений реквизитов, которые не должны сохраняться при копировании |
| Сброс статусов | Установка начального статуса для нового объекта |
| Генерация новых значений | Присвоение новых уникальных значений (GUID, номера) |

---

## 3. Пример использования

```1c
Процедура ПриКопировании(ОбъектКопирования)

    // Очистка реквизитов, не подлежащих копированию
    Статус = Перечисления.СтатусыДокумента.Черновик;
    ДатаУтверждения = Дата(1, 1, 1);
    Утвердил = Неопределено;

    // Очистка табличной части с результатами обработки
    РезультатыОбработки.Очистить();

КонецПроцедуры
```

---

## 4. Реквизиты для очистки

Типичные реквизиты, которые следует очищать при копировании:

| Тип реквизита | Примеры |
|---------------|---------|
| Статусы и состояния | Статус, Проведён, Утверждён |
| Даты событий | ДатаУтверждения, ДатаОтправки |
| Ответственные лица | Утвердил, Проверил |
| Результаты обработки | Табличные части с результатами |
| Уникальные идентификаторы | GUID, внешние номера |
