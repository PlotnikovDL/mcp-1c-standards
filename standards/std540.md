# #std540 Общие требования к регламентным заданиям

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Когда использовать

Регламентные задания — для выполнения **периодических или однократных** действий по расписанию.

---

## 2. Предопределённые задания

### 2.1. Когда использовать

Если задания **не требуется** добавлять или удалять в зависимости от действий пользователя или логики конфигурации.

**Примеры:**
- Загрузка курсов валют
- Извлечение текста для полнотекстового индексирования
- Обновление агрегатов

### 2.2. Управление признаком «Использование»

⛔ **Недопустимо** выполнять задания, если функциональность отключена — это занимает ресурсы сервера.

**Правильно:** Снять флажок `Использование` и управлять им программно в зависимости от функциональной опции (ФО).

#### БСП: Настройка через РегламентныеЗаданияПереопределяемый

```1c
Процедура ПриОпределенииНастроекРегламентныхЗаданий(Настройки) Экспорт

    Настройка = Настройки.Добавить();
    Настройка.РегламентноеЗадание = Метаданные.РегламентныеЗадания.ОбновлениеСтатусовДоставкиSMS;
    Настройка.ФункциональнаяОпция = Метаданные.ФункциональныеОпции.ИспользоватьПочтовыйКлиент;
    Настройка.ДоступноВМоделиСервиса = Ложь;

КонецПроцедуры
```

#### Без БСП: Управление в модуле менеджера константы

```1c
Процедура ПриЗаписи(Отказ)

    Задание = РегламентныеЗадания.НайтиПредопределенное(
        Метаданные.РегламентныеЗадания.ПолучениеИОтправкаЭлектронныхПисем);

    Если Задание.Использование <> Значение Тогда
        Задание.Использование = Значение;
        Задание.Записать();
    КонецЕсли;

КонецПроцедуры
```

### 2.3. Защита от ручного включения

Дополнительно в начале обработчика задания:

```1c
ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания();

Если НЕ ПолучитьФункциональнуюОпцию("ИспользоватьПочтовыйКлиент") Тогда
    ВызватьИсключение НСтр("ru = 'Регламентное задание недоступно по функциональным опциям.'");
КонецЕсли;
```

## 3. Непредопределённые (параметризованные) задания

### 3.1. Когда использовать

Если выполнение зависит от **данных ИБ**:
- Обмен данными с разными базами по индивидуальному расписанию
- Запуск дополнительных обработок по отдельному расписанию

### 3.2. Создание задания

```1c
УстановитьПривилегированныйРежим(Истина);
Задание = РегламентныеЗадания.СоздатьРегламентноеЗадание(
    Метаданные.РегламентныеЗадания.РассылкаОтчетов);

ПараметрыЗадания = Новый Массив;
ПараметрыЗадания.Добавить(РассылкаОтчетов);
Задание.Параметры = ПараметрыЗадания;

Задание.ИмяПользователя = АвторРассылки;
Задание.Использование = Истина;
Задание.Наименование = СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(
    НСтр("ru = 'Рассылка отчетов: %1'"), СокрЛП(РассылкаОтчетов));
Задание.Расписание = РасписаниеРассылки;
Задание.Записать();
```

### 3.3. БСП: Запрет интерактивного создания

```1c
Настройка = Настройки.Добавить();
Настройка.РегламентноеЗадание = Метаданные.РегламентныеЗадания.РассылкаОтчетов;
Настройка.Параметризуется = Истина;
```

---

## 4. Задания с внешними ресурсами

### 4.1. Блокировка в копиях ИБ

Рекомендуется автоматически блокировать задания, обращающиеся к внешним ресурсам, в копиях ИБ (тестирование, техподдержка).

**Примеры:** Рассылка почты, синхронизация данных.

### 4.2. БСП: Настройка

```1c
Настройка = Настройки.Добавить();
Настройка.РегламентноеЗадание = Метаданные.РегламентныеЗадания.РассылкаОтчетов;
Настройка.РаботаетСВнешнимиРесурсами = Истина;
```

---

## 5. БСП: Вызов в начале обработчика

Для заданий, подпадающих под требования 3.1, 4.2, 5:

```1c
ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания(
    Метаданные.РегламентныеЗадания.<ИмяЗадания>);
```

⚠️ **Первый параметр обязателен.**

---

## 6. Сводная таблица

| Тип задания | Предопределённое | Управление |
|-------------|------------------|------------|
| Не зависит от данных ИБ | ✅ Да | Через ФО |
| Зависит от данных ИБ | ❌ Нет | Программное создание |
| Работает с внешними ресурсами | Любое | Блокировка в копиях |
