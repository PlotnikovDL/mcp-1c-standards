# #std407 Применение параметров отчета в СКД

> Область применения: управляемое приложение, обычное приложение.

---

## Рекомендации

При использовании параметров в отчетах СКД (система компоновки данных) следует придерживаться следующих рекомендаций.

---

### 1. Предпочитать отборы вместо параметров

**Избегать** использования параметров отчета, если можно обойтись «обычным» управлением элементами отбора.

**❌ Не рекомендуется:**

```1c
ГДЕ Организация = &Организация
```

**✅ Рекомендуется:** дать пользователю возможность управлять элементом отбора **Организация** через настройки СКД.

---

### 2. Избегать обязательных параметров

**Избегать** применения обязательных параметров, чтобы исключить ситуацию, когда пользователь отключает параметр и получает ошибку «Не задан параметр отчета».

Для этого следует использовать синтаксические элементы расширения языка запросов СКД **{ГДЕ...}**.

**Пример:**

```1c
{ГДЕ Сведения.Период >= &ДатаНачала, Сведения.Период <= &ДатаОкончания}
```

При использовании этой конструкции:

- Оба параметра `ДатаНачала` и `ДатаОкончания` будут **необязательными**
- При отключении параметра пользователем соответствующий фрагмент условия будет **отключён автоматически**

---

## Сводка

| Подход | Рекомендация |
|--------|--------------|
| `ГДЕ Поле = &Параметр` | ❌ Избегать — использовать отборы СКД |
| `{ГДЕ Поле = &Параметр}` | ✅ Рекомендуется — параметр необязательный |
| Обязательные параметры | ❌ Избегать |
