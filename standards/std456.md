# #std456 Тексты модулей

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Язык

Тексты модулей должны быть написаны **на русском языке**.

**Исключения:**
- Веб-сервисы — имена методов и параметров на английском (например, `TestConnection`)
- Идентификаторы сторонних систем — названия полей внешних структур данных

### 1.1. Буква «ё»

❌ В текстах модулей **не допускается** использовать букву «ё».

✅ Исключение: интерфейсные тексты для пользователя (см. #std598).

### 1.2. Специальные символы

❌ Не допускается использовать:
- Неразрывные пробелы
- Знак минус в других кодировках (короткое тире, длинное тире)

**Причина:** часто попадают при копировании из офисных документов. Приводят к:
- Не работает поиск фрагментов текста
- Некорректные подсказки типов в конфигураторе
- Синтаксические ошибки при «неправильном» минусе в выражениях

---

## 2. Неиспользуемый код

> ℹ️ Методическая рекомендация

Программные модули **не должны** иметь неиспользуемых процедур и функций.

---

## 3. Закомментированный и служебный код

❌ Не допускается:
- Закомментированные фрагменты кода
- Отладочный код
- Служебные отметки: `TODO`, `MRG` и т.п.
- Ссылки на конкретных разработчиков

### Примеры

**❌ Неправильно:**

```1c
Процедура ПередУдалением(Отказ)
//    Если Истина Тогда
//        Сообщение("Для отладки");
//    КонецЕсли;
КонецПроцедуры
```

**❌ Неправильно:**

```1c
Процедура ПередУдалением(Отказ)
    Если Истина Тогда
        // Иванов: доделать
    КонецЕсли;
КонецПроцедуры
```

**✅ Правильно:** удалить обработчик `ПередУдалением` после завершения отладки.

### Комментарии в запросах

**❌ Неправильно** — модификация запроса через комментарии:

```1c
ТекстЗапроса = "ВЫБРАТЬ
    | Контрагенты.Ссылка КАК Ссылка
    |// ПОМЕСТИТЬ втКонтрагенты
    |ИЗ
    | Справочник.Контрагенты КАК Контрагенты";

Если ВыгрузитьВоВременнуюТаблицу Тогда
    ТекстЗапроса = СтрЗаменить(ТекстЗапроса, "// ПОМЕСТИТЬ", "ПОМЕСТИТЬ");
КонецЕсли;
```

О модификации текстов запросов см. #std437.

## 4. Один оператор в строке

Тексты модулей оформляются по принципу **«один оператор в одной строке»**.

**Исключение:** однотипные операторы присваивания:

```1c
НачальныйИндекс = 0; Индекс = 0; Результат = 0;
```

---

## 5. Отступы и выравнивание

- Для синтаксического отступа используется **табуляция** (не пробелы)
- Размер табуляции — **4 символа**

### 5.1. С крайней левой позиции начинаются только:

- `Процедура`, `КонецПроцедуры`, `Функция`, `КонецФункции`
- Заголовки (описания) процедур и функций
- Объявление переменных модуля
- Код вне процедур и функций (с учётом синтаксического отступа)
- Директивы компилятора: `&НаКлиенте`, `&НаСервере` и т.д.
- Аннотации: `&Перед`, `&После` и др.
- Инструкции препроцессора: `#Область`, `#КонецОбласти` и др.

### 5.2. Транзакции — не операторные скобки

`НачатьТранзакцию` и `ЗафиксироватьТранзакцию` **не являются** операторными скобками → текст внутри **не сдвигается**.

---

## 6. Длина строки

Максимальная длина строки — **120 символов**.

При превышении — использовать переносы (см. #std444).

**Исключение:** длинные строковые константы, которые нельзя перенести.

---

## 7. Комментарии

### 7.1. Общие требования

- Должны быть понятными
- Составляются по правилам русского языка
- Деловой стиль, эмоционально сдержанные
- Не содержат слов, не относящихся к функциональности

### 7.2. Небольшие комментарии — в конце строки

```1c
НайденныеОшибки.Колонки.Добавить("Номер"); // для совместимости
```

### 7.3. Большие комментарии — перед кодом

```1c
// Инициализируем переменные для выполнения расчетов,
// которые выполняются далее по тексту модуля.
ТекущаяДата = ОбщегоНазначения.ПолучитьРабочуюДату();
ТекущийГод = Год(ТекущаяДата);
ТекущийМесяц = Месяц(ТекущаяДата);
```

- Выравнивание по левой границе комментируемого фрагмента
- Пробел между `//` и текстом комментария

---

## 8. Области в больших процедурах

Тексты больших процедур и функций можно разбивать на **сворачиваемые области**.

Имена областей должны удовлетворять требованиям #std454.

---

## Сводка

| Правило | Требование |
|---------|------------|
| Язык | Русский (исключение: веб-сервисы, внешние идентификаторы) |
| Буква «ё» | ❌ Запрещена (кроме UI текстов) |
| Спецсимволы | ❌ Неразрывные пробелы, тире — запрещены |
| Неиспользуемый код | ❌ Удалять |
| Закомментированный код | ❌ Удалять |
| TODO, отладочный код | ❌ Удалять |
| Операторов в строке | Один (исключение: однотипные присваивания) |
| Отступ | Табуляция, 4 символа |
| Длина строки | Максимум 120 символов |
| Транзакции | Не сдвигать код внутри |
