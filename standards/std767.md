# #std767 Регламентные задания: требования по локализации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Предопределённые регламентные задания

Предопределённым регламентным заданиям **не следует задавать наименования** в конфигураторе. Вместо этого достаточно задать **синоним** предопределённого регламентного задания.

### Неправильно

> На скриншоте: регламентное задание «ЗагрузкаКлассификатораБанков» с заполненным полем «Наименование» = «Загрузка классификатора банков».

### Правильно

> На скриншоте: регламентное задание «ЗагрузкаКлассификатораБанков» с пустым полем «Наименование» и заполненным «Синоним» = «Загрузка классификатора банков».

**Причина:** В отсутствие наименования платформа возьмёт его автоматически из **локализуемого синонима**. Если же наименование задано, то будет использоваться оно, а оно **не поддерживает локализацию**.

---

## 2. Непредопределённые (параметризованные) регламентные задания

Для непредопределённых (параметризованных) регламентных заданий наименование задаётся **программно**, оформляется с **НСтр** и может описывать контекст выполнения задания.

✅ **Правильно:**

```1c
Задание = РегламентныеЗадания.СоздатьРегламентноеЗадание(Метаданные.РегламентныеЗадания.РассылкаОтчетов);
Задание.Наименование = СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(НСтр("ru = 'Рассылка отчетов: %1'"), РассылкаОтчетов);
Задание.Записать();
```

---

## Сводка

| Тип задания | Наименование | Синоним |
|-------------|--------------|---------|
| Предопределённое | Не задавать | Задавать (локализуется) |
| Непредопределённое | Программно с НСтр | — |

| Правило | Описание |
|---------|----------|
| Предопределённые задания | Наименование пустое, используется синоним |
| Параметризованные задания | Наименование через НСтр с контекстом |
