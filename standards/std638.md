# #std638 Работа с неактуальными (недействительными) объектами

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

> *Методическая рекомендация (полезный совет)*

---

## 1. Область применения

Когда объект информационной базы **перестаёт быть актуальным** — навсегда или на время:
- Сотрудник увольняется или уходит в декретный отпуск
- Подразделение расформируется
- и т.д.

⛔ **Удалять объект недопустимо** — нарушается ссылочная целостность (на него ссылаются другие объекты).

**Пример:** Объект `Файл` должен содержать в поле `Автор` ссылку на уволившегося сотрудника и после его увольнения.

---

## 2. Реквизит «Недействителен»

Для учёта неактуальных объектов добавляется реквизит:

| Реквизит | Тип | По умолчанию |
|----------|-----|--------------|
| `Недействителен` | Булево | Ложь |

---

## 3. Запрет выбора неактуальных объектов

### 3.1. Подход 1: Запрет по умолчанию

Если запрет должен действовать **во всех или в большинстве** полей ввода.

#### 3.1.1. Обработчики модуля менеджера

```1c
Процедура ОбработкаПолученияДанныхВыбора(ДанныеВыбора, Параметры, СтандартнаяОбработка)
    Если Не Параметры.Отбор.Свойство("Недействителен") Тогда
        Параметры.Отбор.Вставить("Недействителен", Ложь);
    КонецЕсли;
КонецПроцедуры

Процедура ОбработкаПолученияФормы(ВидФормы, Параметры, ВыбраннаяФорма, ДополнительнаяИнформация, СтандартнаяОбработка)
    Если ВидФормы = "ФормаВыбора" Тогда
        ПараметрИзменен = Ложь;

        Если Не Параметры.Свойство("Отбор") Тогда
            Параметры.Вставить("Отбор", Новый Структура("Недействителен", Ложь));
            ПараметрИзменен = Истина;
        ИначеЕсли Не Параметры.Отбор.Свойство("Недействителен") Тогда
            Параметры.Отбор.Вставить("Недействителен", Ложь);
            ПараметрИзменен = Истина;
        КонецЕсли;

        // Используем изменённые параметры
        Если ПараметрИзменен Тогда
            СтандартнаяОбработка = Ложь;
            ВыбраннаяФорма = "ФормаВыбора";
        КонецЕсли;
    КонецЕсли;
КонецПроцедуры
```

#### 3.1.2. Переопределение для отдельных реквизитов

Для реквизитов, где нужно другое поведение — установить свойства:
- **«Параметры выбора»**
- **«Связи параметров выбора»**

| Задача | Параметры выбора |
|--------|------------------|
| Выбирать только действующих | `Отбор.Недействителен(Ложь)` |
| Без ограничений | `Отбор.Недействителен(Истина, Ложь)` |

### 3.2. Подход 2: Контекстно-зависимый запрет

Если запрет **сильно зависит от контекста** (сценариев работы).

- Модуль менеджера **не реализуется**
- Для каждого реквизита устанавливаются свойства «Параметры выбора» и «Связи параметров выбора»
- При сложных критериях — обработчики формы: `ОбработкаПолученияДанныхВыбора`, `ОбработкаВыбора`, `ОкончаниеВводаТекста` + отдельная форма выбора

---

## 4. Формы списка и выбора

✅ Рекомендуется добавить флажок **«Показывать недействительных пользователей»**.

**Назначение:**
- Выбрать или открыть карточку неактуального пользователя
- Снова сделать пользователя действительным (например, сотрудница вернулась из декретного отпуска)

---

## 5. Отображение в списках

Для отображения неактуальных объектов использовать элемент стиля:

```
ТекстЗапрещеннойЯчейкиЦвет (192, 192, 192)
```

Неактуальные записи отображаются **серым цветом**.
