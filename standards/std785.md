# #std785 Версия платформы 1С:Предприятие для разработки

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Минимальная версия платформы

### 1.1. Правила установки

| Тип решения | Минимальная версия |
|-------------|-------------------|
| Для госучреждений, оборонных предприятий, корпоративных клиентов | ≤ версии последнего сертифицированного релиза 8.3z |
| Любые библиотеки | ≤ версии последнего сертифицированного релиза 8.3z |
| Остальные решения | На усмотрение ответственного |

**Пример:** Если решение выпускается на 8.3.15 в режиме совместимости с 8.3.14, а последний сертифицированный релиз — 8.3.14.2032 (основан на 8.3.14.1976), то минимальная версия = **8.3.14.1976**.

### 1.2. Увеличение минимальной версии

- Допускается при невозможности обойти ошибку на уровне прикладного решения
- Для госучреждений — новый релиз должен быть сертифицирован в короткие сроки

### 1.3. Ограничения для библиотек

⚠️ В **исправительных релизах библиотек** увеличивать минимальную версию **не допускается** — это решение принимается для каждого прикладного решения индивидуально.

---

## 2. Рекомендуемая версия платформы

| Тип решения | Рекомендуемая версия |
|-------------|---------------------|
| Прикладные конфигурации | На усмотрение ответственного (ориентир — последний релиз, на котором ведётся разработка и тестирование) |
| Библиотеки | Не может быть увеличена в исправительных релизах |

**Пример:** Минимальная версия 8.3.14, рекомендуемая — 8.3.15 (улучшен ряд важных функций).

Для госучреждений рекомендуемая версия может быть выше сертифицированной — пользователи продолжают работу на сертифицированном релизе и информируются о рекомендации.

## 3. Техническая реализация

### 3.1. Блокировка запуска (БСП)

Запуск на платформе ниже минимальной версии блокируется через БСП.

Версии задаются в процедуре **ПриОпределенииОбщихПараметровБазовойФункциональности** общего модуля **ОбщегоНазначенияПереопределяемый**:

```1c
Процедура ПриОпределенииОбщихПараметровБазовойФункциональности(ОбщиеПараметры) Экспорт

    ОбщиеПараметры.МинимальноНеобходимаяВерсияПлатформы = "8.3.14.1976";
    ОбщиеПараметры.РекомендуемаяВерсияПлатформы = "8.3.15.1700";

КонецПроцедуры
```

### 3.2. Документирование

Версии указываются в файле **readme.txt** дистрибутива:

```
Минимальная версия платформы 1С:Предприятие для использования конфигурации: 8.3.14.1976.
Рекомендуемая версия платформы: 8.3.15.1700 (или больше).
```

## 4. Краткая справка

| Параметр | Где задаётся | Описание |
|----------|--------------|----------|
| Минимальная версия | `ОбщегоНазначенияПереопределяемый` | Ниже неё запуск блокируется |
| Рекомендуемая версия | `ОбщегоНазначенияПереопределяемый` | Информирование пользователей |
| Режим совместимости | Свойства конфигурации | Определяет поведение платформы |
