# #std777 Использование временных таблиц

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Назначение временных таблиц

Временные таблицы рекомендуется использовать для **повышения производительности** и стабильности выполнения запросов.

Можно использовать для других целей (улучшение архитектуры кода), но это может **снизить производительность**.

---

## 2. Когда НЕ создавать временные таблицы

### 2.1. Большой объём данных

❌ **Не создавайте** временные таблицы с сотнями тысяч записей.

**Последствия:**
- Снижение производительности при записи
- Исчерпание места на диске

**Решение:** Обрабатывать данные **порциями**.

### 2.2. Избыточные данные

❌ Не помещайте во временную таблицу **больше данных**, чем нужно последующим запросам.

### 2.3. Лишние поля

❌ Не помещайте поля, которые **не используются** в последующих запросах — время и место тратятся впустую.

### 2.4. Создание в цикле

❌ Не создавайте и не удаляйте временные таблицы **в цикле**, если можно создать одну таблицу **до** выполнения цикла.

### 2.5. Копирование для переименования

❌ Не копируйте временную таблицу в другую только для **переименования**.

✅ Передавайте **имя таблицы** как параметр.

---

## 3. Индексирование временных таблиц

### 3.1. Когда индексировать

| Ситуация | Что индексировать |
|----------|-------------------|
| Большая таблица в соединении | Поля из условия `ПО` |
| Таблица в подзапросе `В (...)` | Поля из `ВЫБРАТЬ`, соответствующие левой части `В` |

**Пример для соединения:**
```1c
ВЫБРАТЬ ...
ИЗ Документ.Заказы
    ЛЕВОЕ СОЕДИНЕНИЕ ВременнаяТаблица  // ← индексировать
    ПО ВременнаяТаблица.Номенклатура = Заказы.Товар  // ← по этому полю
```

**Пример для `В`:**
```1c
ГДЕ (Номенклатура, Склад) В (
    ВЫБРАТЬ Номенклатура, Склад  // ← индексировать эти поля
    ИЗ ВременнаяТаблица
)
```

### 3.2. Когда НЕ индексировать

- Таблицы **менее 1000 записей** — индекс не нужен

### 3.3. Несколько условий

Если к временной таблице несколько условий/соединений — индексируйте **наиболее частое**.

---

## 4. Сводка

| Правило | Действие |
|---------|----------|
| Большой объём | Обработка порциями |
| Лишние данные/поля | Не помещать |
| Создание в цикле | Создать до цикла |
| Переименование | Передавать имя |
| Индексирование | Для больших таблиц в JOIN и IN |
| Маленькие таблицы | Не индексировать (<1000) |
