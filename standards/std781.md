# #std781 Особенности сортировки в таблице значений

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## Проблема

При сортировке таблицы значений по колонкам, содержащим **ссылочные значения**, для каждой строки таблицы система выполняет **обращение к информационной базе** за представлением ссылки.

Это особенно критично для таблиц с большим количеством строк (сотни и тысячи).

---

## Рекомендации

### 1. Сортировка по наименованию

Если требуется сортировка по наименованию — на этапе заполнения добавлять **дополнительные колонки с представлениями** и сортировать по ним.

### 2. Сортировка по ссылке

В остальных случаях — сортировать «по ссылке», а не по представлению. Для этого использовать объект **СравнениеЗначений**:

```1c
ОбъектСравнения = Новый СравнениеЗначений;
ТаблицаДокументов.Сортировать("Дата,Ссылка", ОбъектСравнения);
```

---

## Сводка

| Способ сортировки | Обращения к БД | Рекомендация |
|-------------------|----------------|--------------|
| По ссылке (без СравнениеЗначений) | Много (за представлениями) | ❌ |
| По ссылке (с СравнениеЗначений) | Нет | ✅ |
| По колонке с представлением | Нет | ✅ |
