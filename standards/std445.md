# #std445 Получение метаданных объектов

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Когда тип объекта известен

Если известен тип объекта метаданных (справочник, документ и т.п.), получать метаданные следует через метод **Метаданные()** самого объекта (или ссылки), а не через глобальное свойство **Метаданные**.

**Причина:** обращение к глобальному контексту **существенно медленнее**.

### ✅ Правильно

```1c
СправочникОбъект.Метаданные()
```

### ❌ Неправильно

```1c
Метаданные.Справочники[ИмяСправочника]
Метаданные.НайтиПоПолномуИмени("Справочник." + ИмяСправочника)
```

---

## 2. Когда тип объекта неизвестен

Если тип объекта метаданных заранее неизвестен, использовать метод **НайтиПоТипу**.

### Пример

```1c
// Получить полное имя объекта метаданных вида
// "Справочник.Номенклатура", "Документ.ПриходнаяНакладная" по переданной ссылке.
ИмяОбъектаМетаданного = Метаданные.НайтиПоТипу(ТипЗнч(Ссылка)).ПолноеИмя();
```

---

## Сводка

| Ситуация | Способ |
|----------|--------|
| Тип известен | `Объект.Метаданные()` или `Ссылка.Метаданные()` |
| Тип неизвестен | `Метаданные.НайтиПоТипу(ТипЗнч(Ссылка))` |
| Через глобальный контекст | ❌ Медленно, не использовать |
