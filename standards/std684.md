# #std684 Список, открываемый из панели навигации формы объекта

> Область применения: управляемое приложение.
>
> Раздел ИТС: Проектирование интерфейсов для 8.2 / Формы
>
> Источник: https://its.1c.ru/db/v8std/content/684/hdoc
>
> Проверено по источнику: 2026-10-07

1\. Список, открываемый из панели навигации формы объекта, следует отражать с отбором по этому объекту.

<span style="color: #536ac2">*Например, в списке «Договоры» справочника «Контрагент» отражаются договоры только по конкретному контрагенту, например, по ООО «Контрагент»*</span>

<a id="2"></a>2\. В списке не следует выводить название объекта (в виде надписи или поля ввода в режиме "просмотр"), т.к. оно отображается в области системных команд и в панели навигации

<a id="3"></a>3\. В списке не следует отражать колонку с названием объекта, т.к. для каждой строки это название будет одинаковым.

<span style="color: #536ac2">*Например, в списке «Договоры» справочника «Контрагент» колонка Контрагент не выводится.*</span>

![Иллюстрация 3 к стандарту #std684](assets/std684/03.png)

<a id="4"></a>4\. В названии команды, отражаемой в панели навигации, не следует указывать название объекта, т.к. его можно определить из контекста.
