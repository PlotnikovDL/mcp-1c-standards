# #std770 Ограничения на использование Выполнить и Вычислить на сервере

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Уязвимость

Опасно не только выполнение кода, введённого в режиме Предприятие, но и выполнение методами `Выполнить` или `Вычислить` кода, **сконструированного на основе параметров**, переданных в серверные функции.

**Ограничение не распространяется** на код, выполняемый на клиенте.

### Пример уязвимости

**Сценарий разработчика:**
1. Клиентская функция создаёт структуру со строкой кода
2. Передаёт структуру в серверную функцию формы
3. Серверная функция вызывает функцию общего модуля
4. В серверной функции исполняется код из строки

**Атака злоумышленника:**
1. Создаёт структуру с вредоносным кодом
2. Вызывает клиентскую функцию формы
3. Вредоносный код исполняется на сервере

**Ещё опаснее:** если методы с `Выполнить`/`Вычислить` располагаются в модулях с признаком **ВызовСервера**.

---

## 2. Решение — безопасный режим

Перед вызовом `Выполнить` или `Вычислить` включать **безопасный режим**:

```1c
УстановитьБезопасныйРежим(Истина);
Выполнить Алгоритм;
```

### Для модели сервиса (с разделением данных)

```1c
УстановитьБезопасныйРежим(Истина);

Для каждого ИмяРазделителя Из РазделителиКонфигурации() Цикл
  УстановитьБезопасныйРежимРазделенияДанных(ИмяРазделителя, Истина);
КонецЦикла;

Выполнить Алгоритм;
```

### При использовании БСП

| Вместо | Использовать |
|--------|--------------|
| `Выполнить` | `ОбщегоНазначения.ВыполнитьВБезопасномРежиме()` |
| `Вычислить` | `ОбщегоНазначения.ВычислитьВБезопасномРежиме()` |
| Формирование строки вызова метода модуля | `ОбщегоНазначения.ВыполнитьМетодКонфигурации()` |
| Формирование строки вызова метода объекта | `ОбщегоНазначения.ВыполнитьМетодОбъекта()` |

---

## 3. Код, требующий небезопасного режима

Если произвольный код **не может** успешно выполняться в безопасном режиме (например, обращение к файлам):

### Сценарий работы

1. **Поместить код** во внешнюю обработку/отчёт (или как фрагмент текста)
2. **Передать администратору** с пометкой о необходимости небезопасного режима
3. **Администратор проводит аудит** полученного кода
4. **Если код безопасен** — поместить в специальный справочник (доступ на запись только у администратора)
5. **Вместо `Выполнить`/`Вычислить`:**
   - Подключить проверенную обработку из справочника и вызвать экспортный метод
   - Или вызвать через централизованную процедуру выполнения внешнего кода

### При использовании БСП

Использовать подсистему **«Дополнительные отчеты и обработки»**.

---

## 4. Модель сервиса — перенос данных

При переносе данных из локальной версии в сервис необходимо **отключить все пользовательские фрагменты кода** или тексты запросов, введённые в локальной версии.

При использовании БСП — см. подсистему **«Работа в модели сервиса»** (предварительная обработка загружаемых данных).

## Сводка

| Ситуация | Решение |
|----------|---------|
| `Выполнить`/`Вычислить` на сервере | `УстановитьБезопасныйРежим(Истина)` |
| С разделением данных | + `УстановитьБезопасныйРежимРазделенияДанных()` |
| При использовании БСП | `ОбщегоНазначения.ВыполнитьВБезопасномРежиме()` |
| Код требует небезопасного режима | Аудит + справочник администратора |
| Перенос в сервис | Отключить пользовательские фрагменты кода |

| Метод платформы | Метод БСП |
|-----------------|-----------|
| `Выполнить` | `ОбщегоНазначения.ВыполнитьВБезопасномРежиме()` |
| `Вычислить` | `ОбщегоНазначения.ВычислитьВБезопасномРежиме()` |
| Вызов метода модуля | `ОбщегоНазначения.ВыполнитьМетодКонфигурации()` |
| Вызов метода объекта | `ОбщегоНазначения.ВыполнитьМетодОбъекта()` |
