# #std450 Порядок записи движений документов

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.
>
> Раздел ИТС: Соглашения при написании кода / Использование прикладных объектов и универсальных коллекций значений
>
> Источник: https://its.1c.ru/db/v8std/content/450/hdoc
>
> Проверено по источнику: 2026-10-07

<a id="1"></a>1\. Не рекомендуется использовать явную запись наборов записей регистров (с помощью метода **Записать**) в процедурах обработки проведения документов. Запись должна производится неявно системой, при завершении процедуры проведения. <br>

<br>

В случае же нарушения этого правила, при параллельной работе нескольких пользователей, возможна ситуация возникновения взаимных блокировок при проведении документов. <br>

<br>

2\. Исключением является ситуация, когда данные, сохраняемые в регистрах, необходимы в последующих алгоритмах, выполняемых до момента выхода из процедуры проведения.
