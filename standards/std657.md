# #std657 Обращения к виртуальным таблицам

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Условия в параметрах, а не в ГДЕ

Передавайте **все условия** в параметры виртуальной таблицы, а не в секцию `ГДЕ`.

❌ **Неправильно:**
```1c
ВЫБРАТЬ Номенклатура
ИЗ РегистрНакопления.ТоварыНаСкладах.Остатки()
ГДЕ Склад = &Склад
```

✅ **Правильно:**
```1c
ВЫБРАТЬ Номенклатура
ИЗ РегистрНакопления.ТоварыНаСкладах.Остатки(, Склад = &Склад)
```

**Причина:** Без параметров СУБД может сначала выбрать **все** записи виртуальной таблицы, а потом отфильтровать. Параметры ограничивают выборку на **раннем этапе**.

---

## 2. Простые условия в параметрах

### 2.1. Используйте простые конструкции

Рекомендуется: `Измерение = Значение`

**Не рекомендуется** в параметрах виртуальных таблиц:
- Подзапросы
- Явные соединения
- Неявные соединения (через точку от ссылки)
- Соединения из RLS

### 2.2. Правила для подзапросов

Если подзапрос **необходим**, соблюдайте условия:

| Условие | Требование |
|---------|------------|
| Одна таблица | Нет соединений с другими таблицами |
| Табличная часть | Нет обращений к реквизитам шапки |
| Таблица с ТЧ | Нет обращений к табличным частям |
| Временная таблица | Нет секции `ГДЕ` |
| Постоянная таблица | Условие выполняется для ≥80% записей |
| Постоянная таблица | RLS без подзапросов и соединений |

❌ **Неправильно:**
```1c
ИЗ РегистрНакопления.ТоварыКОтгрузке.Остатки(
    &ДатаОтгрузки,
    ДокументОтгрузки.Склад = &Склад  // неявное соединение «через точку»
    ИЛИ ДокументОтгрузки В (
        ВЫБРАТЬ Распоряжения.Распоряжение
        ИЗ Документ.ЗаданиеНаПеревозку.Распоряжения КАК Распоряжения
        ВНУТРЕННЕЕ СОЕДИНЕНИЕ ...  // соединение в подзапросе
        ГДЕ Распоряжения.Ссылка.Проведен  // обращение к шапке
    ))
```

✅ **Правильно:**
```1c
ИЗ РегистрНакопления.ТоварыКОтгрузке.Остатки(
    &ДатаОтгрузки,
    Склад = &Склад  // реквизит регистра
    ИЛИ ДокументОтгрузки В (
        ВЫБРАТЬ ЗаданияНаПеревозку.Распоряжение
        ИЗ ВременнаяТаблицаЗаданийНаПеревозку КАК ЗаданияНаПеревозку
    ))  // временная таблица без условий
```

### 2.3. Несколько условий с подзапросами

Если нужно несколько условий с подзапросами:
1. Выберите **одно**, которое фильтрует максимум записей
2. Остальные условия перенесите во **внешний запрос**

### 2.4. Кортежные условия вместо множества IN

❌ **Неправильно:**
```1c
Номенклатура В (...) И Характеристика В (...) И Серия В (...)
```

✅ **Правильно:**
```1c
(Номенклатура, Характеристика, Серия) В (
    ВЫБРАТЬ Номенклатура, Характеристика, Серия
    ИЗ ВременнаяТаблицаТоваров
)
```

---

## 3. Сводка

| Правило | Описание |
|---------|----------|
| Условия в параметрах | Не в `ГДЕ`, а в скобках виртуальной таблицы |
| Простые условия | `Измерение = Значение` |
| Подзапросы | Одна таблица, без соединений, без RLS |
| Временные таблицы | Без секции `ГДЕ` в подзапросе |
| Много условий | Одно в параметрах, остальные снаружи |
