# #std455 Структура модуля

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Разделы модуля

### 1.1. Общий порядок разделов

1. Заголовок модуля
2. Раздел описания переменных
3. Программный интерфейс (экспортные процедуры и функции)
4. Обработчики событий объекта (формы)
5. Служебные процедуры и функции
6. Раздел инициализации

> Некоторые разделы могут отсутствовать в модулях определённого вида.

### 1.2. Объёмные разделы

Рекомендуется разбивать на подразделы **по функциональному признаку**.

### 1.3. Оформление разделов

Разделы и подразделы оформляются в виде **областей** (`#Область`).

### 1.8. Пустые области

❌ В модуле **не должно быть** пустых областей.

---

## 1.4. Шаблон: Общие модули

```1c
#Область ПрограммныйИнтерфейс
// Код процедур и функций
#КонецОбласти

#Область СлужебныйПрограммныйИнтерфейс
// Код процедур и функций
#КонецОбласти

#Область СлужебныеПроцедурыИФункции
// Код процедур и функций
#КонецОбласти
```

| Раздел | Назначение |
|--------|------------|
| ПрограммныйИнтерфейс | Экспортные процедуры для других объектов и внешнего соединения |
| СлужебныйПрограммныйИнтерфейс | Экспортные процедуры только для других подсистем той же библиотеки |
| СлужебныеПроцедурыИФункции | Внутренняя реализация модуля |

## 1.6. Шаблон: Модули форм

```1c
#Область ОписаниеПеременных

#КонецОбласти

#Область ОбработчикиСобытийФормы
// Код процедур и функций
#КонецОбласти

#Область ОбработчикиСобытийЭлементовШапкиФормы
// Код процедур и функций
#КонецОбласти

#Область ОбработчикиСобытийЭлементовТаблицыФормы<ИмяТаблицыФормы>
// Код процедур и функций
#КонецОбласти

#Область ОбработчикиКомандФормы
// Код процедур и функций
#КонецОбласти

#Область СлужебныеПроцедурыИФункции
// Код процедур и функций
#КонецОбласти
```

| Раздел | Назначение |
|--------|------------|
| ОбработчикиСобытийФормы | ПриСозданииНаСервере, ПриОткрытии и т.п. |
| ОбработчикиСобытийЭлементовШапкиФормы | Элементы вне таблиц |
| ОбработчикиСобытийЭлементовТаблицыФормы | Для каждой таблицы — свой раздел |
| ОбработчикиКомандФормы | Обработчики свойства Действие команд формы |

## 2. Требования к разделам

### 2.1. Заголовок модуля

Комментарий в самом начале модуля с кратким описанием и условиями применения.

```1c
////////////////////////////////////////////////////////////////////////////////
// Клиентские процедуры и функции общего назначения:
// - для работы со списками в формах;
// - для работы с журналом регистрации;
// - прочее.
////////////////////////////////////////////////////////////////////////////////
```

Для модулей форм — рекомендуется описание параметров формы.

### 2.2. Раздел описания переменных

Все переменные модуля **должны быть снабжены комментарием**.

```1c
#Область ОписаниеПеременных

Перем ВалютаУчета;   // Валюта регламентированного учета
Перем АдресПоддержки; // Email адрес службы поддержки

#КонецОбласти
```

### 2.3. Программный интерфейс

Экспортные процедуры размещаются **сразу после переменных** — на «видном месте».

❌ Не помещать в этот раздел экспортные процедуры, которые вызываются **только из форм того же объекта**.

### 2.4. Обработчики событий форм

> ℹ️ Методическая рекомендация

- Обработчики одного элемента располагать **вместе**
- Порядок — как в панели свойств конфигуратора
- У каждого события — **своя процедура-обработчик**

**❌ Неправильно:**

```1c
&НаКлиенте
Процедура ПоИсполнителюПриИзменении(Элемент)
    // ... код установки отбора
КонецПроцедуры

&НаКлиенте
Процедура ПоАвторуПриИзменении(Элемент)
    ПоИсполнителюПриИзменении(Неопределено); // вызов другого обработчика!
КонецПроцедуры
```

**✅ Правильно:**

```1c
&НаКлиенте
Процедура ПоИсполнителюПриИзменении(Элемент)
    УстановитьОтбор();
КонецПроцедуры

&НаКлиенте
Процедура ПоАвторуПриИзменении(Элемент)
    УстановитьОтбор();
КонецПроцедуры

&НаСервере
Процедура УстановитьОтбор()
    // ... код установки отбора
КонецПроцедуры
```

### 2.5. Обработчики событий объекта/менеджера

> ℹ️ Методическая рекомендация: располагать в порядке описания встроенного языка.

### 2.6. Служебные процедуры и функции

- Группировать **по функциональному признаку**
- ❌ **Не группировать** по &НаКлиенте / &НаСервере — это затрудняет понимание логики

### 2.7. Раздел инициализации

```1c
#Область Инициализация

АдресПоддержки = "v8@1c.ru";
ВыполнитьИнициализацию();

#КонецОбласти
```

## Сводка

| Правило | Требование |
|---------|------------|
| Порядок разделов | Переменные → Интерфейс → Обработчики → Служебные → Инициализация |
| Оформление | Области `#Область` / `#КонецОбласти` |
| Пустые области | ❌ Запрещены |
| Переменные | Обязательный комментарий |
| Обработчики событий | Каждому событию — своя процедура |
| Группировка служебных | По функционалу, не по &НаКлиенте/&НаСервере |
