# #std697 Использование предопределенных элементов

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

> *Действует для платформы 1С:Предприятие 8.3.3 и выше без режима совместимости с версией 8.2*

---

## 1. Автоматическое создание

### 1.1. Возможности

В справочниках, планах счетов, планах видов характеристик и планах видов расчета предопределённые элементы можно создавать **автоматически** или **программно**.

### 1.2. Рекомендация по умолчанию

✅ В большинстве случаев — создавать **автоматически**.

**Примеры:**
- Предопределённая страна `Россия` в справочнике `СтраныМира`
- Предопределённый профиль групп доступа `Администратор`

**Настройка:**
- Свойство `ОбновлениеПредопределенныхДанных` = **Авто** (по умолчанию)
- Не вызывать программно `УстановитьОбновлениеПредопределенныхДанных`

### 1.3. Запрет удаления пользователями

⛔ Во всех ролях должны быть **выключены** права (по умолчанию выключены):
- `ИнтерактивноеУдалениеПредопределенныхДанных`
- `ИнтерактивнаяПометкаУдаленияПредопределенныхДанных`
- `ИнтерактивноеСнятиеПометкиУдаленияПредопределенныхДанных`
- `ИнтерактивноеУдалениеПомеченныхПредопределенныхДанных`

## 2. Особенности РИБ

> *Область применения (уточнение): управляемое приложение, обычное приложение.*

### 2.1. Дочерние узлы РИБ

В дочерних узлах РИБ предопределённые элементы **автоматически не создаются** — они должны быть переданы из главного узла вместе с изменениями конфигурации.

**Требования:**

| Требование | Описание |
|------------|----------|
| а) Порядок загрузки | Загружать сообщение обмена **до** выполнения прикладного кода, обращающегося к предопределённым элементам |
| б) Логика загрузки | В `ПриПолученииДанныхОтГлавного` и правилах регистрации — **избегать** обращений к предопределённым элементам |
| в) Обработчики обновления | Не выполнять в подчинённых узлах РИБ |

**Пример проверки в обработчике обновления:**

```1c
Если ПланыОбмена.ГлавныйУзел() = Неопределено Тогда
    // заполняем предопределённые элементы
    // ...
КонецЕсли;
```

> При использовании БСП версии 2.1.4+ требования (а) и (б) снимаются.

### 2.2. Таблицы вне плана обмена РИБ

Для таблиц с предопределёнными элементами, которые **не входят** в состав плана обмена РИБ:

✅ Свойство `ОбновлениеПредопределенныхДанных` = **ОбновлятьАвтоматически**

⚠️ Значение `Авто` не подходит — для подчинённого узла это означает `НеОбновлятьАвтоматически`.

## 3. Условное создание предопределённых элементов

### 3.1. Когда применять

Когда наличие предопределённых элементов **зависит от условия**:
- Включённой функциональной опции
- Режима работы программы

**Пример:** Виды расчетов в плане `Начисления` зависят от опций `ИспользоватьУчетВремениСотрудниковВЧасах`, `ИспользоватьСдельныйЗаработок`.

### 3.2. Настройка

- Свойство `ОбновлениеПредопределенныхДанных` = **Не обновлять автоматически**
- Код создания (и пометки недействительным) в зависимости от бизнес-логики

**Пример программного создания:**

```1c
Если ПолучитьФункциональнуюОпцию("ИспользоватьУчетВремениСотрудниковВЧасах") Тогда
    НачислениеОбъект = ПланыВидовРасчета.Начисления.СоздатьВидРасчета();
    НачислениеОбъект.ИмяПредопределенныхДанных = "ОкладПоЧасам";
    // ...
    НачислениеОбъект.Записать();
КонецЕсли;
```

### 3.3. Учёт отсутствия элементов

⚠️ В прикладном коде учитывать **отсутствие** предопределённых элементов в ИБ.

**Проблема:** При обращении к несуществующему элементу — исключение:

```1c
// ⛔ Вызовет исключение, если элемент не существует
... = ПланВидовРасчета.Начисления.ОкладПоЧасам;
... = ПредопределенноеЗначение("ПланВидовРасчета.Начисления.ОкладПоЧасам");
```

**Решение (БСП 2.1.4+):**

```1c
// ✅ Вернёт Неопределено, если элемент не существует
... = ОбщегоНазначенияКлиент.ПредопределенныйЭлемент("ПланВидовРасчета.Начисления.ОкладПоЧасам");
```

## 4. Сводная таблица

| Ситуация | ОбновлениеПредопределенныхДанных | Примечание |
|----------|----------------------------------|------------|
| Стандартный случай | Авто | По умолчанию |
| Таблица вне РИБ | ОбновлятьАвтоматически | Для подчинённых узлов |
| Зависит от условий | Не обновлять автоматически | Программное создание |
