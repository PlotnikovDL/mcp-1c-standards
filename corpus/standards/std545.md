# #std545 Обращение из кода к пользовательским элементам управления формы

> Область применения: управляемое приложение.
>
> Раздел ИТС: Разработка пользовательских интерфейсов / Реализация работы формы
>
> Источник: https://its.1c.ru/db/v8std/content/545/hdoc
>
> Проверено по источнику: 2026-10-07

<table><tbody><tr><td> <p style="text-align: right"><em>Методическая рекомендация (полезный совет)</em></p> <p>При разработке логики работы формы следует иметь в виду, что если пользователь в режиме <strong>1С:Предприятия</strong> добавляет какие-либо элементы формы (<strong>Все действия - Изменить форму</strong>), то обращение к таким элементам из встроенного языка невозможно.</p> <p>Например, если в элемент формы <strong>Группа</strong> вида <strong>Страницы</strong> пользователь добавил страницу, то при переходе на эту страницу, свойство группы <strong>ТекущаяСтраница</strong> станет равно <strong>Неопределено</strong>. Свойство формы <strong>ТекущийЭлемент</strong> также будет содержать значение <strong>Неопределено</strong> в том случае, когда активным элементом формы является элемент, добавленный пользователем.</p> <p>Например, вместо непосредственного обращения к свойствам элементов группы со страницами:</p> <pre data-code-id="code-0001">ИмяТекущейСтраницы = Элементы.ГруппаСоСтраницами.ТекущаяСтраница.Имя;</pre> <p>следует предварительно выполнять проверку на <strong>Неопределено</strong>:</p> <pre data-code-id="code-0002">ТекущаяСтраница = Элементы.ГруппаСоСтраницами.ТекущаяСтраница;&#10;ИмяТекущейСтраницы = ?(ТекущаяСтраница &lt;&gt; Неопределено, ТекущаяСтраница.Имя, "");</pre> <h3>См. также</h3> <ul><li><a href="https://its.1c.ru/db/v8std/content/536/hdoc">Обращение из кода к автоматически формируемым элементам управления формы</a></li></ul></td></tr></tbody></table>
