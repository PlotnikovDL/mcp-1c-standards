# #std764 Строковые константные выражения в коде: требования по локализации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Внутренние строковые идентификаторы

**Не локализуются** строковые константы с внутренними идентификаторами, которые не выводятся пользователям. К ним **не следует** применять функцию **НСтр**.

**Требование:** Такие строковые идентификаторы должны именоваться по правилам именования идентификаторов переменных встроенного языка.

### Примеры корректных идентификаторов

```1c
Возврат "ОперацияВыполненаУспешно";
Оповестить("ЗаписьФайл", Новый Структура("Событие", "ВерсияСохранена"), ФайлСсылка);
```

### Правила именования

❌ **Неправильно** — идентификатор похож на текст для пользователя:

```1c
Если Статус = "Отгрузка клиентам" Тогда ...
```

✅ **Правильно** — идентификатор по правилам именования переменных:

```1c
Если Статус = "ОтгрузкаКлиентам" Тогда ...
```

**Важно:** Это требование распространяется и на использование идентификаторов в текстах запросов и в выражениях СКД.

### Функции для строковых констант

При использовании в коде строковых констант можно и даже **предпочтительно** применять функции, возвращающие эти строковые константы. Такой подход упрощает отладку и рефакторинг кода.

✅ **Правильно:**

```1c
РезультатЗагрузки = ЗагрузитьФайлИзИнтернета(...);
Если РезультатЗагрузки = РезультатЗагрузкиУспешно() Тогда
...
ИначеЕсли ...

Функция РезультатЗагрузкиУспешно()
  Возврат "Успешно";
КонецФункции
```

**Преимущество:** Устраняется неоднозначность, когда идентификатор визуально выглядит в коде как строка, выводимая пользователю, но без необходимого **НСтр**.

## 2. Запрет использования представлений объектов и типов

В алгоритмах программы **не следует** использовать представления объектов и типов.

**Причины:**
- Строковые представления предназначены **только для вывода пользователю**
- Они могут различаться в зависимости от текущего языка программы
- Их использование приводит к ошибкам при локализации конфигурации
- Приводит к ошибкам при интеграции с системами на других языках

### 2.1. Предопределённые значения на клиенте

Для получения предопределённого значения на клиенте следует указывать его **строковое имя**, как оно указано в конфигураторе.

❌ **Неправильно:**

```1c
Если Строка(ЮрФизЛицо) = "Юридическое лицо" Тогда
```

✅ **Правильно:**

```1c
Если ЮрФизЛицо = ПредопределенноеЗначение("Перечисление.ЮридическоеФизическоеЛицо.ЮридическоеЛицо") Тогда
```

## Сводка

| Тип строки | Локализация | Пример |
|------------|-------------|--------|
| Внутренний идентификатор | Не требуется | `"ОтгрузкаКлиентам"` |
| Текст для пользователя | Требуется НСтр | `НСтр("ru='Отгрузка клиентам'")` |
| Предопределённое значение | Имя из конфигуратора | `ПредопределенноеЗначение("...")` |

| Правило | Описание |
|---------|----------|
| Именование идентификаторов | По правилам переменных встроенного языка |
| Функции-обёртки | Предпочтительны для строковых констант |
| Представления объектов | Не использовать в алгоритмах |
| Предопределённые значения | Через `ПредопределенноеЗначение()` |
