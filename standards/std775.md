# #std775 Безопасность программного обеспечения, вызываемого через открытые интерфейсы

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Общий принцип

При использовании интеграции со сторонними приложениями с помощью открытых интерфейсов (в частности, COM) требуется **отключать исполнение произвольного кода** средствами вызываемого приложения.

---

## 2. Открытие документов Microsoft Office

Перед программным открытием документов Microsoft Word и Microsoft Excel через COM следует **запрещать исполнение макросов**.

**Причина:** вредоносные макросы (вирусы) в документе могут выполниться автоматически.

### 2.1. Microsoft Word

❌ **НЕПРАВИЛЬНО** — открытие документа по умолчанию:

```1c
ОбъектWord = Новый COMОбъект("Word.Application");
Документ = ОбъектWord.Documents.Open(ИмяФайла);
```

✅ **ПРАВИЛЬНО** — открытие с отключением макросов:

```1c
ОбъектWord = Новый COMОбъект("Word.Application");
ОбъектWord.WordBasic.DisableAutoMacros(1);
Документ = ОбъектWord.Documents.Open(ИмяФайла);
```

### 2.2. Microsoft Excel

✅ **ПРАВИЛЬНО** — открытие с отключением макросов:

```1c
ОбъектExcel = Новый COMОбъект("Excel.Application");
ОбъектExcel.AutomationSecurity = 3; // msoAutomationSecurityForceDisable = 3
Документ = ОбъектExcel.Workbooks.Open(ИмяФайла);
```

## 3. Если макросы всё же необходимы

Если при программном открытии документов Microsoft Office необходимо разрешить выполнение автоматически запускающихся макросов:

### 3.1. Формы настройки безопасности

Реализовать **отдельные формы настроек** для клиентского и серверного кода:

| Вариант | Описание |
|---------|----------|
| Запретить автоматический запуск | Макросы не выполняются |
| Разрешить запуск подписанных макросов | **По умолчанию (рекомендуется)** |
| Разрешить запуск не подписанных макросов | ⚠️ Опасно |

### 3.2. Разграничение доступа к настройкам

| Контекст | Доступ | Хранение |
|----------|--------|----------|
| Клиентский код | Каждый пользователь | В разрезе пользователей |
| Серверный код | Только администратор | Общие настройки |

### 3.3. Проверка подписи в Microsoft Word

```1c
ОбъектWord = Новый COMОбъект("Word.Application");
ОбъектWord.WordBasic.DisableAutoMacros(1); // Отключить автозапуск
Документ = ОбъектWord.Documents.Open(ФайлДокумента);

Если Документ.VBASigned Тогда
  ОбъектWord.WordBasic.DisableAutoMacros(0); // Включить автозапуск
  Документ.RunAutoMacro(2); // wdAutoOpen = 2
Иначе
  Документ.Close();
  ВызватьИсключение НСтр("ru = 'Документ не подписан. Открытие отменено.'");
КонецЕсли;
```

### 3.4. Проверка подписи в Microsoft Excel

```1c
ОбъектExcel = Новый COMОбъект("Excel.Application");
ИсходныйУровеньБезопасности = ОбъектExcel.AutomationSecurity;
ОбъектExcel.AutomationSecurity = 3; // msoAutomationSecurityForceDisable = 3
Документ = ОбъектExcel.Workbooks.Open(ФайлДокумента);
ОбъектExcel.AutomationSecurity = ИсходныйУровеньБезопасности;

Если Документ.VBASigned Тогда
  Документ.Close();
  Документ = ОбъектExcel.Workbooks.Open(ФайлДокумента);
Иначе
  Документ.Close();
  ВызватьИсключение НСтр("ru = 'Документ не подписан. Открытие отменено.'");
КонецЕсли;
```

## Сводка

| Приложение | Метод отключения макросов |
|------------|---------------------------|
| Microsoft Word | `ОбъектWord.WordBasic.DisableAutoMacros(1)` |
| Microsoft Excel | `ОбъектExcel.AutomationSecurity = 3` |

| Свойство | Назначение |
|----------|------------|
| `VBASigned` | Проверка наличия цифровой подписи макросов |

| Константа | Значение | Описание |
|-----------|----------|----------|
| `msoAutomationSecurityForceDisable` | 3 | Принудительное отключение макросов |
| `wdAutoOpen` | 2 | Автоматически запускаемый макрос при открытии |
