# #std454 Правила образования имен переменных

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Имена из предметной области

Имена переменных следует образовывать от **терминов предметной области** так, чтобы из имени было понятно назначение переменной.

---

## 2. Правила написания (PascalCase)

- Удалять пробелы между словами
- Каждое слово с **прописной буквы**
- Предлоги и местоимения из одной буквы — тоже **прописными**

**✅ Правильно:**

```1c
Перем ДиалогРаботыСКаталогом;     // Диалог работы с каталогом
Перем КоличествоПачекВКоробке;    // Количество пачек в коробке
```

**❌ Неправильно** — сокращения, непонятные имена:

```1c
масРеквизитов, соотвВидИмя, новСтр
```

---

## 3. Запрет подчёркивания в начале

❌ Имена переменных **запрещается** начинать с подчёркивания.

---

## 4. Односимвольные имена

❌ Имена переменных **не должны** состоять из одного символа.

**Исключение:** счётчики циклов (`Для Индекс = ...`).

---

## 5. Имена флагов (булевых переменных)

Переменные-флаги называть так, как пишется **истинное значение** флага.

**✅ Правильно:**

```1c
Перем ЕстьОшибки;     // Признак наличия ошибок в процедуре
Перем ЭтоТоварТара;   // Признак, что товар относится к возвратной таре
```

---

## Сводка

| Правило | Требование |
|---------|------------|
| Источник имён | Термины предметной области |
| Стиль | PascalCase (КаждоеСловоСБольшой) |
| Предлоги в/с/к/о | Прописными: `РаботаСФайлом` |
| Сокращения | ❌ Запрещены |
| Начало с `_` | ❌ Запрещено |
| Односимвольные | ❌ Только для счётчиков |
| Флаги | Имя = истинное состояние: `ЕстьОшибки`, `ЭтоДокумент` |
