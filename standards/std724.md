# #std724 Использование модулей с повторным использованием возвращаемых значений

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Назначение

Общие модули с повторным использованием возвращаемых значений (кэш) предназначены для кэширования результатов работы функций — на время сеанса или на время вызова.

**Применять для:**
- Экономии вычислительных ресурсов сервера
- Минимизации клиент-серверного взаимодействия

---

## 2. Ограничения применения

Чрезмерное применение кэша может приводить к **излишнему потреблению памяти**.

### 2.1. Не кэшировать быстровычисляемые данные

**Недопустимо** кэшировать данные, вычисление которых выполняется быстрее получения из кэша.

**❌ Неправильно** (в модуле с повторным использованием):

```1c
Функция ИмяПакетаУправления() Экспорт
    Возврат "ManagementPackage";
КонецФункции
```

**Имеет смысл кэшировать:**
- Данные из базы данных
- Данные из внешних источников
- Результаты сложных (ресурсоёмких) вычислений

> **Примечание:** константы примитивных типов часто не стоит кэшировать — они привносят незначительную долю от общего времени операции.

### 2.2. Кэшировать только часто используемые данные

Кэш не хранит данные вечно:
- Удаление через **20 минут** после вычисления
- Или через **6 минут** после последнего использования
- При нехватке памяти, перезапуске процесса, переключении клиента

### 2.3. Узкий диапазон входных параметров

Диапазон значений входных параметров функций **не должен быть широким**.

**Пример проблемы:** функция получает контрагента. Если контрагентов много и вероятность повторного обращения низкая — ресурсы потрачены впустую.

---

## 3. Не изменять данные из кэша

**Не следует** изменять данные, полученные из кэша — возможны скрытые ошибки и расходование памяти.

Кэш возвращает **ссылку на объект в памяти**, а не копию.

**Рекомендуется** возвращать неизменяемые типы:
- `ФиксированныйМассив`
- `ФиксированнаяСтруктура`
- `ФиксированноеСоответствие`

---

## 4. Внутренние вызовы не кэшируются

Если функции модуля вызывают друг друга, результат внутренних вызовов **не кэшируется**.

**❌ Неправильно:**

```1c
Функция ЭтоАвтономноеРабочееМесто() Экспорт
    Возврат АвтономнаяРаботаПоддерживается() И ...;
КонецФункции
```

**✅ Правильно** — явно указать имя модуля:

```1c
Функция ЭтоАвтономноеРабочееМесто() Экспорт
    Возврат ОбменДаннымиПовтИсп.АвтономнаяРаботаПоддерживается() И ...;
КонецФункции
```

---

## 5. Запрещённые типы возвращаемых значений

Для модулей с повторным использованием **«На время сеанса»** нельзя возвращать:

- `МенеджерВременныхТаблиц`
- `Запрос`
- Объекты базы данных (`ДокументОбъект`, `ОтчетОбъект` и т.п.)

Ни непосредственно, ни в составе коллекций.

> Ограничение вызвано тем, что значения этих типов допустимо использовать только в том же серверном вызове.

---

## Сводка

| Что кэшировать | Рекомендация |
|----------------|--------------|
| Строковые константы | ❌ Не кэшировать |
| Константы примитивных типов | ❌ Обычно не стоит |
| Данные из БД (часто используемые) | ✅ Кэшировать |
| Сложные вычисления | ✅ Кэшировать |
| Данные с широким диапазоном параметров | ❌ Не кэшировать |

| Правило | Описание |
|---------|----------|
| Возвращаемые значения | Использовать `Фиксированный*` типы |
| Внутренние вызовы | Указывать полное имя модуля |
| Изменение данных | ❌ Запрещено |
