# #std465 Обработчик события ПриЗаписи

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.
>
> Раздел ИТС: Создание и изменение объектов метаданных / Обработчики событий объектов
>
> Источник: https://its.1c.ru/db/v8std/content/465/hdoc
>
> Проверено по источнику: 2026-10-07

<a id="1"></a>1\. В данном обработчике модуля объекта (набора записей, значения константы; далее - "объект"), как правило, выполняются действия по записи связанных с объектом данных в других объектах конфигурации, а также выполняются другие действия, связанные с изменением объекта. <br>

<br>

Запрещается в данном обработчике изменять содержимое записываемого объекта, поскольку на момент выполнения обработчика, объект уже записан в БД.

<a id="2"></a>2\. Все действия в процедуре-обработчике события **ПриЗаписи** должны выполняться после [проверки на **ОбменДанными.Загрузка**](<https://its.1c.ru/db/v8std/content/773/hdoc>).
