# #std794 Ограничения на использование внешних ресурсов

> Область применения: управляемое приложение, обычное приложение.
>
> Раздел ИТС: Общие вопросы безопасности
>
> Источник: https://its.1c.ru/db/v8std/content/794/hdoc
>
> Проверено по источнику: 2026-10-07

<a id="1"></a>1\. В целях безопасности и гибкости следует, когда возможно, использовать средства платформы вместо внешних компонент, приложений операционной системы, COM. Например, рекомендуется перейти на использование метода платформы **ВызватьПаузу** во всех местах, где возможно, вместо средств ОС, внешних компонент и COM.

<a id="2"></a>2\. При использовании **Библиотеки стандартных подсистем (БСП)** для упрощения настройки профилей безопасности следует использовать подсистему [**Профили безопасности**](<https://its.1c.ru/db/bsp3111doc/content/2970/hdoc>).

Требуемые внешние ресурсы необходимо перечислить в переопределяемом модуле **РаботаВБезопасномРежимеПереопределяемый**. Это могут быть как статические ресурсы, постоянно необходимые для работы приложения, так и ресурсы, востребованность которых определяется включением определенных функциональных опций, настройками интеграции и т.п.

При включении и выключении функции приложения, которая предполагает работу с внешними ресурсами, необходимо предварительно запрашивать у администратора разрешение на включение/выключение доступа к ним. Для этого предусмотрен программный интерфейс в общем модуле **РаботаВБезопасномРежимеКлиент**.
