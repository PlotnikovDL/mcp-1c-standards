# #std733 Эффективное обращение к виртуальной таблице «Остатки»

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Общие принципы

При обращении к виртуальной таблице платформа генерирует запрос к СУБД с **вложенным запросом**.

**Самый эффективный** вложенный запрос для чтения остатков — чтение хранимой таблицы текущих остатков **без группировки** по измерениям.

---

## 2. Условия для оптимального запроса

Платформа сгенерирует оптимальный запрос, если выполнены **все** условия:

| Условие | Описание |
|---------|----------|
| Без даты | Получение остатков **без указания даты** |
| Без разделения итогов | Не используется режим разделения итогов (см. #std664, #std663) |
| Все измерения | Внешний запрос использует **все измерения** (в `ВЫБРАТЬ` или в условиях соединения) |

⚠️ При отключении разделения итогов может снижаться параллельность записи в регистр.

---

## 3. Пример

**Задача:** Регистр `ОстаткиТовара` с измерениями `Склад` и `Номенклатура`. Нужен список номенклатуры с количеством на конкретном складе.

### ❌ Неправильно

```1c
ВЫБРАТЬ
    СпрНоменклатура.Ссылка КАК Товар,
    ЕСТЬNULL(ОстаткиТоваров.Остаток, 0) КАК Остаток
ИЗ
    Справочник.Номенклатура КАК СпрНоменклатура
    ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ОстаткиТоваров.Остатки(&СегодняшняяДата, Склад = &Склад) КАК ОстаткиТоваров
    ПО ОстаткиТоваров.Номенклатура = СпрНоменклатура.Ссылка
```

**Проблемы:**
- Передана дата → используются таблицы остатков **и движений**
- Измерение `Склад` не в внешнем запросе → вложенный запрос будет с **группировкой**

### ✅ Правильно

```1c
ВЫБРАТЬ
    СпрНоменклатура.Ссылка КАК Товар,
    ЕСТЬNULL(ОстаткиТоваров.Остаток, 0) КАК Остаток
ИЗ
    Справочник.Номенклатура КАК СпрНоменклатура
    ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ОстаткиТоваров.Остатки(, Склад = &Склад) КАК ОстаткиТоваров
    ПО ОстаткиТоваров.Номенклатура = СпрНоменклатура.Ссылка
        И ОстаткиТоваров.Склад = &Склад
```

**Исправления:**
- Убрана дата (текущие остатки и так без даты)
- Добавлено условие `Склад` в `ПО` — все измерения использованы

---

## 4. Сводка

| Что делать | Зачем |
|------------|-------|
| Не указывать дату для текущих остатков | Избежать обращения к таблице движений |
| Все измерения в внешнем запросе | Избежать группировки во вложенном запросе |
| Учитывать режим разделения итогов | Влияет на план запроса |
