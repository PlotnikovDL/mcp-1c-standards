# 1C Docs

Локальный репозиторий markdown-стандартов разработки 1С.

## Назначение

Стандарты из этого репозитория используются MCP-сервером `mcp-1c-standards` как источник данных для поиска, чтения и подбора релевантных правил разработки.

## Структура

```text
standards/
```

В `standards` хранятся markdown-файлы стандартов. Текущий путь, на который настроен `mcp-1c-standards`:

```text
C:\projects\1c-tools\1c-docs\standards
```

## Связанные инструменты

- `C:\projects\1c-tools\mcp-1c-standards` - MCP-сервер семантического поиска по этим стандартам.
- `C:\projects\1c-tools\mcp-1c-standards\.cache` - технический кэш embeddings, который не хранится в этом репозитории и пересобирается автоматически.
