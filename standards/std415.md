# #std415 Ограничения на использование ключевого слова «РАЗРЕШЕННЫЕ» в запросах

> Область применения: управляемое приложение, обычное приложение.

---

## Проблема

Использование ключевого слова `РАЗРЕШЕННЫЕ` во всех запросах с целью «нормальной работы пользователя без нарушения прав доступа» может привести к **искажению данных**, полученных в результате выполнения запроса.

Для корректной работы бизнес-логики различным подсистемам необходимо предоставить доступ **ко всей требуемой информации**, а не к ограниченной.

---

## Примеры

### ❌ Когда РАЗРЕШЕННЫЕ недопустимо

**Пример: себестоимость товаров**

Если использовать `РАЗРЕШЕННЫЕ` в запросах механизмов определения списания себестоимости товаров при отгрузке со склада, то себестоимость списания **одного пользователя может отличаться** от себестоимости другого.

**Правильное решение:**
- Либо разрешить пользователю чтение информации для корректного отражения хозяйственной операции
- Либо прекратить выполнение операции с сообщением о нарушении прав доступа

### ✅ Когда РАЗРЕШЕННЫЕ допустимо

**Пример: контактная информация**

Если у пользователя отсутствует доступ к контактной информации контактных лиц контрагентов — пользователь её не увидит.

Данная информация **не задействована** в бизнес-процессах конфигурации. Ограничение доступа к ней **не повлияет** на работу конфигурации в целом.

---

## Принцип

| Ситуация | Рекомендация |
|----------|--------------|
| Данные участвуют в бизнес-логике (расчёты, проведение, учёт) | ❌ Не использовать `РАЗРЕШЕННЫЕ`, поддерживать целостность информации |
| Данные только для отображения, не влияют на бизнес-процессы | ✅ Допустимо использовать `РАЗРЕШЕННЫЕ` |

---

## Сводка

| Аспект | Описание |
|--------|----------|
| **Риск** | Искажение данных, разная бизнес-логика для разных пользователей |
| **Когда запрещено** | Расчёты себестоимости, формирование движений, проверки остатков |
| **Когда допустимо** | Отображение справочной информации, не влияющей на учёт |
| **Альтернатива** | Дать права на чтение или прервать операцию с сообщением об ошибке |
