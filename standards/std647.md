# #std647 Имена процедур и функций

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Общий принцип

Правильный выбор имён **очень важен** для читаемости кода.

Хорошо выбранное имя процедуры + правильные имена параметров = **нет необходимости в дополнительном описании**.

> Если трудно придумать «самодокументирующееся» имя — возможно, процедура **спроектирована неправильно**.

---

## 2. Имена из предметной области

Имена процедур, функций и параметров должны быть образованы от **терминов предметной области**.

**❌ Неправильно:**

```1c
Функция ВыполнитьПроверку(Параметр1, Рекв, ТЗ)
Функция ПолучитьМассивыРеквизитов(ХозяйственнаяОперация, МассивВсехРеквизитов, МассивРеквизитовОперации)
```

**✅ Правильно:**

```1c
Функция РеквизитОбъектаЗаданногоТипа(Объект, ИмяРеквизита, ТипЗначения)
Функция ЗаполнитьИменаРеквизитовПоХозяйственнойОперации(ХозяйственнаяОперация, ИменаВсеРеквизиты, ИменаРеквизитыОперации)
```

---

## 3. Правила написания

- Удалять пробелы между словами
- Каждое слово с **прописной буквы** (PascalCase)
- Предлоги и местоимения из одной буквы — тоже **прописными**

---

## 4. Не указывать типы в именах

> ℹ️ Методическая рекомендация

**❌ Неправильно:**

```1c
Функция ПолучитьМассивРолейСПравомДобавления()
Функция ПолучитьСтруктуруДополнительныхНастроек()
```

**✅ Правильно:**

```1c
Функция ИменаРолейСПравомДобавления()
Функция ДополнительныеНастройки()
```

Исключение: когда без указания типа не ясно назначение процедуры.

---

## 5. Имена процедур — от глагола

Имена процедур образуются от **неопределённой формы глагола** (что делать?).

**❌ Неправильно:**

```1c
Процедура ЗагрузкаКонтрагента()
```

**✅ Правильно:**

```1c
Процедура ЗагрузитьКонтрагента()
```

---

## 6. Имена функций

### 6.1. От описания возвращаемого значения

**❌ Неправильно:**

```1c
Функция ПолучитьПолноеИмяПользователя()
Функция СоздатьПараметрыЗаполненияЦенПоставщика()
Функция ОпределитьДатуНачалаСеанса()
```

**✅ Правильно:**

```1c
Функция ПолноеИмяПользователя()
Функция НовыеПараметрыЗаполненияЦенПоставщика()
Функция ДатаНачалаСеанса()
```

### 6.2. Создание объектов — слово «Новый»

**❌ Неправильно:**

```1c
Функция ДобавитьПолеФормы()
Функция СоздатьЭлементСправочникаФайлы()
Функция ПолучитьТаблицуКоманд()
```

**✅ Правильно:**

```1c
Функция НовоеПолеФормы()
Функция НовыйЭлементСправочникаФайлы()
Функция НоваяТаблицаКоманд()
```

### 6.3. Проверка условий — «Это» или причастия

**❌ Неправильно:**

```1c
Функция ПроверитьПроведенностьДокумента()
Функция ПроверитьИзменениеРеквизитовДокумента()
Функция ВнешняяЗадача()
```

**✅ Правильно:**

```1c
Функция ДокументПроведен()
Функция РеквизитыДокументаИзменены()
Функция ЭтоВнешняяЗадача()
```

### 6.4. Глаголы — когда важен способ получения

Если для понимания назначения важно, **как** было получено значение:

```1c
Функция ВыбратьДанныеПоПравилу(Правило, ПользовательскиеНастройки)
Функция ПреобразоватьДанныеПоПравилу(НаборыДанных, ПараметрыПреобразования)
```

### 6.5. Глаголы — когда действие важнее результата

Если функция **выполняет действие**, а возврат значения (например, признак успеха) — не основная задача:

```1c
Функция РазрешитьРедактированиеРеквизитовОбъекта(Форма)
```

---

## Сводка

| Что | Как называть |
|-----|--------------|
| Процедуры | Глагол: `ЗагрузитьКонтрагента()` |
| Функции (значение) | Описание результата: `ПолноеИмяПользователя()` |
| Функции (создание) | «Новый»: `НоваяТаблицаКоманд()` |
| Функции (проверка) | «Это» / причастие: `ЭтоВнешняяЗадача()`, `ДокументПроведен()` |
| Функции (действие важнее) | Глагол: `РазрешитьРедактирование()` |
| Типы в именах | ❌ Не указывать |
