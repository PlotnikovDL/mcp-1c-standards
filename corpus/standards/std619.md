# #std619 Формы

> Область применения: управляемое приложение.
>
> Раздел ИТС: Проектирование интерфейсов для 8.2 / Формы
>
> Источник: https://its.1c.ru/db/v8std/content/619/hdoc
>
> Проверено по источнику: 2026-10-07

Форма должна быть оптимизирована под клавиатурный ввод :

- Логичный сценарий переходов по клавише Tab.

- Последний переход должен быть на кнопку завершающую сценарий.

- Связанные объекты должны быть расположены так, чтобы переходы по клавише Tab осуществлялся последовательно.<br>

    <span style="color: #536ac2">*Например, переход с выбора партнера на выбор контрагента.*</span>

<br>
