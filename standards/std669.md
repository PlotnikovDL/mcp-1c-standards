# #std669 Ограничение на выполнение «внешнего» кода

> Область применения: управляемое приложение, обычное приложение.

---

## Введение

Помимо кода конфигурации, может исполняться сторонний код через внешние отчёты/обработки, расширения, внешние компоненты и др. Злоумышленник может предусмотреть **деструктивные действия**, которые нанесут вред компьютерам и данным.

**Особенно критично** при работе в модели сервиса — вредоносный код может получить доступ ко всем приложениям всех пользователей.

---

## 1. Запрет выполнения внешнего кода в небезопасном режиме

**Запрещено** выполнение в небезопасном режиме любого кода на сервере, который не является частью конфигурации.

**Исключения:** код, прошедший аудит, и код на клиенте.

### Примеры недопустимого выполнения

| Источник | Описание |
|----------|----------|
| Внешние отчёты и обработки | Печатные формы и т.п. |
| Расширения конфигурации | Подключаемый пользователями код |
| Внешние компоненты | Бинарные модули |
| `Выполнить` / `Вычислить` | Интерактивно введённые алгоритмы |
| Схемы СКД | Изменение пользователями с внешними функциями |

### При использовании БСП

Внешний код подключать **только через подсистемы БСП:**

| Тип кода | Подсистема БСП |
|----------|----------------|
| Расширения конфигурации | «Базовая функциональность» |
| Внешние отчёты и обработки | «Дополнительные отчеты и обработки» |
| Внешние компоненты | «Внешние компоненты» |
| Запуск внешних программ | См. #std774 |

---

## 2. Интерактивное открытие внешних отчётов

**По умолчанию** должна быть отключена возможность открывать внешние отчёты/обработки через меню **Файл → Открыть** для всех категорий пользователей.

**Должна быть возможность** для администратора разрешить это действие с предупреждением об опасности.

---

## 3. Предупреждения об опасности

### 3.1. Для администраторов

Перед подключением любого внешнего кода выводить предупреждение:
- Внешний код из недостоверных источников может нанести вред
- Возможность отказаться от загрузки
- Возможность повторить загрузку после аудита

### 3.2. Для остальных пользователей

**Не показывать** дополнительных предупреждений при исполнении кода, подключение которого подтверждено администратором.

Для программного отключения: `РежимБезопасности` и `УстановитьБезопасныйРежим()`.

---

## 4. Обновление конфигурации

Если предусмотрены средства обновления (.cf, .cfu), восстановления из резервной копии или загрузки из dt-файла:

| Требование | Описание |
|------------|----------|
| Только администратор | Роль «Администратор системы» |
| Только интерактивно | Текущим пользователем, не служебным |
| Предупреждение | Убедиться, что файл из надёжного источника |
| Защищённое соединение | При обновлении через Интернет |

---

## 5. Загрузка произвольных файлов

Файлы могут содержать вредоносный исполняемый код.

**Предусмотреть:**
- Список разрешённых/запрещённых расширений (для администратора)
- Блокирование открытия исполняемых файлов из программы

При использовании БСП — подсистема «Работа с файлами».

---

## 6. Безопасность внешних компонент

### 6.1. Общие требования

- Не загружать из недоверенных источников
- Пользователи без прав администратора **не должны** загружать/устанавливать/подключать компоненты на сервере
- На клиенте — всегда спрашивать пользователя

### 6.2. Хранение

Сторонние компоненты хранить в **отдельном справочнике** с доступом на запись только у администратора.

**Подключать только по навигационной ссылке** на реквизит справочника.

**Не подключать** по имени файла или идентификатору программы — возможна подмена.

### 6.3. Компоненты в составе конфигурации

Хранить в макетах типа **«Внешняя компонента»**.

### 6.4. При использовании БСП

**Исключить** прямое использование платформенных методов:
- `ПодключитьВнешнююКомпоненту`
- `НачатьУстановкуВнешнейКомпоненты`
- `УстановитьВнешнююКомпоненту`
- `НачатьПодключениеВнешнейКомпоненты`
- `ЗагрузитьВнешнююКомпоненту`

**Использовать:**

```1c
// На клиенте (из макета)
ОбщегоНазначенияКлиент.ПодключитьКомпонентуИзМакета()

// На сервере (из макета)
ОбщегоНазначения.ПодключитьКомпонентуИзМакета()

// Из хранилища внешних компонент
ВнешниеКомпонентыКлиент.ПодключитьКомпоненту()
```

---

## 7. Защищённое соединение

При загрузке кода из внешних источников:
- Использовать только надёжные источники
- Передавать данные **только по защищённым каналам**
- Проверять подлинность сервера

```1c
ЗащищенноеСоединение = Новый ЗащищенноеСоединениеOpenSSL(,
  Новый СертификатыУдостоверяющихЦентровОС);
Соединение = Новый HTTPСоединение(Сервер,,,,,, ЗащищенноеСоединение);
```

**При использовании БСП:**

```1c
ЗащищенноеСоединение = ОбщегоНазначенияКлиентСервер.НовоеЗащищенноеСоединение();
Соединение = Новый HTTPСоединение(Сервер,,,,,, ЗащищенноеСоединение);
```

## 8. Регламентные задания

По умолчанию регламентные задания запускаются **под полными правами**. Установка безопасного режима не уменьшает права.

**Требуется** ограничить права в сеансе регламентного задания — создать служебного пользователя с ограниченными правами.

### Варианты ограничения

| Вариант | Описание |
|---------|----------|
| а) Пустой список ролей | Чтение/изменение в привилегированном режиме, вычисление — в безопасном |
| б) Реальный пользователь | Для одноразовых заданий |
| в) Специальные роли | Только для чтения нужных таблиц |

**При использовании БСП (вариант а):**

```1c
// В начале обработчика регламентного задания
РегламентныеЗаданияСервер.УстановитьСлужебногоПользователяРегламентногоЗадания()
```

---

## Сводка

| Угроза | Защита |
|--------|--------|
| Внешний код на сервере | Только через подсистемы БСП, в безопасном режиме |
| Интерактивное открытие обработок | Отключено по умолчанию |
| Подключение внешнего кода | Предупреждение администратору |
| Обновление конфигурации | Только администратор, интерактивно, защищённое соединение |
| Внешние компоненты | Хранить в справочнике, подключать по ссылке |
| Загрузка из Интернета | Защищённое соединение с проверкой сервера |
| Регламентные задания | Служебный пользователь с ограниченными правами |
