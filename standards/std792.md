# #std792 Многократная запись регистров сведений и накопления

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Не записывайте наборы в цикле

❌ Не записывайте наборы записей регистров сведений и накопления **в цикле** по одной или нескольким записям.

Это в **несколько раз медленнее** по сравнению с записью одним набором.

**Рекомендация:** порционная запись наборов из **~1000 записей**.

---

## 2. Избегайте перезаписи больших наборов

❌ Не перезаписывайте большой набор, если меняется **не более 30%** записей.

### Почему это плохо

Перезапись набора = удаление **всех** записей по отбору + вставка **всех** новых (включая неизменённые).

| Последствие | Описание |
|-------------|----------|
| Медленнее | В несколько раз медленнее, чем изменить только разницу |
| Журнал транзакций | Избыточно растёт пропорционально удалениям и вставкам |

✅ Записывайте **только изменения** (добавленные, изменённые, удалённые записи).

---

## 3. Режимы замещения

Для оптимальной записи используйте режимы замещения + вычисление изменений.

| Режим | Параметр метода `Записать()` | Платформа |
|-------|------------------------------|-----------|
| Добавление | `РежимЗамещения = Ложь` | Все версии |
| Слияние | `РежимЗамещения.Слияние` | 8.3.26+ |
| Удаление | `РежимЗамещения.Удаление` | 8.3.26+ |
| Обновление | `РежимЗамещения.Обновление` | 8.3.27+ |

**Добавление** — только для записи в пустой регистр.

## 4. Примеры

### 4.1. Удаление известных записей

**❌ Неправильно** — запись в цикле:

```1c
Для Каждого ЗначениеНастройки Из Настройки Цикл
    УдаляемыеЗаписи = РегистрыСведений.ПользовательскиеНастройки.СоздатьНаборЗаписей();
    УдаляемыеЗаписи.Отбор.ИдентификаторКоманды.Установить(ЗначениеНастройки.ИдентификаторКоманды);
    УдаляемыеЗаписи.Отбор.Пользователь.Установить(ПользовательСсылка);
    УдаляемыеЗаписи.Записать(); // в цикле!
КонецЦикла;
```

**✅ Правильно** — один набор с режимом Удаление:

```1c
УдаляемыеЗаписи = РегистрыСведений.ПользовательскиеНастройки.СоздатьНаборЗаписей();
Для Каждого ЗначениеНастройки Из Настройки Цикл
    УдаляемаяЗапись = УдаляемыеЗаписи.Добавить();
    УдаляемаяЗапись.ИдентификаторКоманды = ЗначениеНастройки.ИдентификаторКоманды;
    УдаляемаяЗапись.Пользователь = ПользовательСсылка;
КонецЦикла;
УдаляемыеЗаписи.Записать(РежимЗамещения.Удаление);
```

### 4.2. Обновление реквизита в обработчике обновления

**❌ Неправильно** — чтение и запись в цикле:

```1c
Для Каждого Данные Из ПорцияЗначенийИзмерений Цикл
    НачатьТранзакцию();
    Попытка
        Блокировка.Заблокировать();
        НаборЗаписей = РегистрыСведений.ДанныеБизнесПроцессов.СоздатьНаборЗаписей();
        НаборЗаписей.Отбор.Владелец.Установить(Данные.Владелец);
        НаборЗаписей.Прочитать();
        // Установка значений...
        ОбновлениеИнформационнойБазы.ЗаписатьНаборЗаписей(НаборЗаписей);
        ЗафиксироватьТранзакцию();
    Исключение
        ОтменитьТранзакцию();
    КонецПопытки;
КонецЦикла;
```

**✅ Правильно** — один запрос + один набор с режимом Обновление:

```1c
Запрос = Новый Запрос;
Запрос.УстановитьПараметр("ПорцияЗначенийИзмерений", ПорцияЗначенийИзмерений);
Запрос.Текст =
    "ВЫБРАТЬ
    |    *,
    |    ЗНАЧЕНИЕ(Перечисление.СостоянияБизнесПроцессов.Активен) КАК Состояние
    |ИЗ
    |    РегистрСведений.ДанныеБизнесПроцессов КАК ДанныеБизнесПроцессов
    |ГДЕ
    |    ДанныеБизнесПроцессов.Состояние = ЗНАЧЕНИЕ(Перечисление.СостоянияБизнесПроцессов.ПустаяСсылка)
    |    И (ДанныеБизнесПроцессов.Владелец) В (&ПорцияЗначенийИзмерений)";

НачатьТранзакцию();
Попытка
    БлокировкаДанных.Заблокировать();
    Выгрузка = Запрос.Выполнить().Выгрузить();
    НаборЗаписей = РегистрыСведений.ДанныеБизнесПроцессов.СоздатьНаборЗаписей();
    НаборЗаписей.Загрузить(Выгрузка);
    ОбновлениеИнформационнойБазы.ЗаписатьНаборЗаписей(НаборЗаписей, РежимЗамещения.Обновление);
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
КонецПопытки;
```

### 4.3. Частичное обновление записей

При обновлении части записей используйте **запрос** для вычисления различий:
- Лишние записи → для удаления
- Недостающие + изменённые → для слияния

**❌ Неправильно** — полная перезапись в цикле:

```1c
Для Каждого ГруппаПользователей Из ГруппыПользователей Цикл
    НаборЗаписей = РегистрыСведений.СоставыГруппПользователей.СоздатьНаборЗаписей();
    НаборЗаписей.Отбор.ГруппаПользователей.Установить(ГруппаПользователей);
    НаборЗаписей.Загрузить(...);
    НаборЗаписей.Записать(); // Замена всех записей!
КонецЦикла;
```

**✅ Правильно** — вычислить различия запросом, записать отдельно удаляемые и добавляемые:

```1c
// Запрос вычисляет:
// - ДляУдаления: записи, которых не должно быть
// - ДляСлияния: записи, которые нужно добавить или обновить

НаборДляУдаления = РегистрыСведений.СоставыГруппПользователей.СоздатьНаборЗаписей();
НаборДляУдаления.Загрузить(ТаблицаДляУдаления);
НаборДляУдаления.Записать(РежимЗамещения.Удаление);

НаборДляСлияния = РегистрыСведений.СоставыГруппПользователей.СоздатьНаборЗаписей();
НаборДляСлияния.Загрузить(ТаблицаДляСлияния);
НаборДляСлияния.Записать(РежимЗамещения.Слияние);
```

## Сводка

| Правило | Рекомендация |
|---------|--------------|
| Запись в цикле | ❌ Избегать |
| Размер порции | ~1000 записей |
| Перезапись большого набора | ❌ Если изменено < 30% |
| Добавление в пустой | `РежимЗамещения = Ложь` |
| Слияние/Обновление | `РежимЗамещения.Слияние`, `.Обновление` (8.3.26+) |
| Удаление списка | `РежимЗамещения.Удаление` (8.3.26+) |
