# #std536 Обращение из кода к автоматически формируемым элементам управления формы

> Область применения: управляемое приложение.
>
> Раздел ИТС: Разработка пользовательских интерфейсов / Реализация работы формы
>
> Источник: https://its.1c.ru/db/v8std/content/536/hdoc
>
> Проверено по источнику: 2026-10-07

Не рекомендуется управлять из кода элементами управления формы, которые автоматически формируются платформой.

При программной установке свойств элементов формы, которые автоматически формируются платформой, необходимо иметь в виду, что в ряде сценариев платформа может пересоздавать такие элементы.

Например, после изменения свойства ОсновнаяТаблица динамического списка командная панель списка будет автоматически перезаполнена, что приведет к потере ранее сделанных изменений свойств кнопок панели.

При наличии подобных изменений программную установку свойств кнопок панели нужно будет выполнить повторно.
