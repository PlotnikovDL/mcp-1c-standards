# #std571 Подсказки для интерфейсных подсистем

> Область применения: управляемое приложение.
>
> Раздел ИТС: Проектирование интерфейсов для 8.2 / Панель разделов
>
> Источник: https://its.1c.ru/db/v8std/content/571/hdoc
>
> Проверено по источнику: 2026-10-07

См. также: [Панель разделов (8.3)<span style="color: #536ac2"></span>](<https://its.1c.ru/db/v8std/content/712/hdoc>)

· Подсказки для ПР не являются обязательными – назначение раздела должно быть однозначно понятно из его названия.<br>

<span style="color: #536ac2">Название раздела должно быть настолько интуитивно понятно, чтобы пользователь, в поисках нужной ему информации, сразу понял, в каком разделе ее следует искать.</span>

· Подсказка может дополнительно расшифровывать содержимое раздела, например, с помощью краткого перечисления входящих в него функции.

· Справка для разделов ПР не является обязательной.
