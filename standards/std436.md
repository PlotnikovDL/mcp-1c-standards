# #std436 Многократное выполнение однотипных запросов

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Общий принцип

Рекомендуется получать все необходимые **однотипные данные одним запросом** вместо серии запросов.

Это **ускоряет** исполнение запроса к базе данных.

### 1.1. Способы объединения

| Способ | Применение |
|--------|------------|
| Условие `В` (IN) | Отбор по списку значений |
| `ОБЪЕДИНИТЬ ВСЕ` | Объединение результатов |
| Пакет запросов | Несколько связанных запросов |

### 1.2. Пример

✅ **Правильно** (один запрос со списком):

```1c
ОбщийЗапрос = Новый Запрос("
    |ВЫБРАТЬ
    |   БанковскиеСчета.Ссылка КАК Счет
    |ИЗ
    |   Справочник.БанковскиеСчета КАК БанковскиеСчета
    |ГДЕ
    |   БанковскиеСчета.Банк В(&БанкиДляОбработки)");

ОбщийЗапрос.УстановитьПараметр("БанкиДляОбработки", БанкиДляОбработки);
ВыборкаСчетов = ОбщийЗапрос.Выполнить().Выбрать();
Пока ВыборкаСчетов.Следующий() Цикл
    ОбработатьСчетаВБанке(ВыборкаСчетов.Счет);
КонецЦикла;
```

❌ **Неправильно** (запрос в цикле):

```1c
ЧастныйЗапрос = Новый Запрос("
    |ВЫБРАТЬ
    |   БанковскиеСчета.Ссылка КАК Счет
    |ИЗ
    |   Справочник.БанковскиеСчета КАК БанковскиеСчета
    |ГДЕ
    |   БанковскиеСчета.Банк = &Банк");

Для каждого Банк Из БанкиДляОбработки Цикл
    ЧастныйЗапрос.УстановитьПараметр("Банк", Банк);
    ВыборкаСчетов = ЧастныйЗапрос.Выполнить().Выбрать();
    Пока ВыборкаСчетов.Следующий() Цикл
        ОбработатьСчетаВБанке(ВыборкаСчетов.Счет);
    КонецЦикла;
КонецЦикла;
```

---

## 2. Использование БСП

При использовании БСП вызывайте функции для **списков объектов**:

| ❌ В цикле | ✅ Один вызов |
|-----------|---------------|
| `ОбщегоНазначения.ЗначениеРеквизитаОбъекта` | `ОбщегоНазначения.ЗначениеРеквизитаОбъектов` |
| `УправлениеКонтактнойИнформацией.КонтактнаяИнформацияОбъекта` | `УправлениеКонтактнойИнформацией.КонтактнаяИнформацияОбъектов` |

---

## 3. Допустимые исключения

Разделение на серию запросов **допускается** в случаях:

### 3.1. Усложнение разработки

Запрос для выбора всех данных сразу **заметно усложняется**.

### 3.2. Деградация производительности

Запрос содержит обращение к виртуальным таблицам на определённую дату:
- Виртуальные таблицы **остатков** регистра накопления
- **Срез последних** периодического регистра сведений
- и т.п.

### 3.3. Порционная обработка больших объёмов

| Сценарий | Примеры |
|----------|---------|
| Обработчики обновления | Отложенное обновление данных |
| Групповые операции | Проведение, изменение, удаление помеченных объектов |
| Контроль ведения учёта | Проверки целостности |
| Загрузка данных | Из файла, внешних источников, получение почты |

### 3.4. Обоснование исключений

В этих случаях запросы в цикле:
- **Необходимы** для порционности
- **Незначительно** замедляют по сравнению с записью данных
- **Неустранимы** на текущих средствах платформы (например, чтение/запись наборов регистра в цикле по измерению)

---

## 4. Запросы к разным таблицам

Запросы к **разным таблицам** также рекомендуется объединять:
- `ОБЪЕДИНИТЬ ВСЕ`
- Пакет запросов

⚠️ Выигрыш во времени может оказаться **незначительным**.

---

## 5. Сводка

| Ситуация | Решение |
|----------|---------|
| Однотипные данные | Один запрос с `В` / `ОБЪЕДИНИТЬ ВСЕ` |
| БСП функции | Версии для списков (`*Объектов`) |
| Виртуальные таблицы с датой | Допустимо в цикле |
| Большие объёмы | Порционная обработка |
| Чтение/запись наборов регистра | Цикл по измерению допустим |
