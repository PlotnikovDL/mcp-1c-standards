# #std396 Обработчик события ОбработкаЗаполнения

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Назначение обработчика

В обработчике `ОбработкаЗаполнения` модуля объекта (набора записей) выполняются:
- Проверки ограничения **ввода на основании** по команде «Создать на основании»
- **Заполнение** реквизитов нового объекта

---

## 2. Ограничение ввода на основании

### 2.1. Примеры проверок

| Ситуация | Проверка |
|----------|----------|
| Группы и элементы | Команда одинаково доступна для групп и элементов — требуется запретить ввод на основании групп |
| Непроведённые документы | Требуется запретить ввод на основании непроведённых документов |

### 2.2. Использование исключений

Для оповещения пользователя о причинах отказа — использовать **исключения**:

```1c
Процедура ОбработкаЗаполнения(ДанныеЗаполнения, ТекстЗаполнения, СтандартнаяОбработка)

    Если ТипЗнч(ДанныеЗаполнения) = Тип("СправочникСсылка.Сотрудники") Тогда
        Если ПолучитьЗначениеРеквизита(ДанныеЗаполнения, "ЭтоГруппа") = Истина Тогда
            ВызватьИсключение "Ввод приказа о приеме на основании группы сотрудников невозможен!
                              |Выберите сотрудника. Для раскрытия группы используйте Ctrl и стрелку вниз";
        КонецЕсли;

        // Обработка заполнения объекта по данным заполнения

    КонецЕсли;

КонецПроцедуры
```

### 2.3. Запрещённые подходы

⛔ **Не рекомендуется:**
- Создавать дополнительные команды для ввода на основании
- Размещать проверки в обработчиках этих команд

---

## 3. Структура обработчика

> *Методическая рекомендация*

Рекомендуется придерживаться следующей структуры (отдельные шаги могут быть пропущены):

### 3.1. Специальное заполнение

Заполнение в зависимости от типа параметра `ДанныеЗаполнения`:

```1c
ТипДанныхЗаполнения = ТипЗнч(ДанныеЗаполнения);

Если ТипДанныхЗаполнения = Тип("Структура") Тогда
    ЗаполнитьДокументПоОтбору(ДанныеЗаполнения);
ИначеЕсли ТипДанныхЗаполнения = Тип("ДокументСсылка.ЗаказКлиента") Тогда
    ЗаполнитьДокументНаОснованииЗаказаКлиента(ДанныеЗаполнения);
// ...
КонецЕсли;
```

### 3.2. Общее заполнение

Заполнение значениями по умолчанию реквизитов, которые **не были заполнены** специальным заполнением.

⚠️ **Важно:** Предварительно проверять реквизит на заполненность:

```1c
Если Не ЗначениеЗаполнено(Подразделение) Тогда
    Подразделение = ЗначениеНастроекПовтИсп.ПодразделениеПоУмолчанию();
КонецЕсли;
```

### 3.3. Свойство «Значение заполнения»

✅ Рекомендуется использовать свойство метаданных **«Значение заполнения»**.

**Поведение:**
- Значение автоматически присваивается реквизиту при выходе из обработчика
- Условие: `СтандартнаяОбработка = Истина` и реквизит не был заполнен в обработчике

## 4. Сводная таблица

| Этап | Действие | Пример |
|------|----------|--------|
| 1 | Проверки ограничений | `ВызватьИсключение` при ошибке |

| 3 | Общее заполнение | Значения по умолчанию с проверкой `ЗначениеЗаполнено()` |
