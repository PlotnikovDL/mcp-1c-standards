# #std606 Команды, размещаемые во "Всех действиях"

> Область применения: управляемое приложение.
>
> Раздел ИТС: Проектирование интерфейсов для 8.2 / Оформление форм списков
>
> Источник: https://its.1c.ru/db/v8std/content/606/hdoc
>
> Проверено по источнику: 2026-10-07

- Рекомендуется использовать умолчание платформы.

- Для отдельных списков допускается индивидуальная настройка командной панели. При этом непосредственно в командной панели формы лучше располагать небольшое количество наиболее частотных команд (не более 10), а остальные размещать во «Все действия».<br>
