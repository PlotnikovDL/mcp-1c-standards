# Правила корпуса стандартов (`corpus/`)

Дополняют правила корня репозитория `mcp-1c-standards` (`../AGENTS.md`); при расхождении действуют более строгие.

## Назначение

- Этот каталог хранит markdown-стандарты разработки 1С (бывший репозиторий `1c-docs`).
- Стандарты используются MCP-сервером `mcp-1c-standards` из этого же репозитория как источник данных.
- Основная папка стандартов: `corpus/standards`.

## Рабочий режим

- Перед изменением файлов кратко описывать, что будет изменено и зачем, затем ждать явного подтверждения пользователя.
- Изменения делать маленькими шагами.
- Не переименовывать, не удалять и массово не форматировать стандарты без отдельного согласования.
- Не коммитить изменения, не менять ветки и не выполнять операции Git с историей без прямой просьбы пользователя.

## Правила для стандартов

- Сохранять стандарты в markdown-формате.
- Сохранять имена файлов стандартов стабильными, если нет отдельной задачи на миграцию имен.
- Не добавлять сюда embeddings, модели, кэши, выгрузки синтакс-помощника или временные результаты обработки.
- После изменения стандартов учитывать, что `mcp-1c-standards` может пересобрать кэш при следующем поиске.

## Проверка

- После изменения стандартов проверить, что нужные `.md` файлы читаются обычным текстом.
- Для проверки через MCP использовать `list_standards`, `read_standard` и при необходимости `search_standards`.
- В финальном ответе кратко указывать, какие проверки запускались.
