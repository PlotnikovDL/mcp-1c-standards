# #std442 Определение типа значения переменной

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.
>
> Раздел ИТС: Соглашения при написании кода / Использование конструкций встроенного языка
>
> Источник: https://its.1c.ru/db/v8std/content/442/hdoc
>
> Проверено по источнику: 2026-10-07

Определение типа значения переменной необходимо выполнять путем его сравнения с типом, а не каким-либо другим методом. <br>

Правильно:

```bsl
Если ТипЗнч(Ссылка) = Тип("ДокументСсылка.ПоступлениеТоваровУслуг") Тогда
```

Неправильно:

```bsl
Если Ссылка.Метаданные().Имя = "ПоступлениеТоваровУслуг" Тогда
```
