# #std794 Ограничения на использование внешних ресурсов

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Предпочтение средств платформы

В целях безопасности и гибкости следует, когда возможно, использовать **средства платформы** вместо:

- Внешних компонент
- Приложений операционной системы
- COM-объектов

### Пример

Рекомендуется перейти на использование метода платформы **`ВызватьПаузу`** во всех местах, где возможно, вместо средств ОС, внешних компонент и COM.

---

## 2. При использовании БСП

### 2.1. Подсистема «Профили безопасности»

Для упрощения настройки профилей безопасности использовать подсистему **«Профили безопасности»**.

### 2.2. Регистрация внешних ресурсов

Требуемые внешние ресурсы необходимо перечислить в переопределяемом модуле:

```
РаботаВБезопасномРежимеПереопределяемый
```

**Типы ресурсов:**

| Тип | Описание |
|-----|----------|
| Статические | Постоянно необходимы для работы приложения |
| Динамические | Востребованность определяется функциональными опциями, настройками интеграции и т.п. |

### 2.3. Запрос разрешений у администратора

При включении и выключении функции приложения, которая предполагает работу с внешними ресурсами, необходимо **предварительно запрашивать** у администратора разрешение на включение/выключение доступа к ним.

**Программный интерфейс:**

```
РаботаВБезопасномРежимеКлиент
```

---

## Сводка

| Рекомендация | Описание |
|--------------|----------|
| Приоритет платформы | Использовать встроенные методы вместо внешних ресурсов |
| `ВызватьПаузу` | Вместо Sleep через COM/ОС |
| Регистрация ресурсов | `РаботаВБезопасномРежимеПереопределяемый` |
| Запрос разрешений | `РаботаВБезопасномРежимеКлиент` |
