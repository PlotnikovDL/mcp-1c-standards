# #std784 Автогенерированные данные в информационной базе: требования по локализации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Язык автогенерируемых строк

Автогенерируемые строки, которые программно записываются в информационную базу и выводятся пользователям, необходимо формировать **не на языке текущего пользователя, а на языке информационной базы**.

### Примеры таких строк

- Начальное заполнение информационной базы данными из макета
- Автогенерация комментария к проводке
- Значение параметра **ИмяСобытия** метода ЗаписьЖурналаРегистрации

### Почему это важно

Если документ провёл пользователь с русскоязычным интерфейсом, а затем тот же документ перепровёл пользователь с англоязычным интерфейсом, то содержание записей регистра бухгалтерии станет другим (что ошибочно).

### Комментарий в коде

Такие места в коде рекомендуется сопровождать комментарием, поясняющим, что строка является данными, а не интерфейсным текстом.

❌ **Неправильно:**

```1c
Комментарий = НСтр("ru = 'Комментарий к проводке'");
```

✅ **Правильно:**

```1c
Комментарий = НСтр("ru = 'Комментарий к проводке'", КодОсновногоЯзыка); // строка записывается в ИБ
```

### Код основного языка

**КодОсновногоЯзыка** — код языка хранения данных в информационной базе, выбранный в момент первого запуска программы из языков интерфейса конфигурации и сохранённый в константе **ОсновнойЯзык**.

### При использовании БСП

При использовании **Библиотеки стандартных подсистем** для получения кода языка для хранения данных следует использовать функцию **КодОсновногоЯзыка** общего модуля **ОбщегоНазначения**.

```1c
Комментарий = НСтр("ru = 'Комментарий к проводке'", ОбщегоНазначения.КодОсновногоЯзыка()); // строка записывается в ИБ
```

## 2. Начальное заполнение предопределённых элементов

Аналогичные требования распространяются на обработчики начального заполнения, заполняющие строковые реквизиты предопределённых элементов справочников, ПВХ и т.п.

✅ **Правильно:**

```1c
Процедура ПриДобавленииОбработчиковОбновления(Обработчики) Экспорт
    Обработчик = Обработчики.Добавить();
    Обработчик.НачальноеЗаполнение = Истина;
    Обработчик.Процедура = "ПользователиСлужебный.ЗаполнитьНаименованиеПредопределенныхГруппПользователей";
КонецПроцедуры

Процедура ЗаполнитьНаименованиеПредопределенныхГруппПользователей() Экспорт
    ГруппаПользователей = Справочники.ГруппыПользователей.ВсеПользователи.ПолучитьОбъект();
    ГруппаПользователей.Наименование = НСтр("ru='Все пользователи'", КодОсновногоЯзыка);
    ОбновлениеИнформационнойБазы.ЗаписатьОбъект(ГруппаПользователей);
КонецПроцедуры
```

### Добавление новых предопределённых элементов

При добавлении новых предопределённых элементов необходимо:
- Создать новый обработчик начального заполнения с указанием версии
- Или дополнить существующий обработчик

### При использовании БСП

При использовании **Библиотеки стандартных подсистем** **не следует** создавать собственные обработчики начального заполнения.

**Правильный подход:**

1. Первоначальные данные заполнения размещать в **модуле менеджера объекта** в процедуре **ПриНачальномЗаполненииЭлементов**
2. Для объектов, зарегистрированных в процедуре **ПриОпределенииНастроек** общего модуля **ОбновлениеИнформационнойБазыПереопределяемый**, эти процедуры будут вызваны автоматически

### При изменении существующего элемента

При добавлении нового или изменении существующего элемента следует:
1. Создать собственный обработчик обновления перехода на версию
2. Продублировать изменения в процедуре **ПриНачальномЗаполненииЭлементов** модуля менеджера объекта

## Сводка

| Контекст | Рекомендация |
|----------|--------------|
| Строки, записываемые в ИБ | `НСтр("...", КодОсновногоЯзыка)` |
| Комментарий в коде | `// строка записывается в ИБ` |
| БСП: получение кода языка | `ОбщегоНазначения.КодОсновногоЯзыка()` |
| БСП: начальное заполнение | `ПриНачальномЗаполненииЭлементов` в модуле менеджера |

| Правило | Описание |
|---------|----------|
| Язык данных | Язык ИБ, не язык текущего пользователя |
| Второй параметр НСтр | Обязателен для данных, записываемых в ИБ |
| Обработчики обновления | Для изменения существующих элементов |
