# #std761 Интерфейсные тексты в коде: требования по локализации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Функция НСтр для интерфейсных строк

Если в модулях встречаются строки, предназначенные для пользовательского интерфейса (сообщения пользователю, надписи в формах, названия команд, выражения в СКД и т.п.), необходимо применять функцию **НСтр** вместо прямого использования строковых литералов.

❌ **Неправильно:**

```1c
ПоказатьПредупреждение(, "Для выполнения операции необходимо установить расширение работы с файлами.");
```

✅ **Правильно:**

```1c
ПоказатьПредупреждение(, НСтр("ru='Для выполнения операции необходимо установить расширение работы с файлами.'"));
```

### Корректное использование НСтр

❌ **Неправильно:**

```1c
ТекстСообщения = "ru='Для выполнения операции необходимо установить расширение работы с файлами.'";
ПоказатьПредупреждение(, НСтр(ТекстСообщения));
```

✅ **Правильно:**

```1c
ТекстСообщения = НСтр("ru='Для выполнения операции необходимо установить расширение работы с файлами.'");
ПоказатьПредупреждение(, ТекстСообщения);
```

## 2. Составные строки и СтрШаблон

Для составных строк следует использовать логически завершённые, целостные фразы и функцию **СтрШаблон** для подстановки параметров.

**Причины:**
- Разное расположение параметров в предложении на разных языках
- Невозможность корректно перевести несогласованные части предложения

❌ **Неправильно:**

```1c
СообщениеОНехватке = "Не хватает товара " + НаименованиеТовара + " на складе " + НаименованиеСклада + ".";
```

✅ **Правильно:**

```1c
ТекстСообщения = НСтр("ru = 'Не хватает товара %1 на складе %2.'");
СообщениеОНехватке = СтрШаблон(ТекстСообщения, НаименованиеТовара, НаименованиеСклада);
```

### Не разрывать целостные фразы

❌ **Неправильно** — параметр %1 принимает разные слова:

```1c
НСтр("ru = '%1 пользователя ""%2"" в группу ""%3""?'") // %1 = "Включить", "Копировать" или "Удалить"
```

✅ **Правильно** — отдельные полные фразы:

```1c
НСтр("ru = 'Включить пользователя ""%2"" в группу ""%3""?'")
НСтр("ru = 'Копировать пользователя ""%2"" в группу ""%3""?'")
НСтр("ru = 'Удалить пользователя ""%2"" из группы ""%3""?'")
```

### Допустимые случаи

1. Составление текста из нескольких предложений (каждое в отдельном `НСтр`)
2. Предложения, заканчивающиеся двоеточием: `НСтр("ru = 'Создание каталога не выполнено по причине:'")`

### Именованные параметры

Допускаются форматы: `[Параметр]` или `%Параметр%`

```1c
СообщениеОНехватке = НСтр("ru='Не хватает товара %Товар% на складе %Склад%.'");
СообщениеОНехватке = СтрЗаменить(СообщениеОНехватке, "%Товар%", НаименованиеТовара);
СообщениеОНехватке = СтрЗаменить(СообщениеОНехватке, "%Склад%", НаименованиеСклада);
```

## 3. Форматированные строки в БСП

При использовании БСП для составных форматированных строк применять функцию **ФорматированнаяСтрока** из модулей **СтроковыеФункции** или **СтроковыеФункцииКлиент**.

❌ **Неправильно:**

```1c
Текст = Новый Массив;
Текст.Добавить(НСтр("ru = 'Перед удалением расширения рекомендуется'"));
Текст.Добавить(" ");
Текст.Добавить(Новый ФорматированнаяСтрока(НСтр("ru = 'выполнить резервное копирование информационной базы.'"), ШрифтыСтиля.ПолужирныйШрифт);
ТекстПредупреждения = Новый ФорматированнаяСтрока(Текст);
```

✅ **Правильно:**

```1c
ТекстПредупреждения = СтроковыеФункцииКлиент.ФорматированнаяСтрока(НСтр("ru = 'Перед удалением расширения рекомендуется <b>выполнить резервное копирование информационной базы</b>.'"));
```

## 4. Одинарные кавычки в НСтр

В функции **НСтр** строка ограничивается символами **одинарных кавычек**.

❌ **Неправильно:**

```1c
ПоказатьПредупреждение(, НСтр("ru=Переменная типа ""Строка"""));
ПоказатьПредупреждение(, НСтр("ru=""Переменная типа ""Строка"""""));
```

✅ **Правильно:**

```1c
ПоказатьПредупреждение(, НСтр("ru='Переменная типа ""Строка""'"));
```

## 5. Синонимы вместо имён метаданных

Недопустимо выводить в пользовательском интерфейсе **имена объектов метаданных** и внутренние идентификаторы. Допустимо выводить **синонимы** (представления).

Рекомендуется получать синонимы напрямую из метаданных с помощью функции **Представление**.

❌ **Неправильно:**

```1c
СообщениеОшибка = НСтр("ru='Обнаружены отрицательные остатки по регистру ТоварыОрганизаций.'");
```

✅ **Правильно:**

```1c
СообщениеОшибка = СтрШаблон(НСтр("ru = 'Обнаружены отрицательные остатки по регистру ""%1"".'"), Метаданные.РегистрыНакопления.ТоварыОрганизаций.Представление());
```

Или сокращённый вариант:

```1c
СообщениеОшибка = СтрШаблон(НСтр("ru = 'Обнаружены отрицательные остатки по регистру ""%1"".'"), Метаданные.РегистрыНакопления.ТоварыОрганизаций);
```

### 5.1. Исключение для разработчиков

В сообщениях для разработчиков допускается вывод имён метаданных. При выводе имён процедур и функций указывать **полные имена** с именем модуля.

❌ **Неправильно:**

```1c
СообщениеОшибка = НСтр("ru = 'Ошибка в функции ЕстьРоль модуля УправлениеДоступом.'");
```

✅ **Правильно:**

```1c
ИмяФункции = "УправлениеДоступом.ЕстьРоль";
СообщениеОшибка = СтрШаблон(НСтр("ru = 'Ошибка в функции %1.'"), ИмяФункции);
```

Для модуля менеджера:

```1c
ИмяФункции = "Документы.АвансовыйОтчет.АдаптированныйТекстЗапросаДвиженийПоРегистру";
СообщениеОшибка = СтрШаблон(НСтр("ru = 'Для исправления движений документа необходимо вызвать функцию %1.'"), ИмяФункции);
```

Для имён метаданных использовать **ПолноеИмя()**:

```1c
СообщениеОшибка = СтрШаблон(НСтр("ru = 'Подсистема некорректно встроена в регистр %1.'"), Метаданные.РегистрыНакопления.ТоварыОрганизаций.ПолноеИмя());
```

## 6. Параметр "Л=" в ЧислоПрописью

Не указывать параметр `"Л="` (`"L="`) в строке форматирования функций **ЧислоПрописью**, **ПредставлениеПериода**, **СтрокаСЧислом**.

❌ **Неправильно:**

```1c
СуммаПрописью = ЧислоПрописью(2341.56, "Л = ru_RU; ДП = Истина", НСтр("ru='доллар,доллара,долларов,м,цент,цента,центов,м,2'"));
```

✅ **Правильно:**

```1c
СуммаПрописью = ЧислоПрописью(2341.56, "ДП = Истина", НСтр("ru='доллар,доллара,долларов,м,цент,цента,центов,м,2'"));
```

## 7. Запрет ПолучитьСклоненияСтрокиПоЧислу

❌ Недопустимо вызывать функцию **ПолучитьСклоненияСтрокиПоЧислу** — она предназначена только для русскоязычного интерфейса.

✅ Вместо неё использовать:
- `СтроковыеФункцииКлиентСервер.СтрокаСЧисломДляЛюбогоЯзыка`
- `РаботаСКурсамиВалют.СформироватьСуммуПрописью`
- `СтрокаСЧислом`
- `ЧислоПрописью`
- Собственные прикладные функции

## 8. Неязыковые символы при сложении строк

При сложении строк неязыковые символы (перенос строки) выделять в отдельные строковые литералы.

❌ **Неправильно:**

```1c
ТекстСообщения = НСтр("ru = 'Не удалось сохранить файл документа по причине:
  |'")
  + ИнформацияОбОшибке;
```

✅ **Правильно:**

```1c
ТекстСообщения = НСтр("ru = 'Не удалось сохранить файл документа по причине:'")
  + Символы.ПС + ИнформацияОбОшибке;
```

**Причина:** концевой пробел может быть не замечен переводчиком в сводной таблице строк.

## 9. Кнопки в ПоказатьВопрос

При вызове **ПоказатьВопрос** с параметром **Кнопки**:
- По возможности использовать **КодВозвратаДиалога**
- Для нестандартных кнопок задавать представление через **НСтр**

❌ **Неправильно:**

```1c
Кнопки = Новый СписокЗначений;
Кнопки.Добавить("Отключить");
Кнопки.Добавить("Нет");
ПоказатьВопрос(..., Кнопки);
```

✅ **Правильно:**

```1c
Кнопки = Новый СписокЗначений;
Кнопки.Добавить("Отключить", НСтр("ru='Отключить'"));
Кнопки.Добавить(КодВозвратаДиалога.Нет);
ПоказатьВопрос(..., Кнопки);
```

## Сводка

| Правило | Описание |
|---------|----------|
| НСтр для интерфейсных строк | Всегда использовать `НСтр("ru='...'")` |
| СтрШаблон для параметров | Использовать `%1`, `%2` вместо конкатенации |
| Целостные фразы | Не разрывать предложения параметрами |
| Одинарные кавычки | Внутри НСтр строка в одинарных кавычках |
| Представление метаданных | Использовать `.Представление()` для пользователей |
| ПолноеИмя метаданных | Использовать `.ПолноеИмя()` для разработчиков |
| Без параметра "Л=" | Не указывать в ЧислоПрописью и др. |
| КодВозвратаДиалога | Использовать для стандартных кнопок |
