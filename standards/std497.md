# #std497 Запись событий в историю работы пользователя

> Область применения: управляемое приложение.

---

## Автоматическая запись

В историю работы пользователя **автоматически** попадают события:
- Интерактивное добавление объектов (документов, элементов справочников и пр.)
- Интерактивное изменение объектов

---

## Когда добавлять вручную

Рекомендуется записывать в историю работы и **другие события**, которые приводят к записи объектов в результате действий пользователя.

| Пример события | Описание |
|----------------|----------|
| Команда «Поместить файл» | Изменение элемента справочника Файлы |
| Групповое изменение | Массовое обновление объектов по команде |
| Импорт данных | Загрузка данных из внешнего источника |

---

## Как записать событие

Используйте объект `ИсторияРаботыПользователя` типа `МенеджерИсторииРаботыПользователя`.

```1c
&НаКлиенте
Процедура ПоместитьФайл(Команда)
    // Поместить файл в базу
    // ...

    // Добавить событие в историю работы пользователя
    ИсторияРаботыПользователя.Добавить(ПолучитьНавигационнуюСсылку(Объект.Ссылка));
КонецПроцедуры
```

---

## Сводка

| Правило | Описание |
|---------|----------|
| Автоматически | Интерактивное добавление/изменение объектов |
| Вручную | Другие события, приводящие к записи объектов |
| Метод | `ИсторияРаботыПользователя.Добавить()` |
| Параметр | Навигационная ссылка на объект |
