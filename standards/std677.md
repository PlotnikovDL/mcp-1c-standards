# #std677 Использование общих реквизитов

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Назначение общих реквизитов

Общие реквизиты позволяют добавлять реквизиты сразу для нескольких объектов метаданных (справочников, документов, регистров и т.п.) для решения одной из двух прикладных задач:

| Свойство "Разделение данных" | Назначение |
|------------------------------|------------|
| **Разделять** | Разделение данных между областями (многофирменность, SaaS) |
| **Не использовать** | Расширение состава реквизитов у нескольких объектов |

---

## 2. Общие реквизиты без разделения данных

### 2.1. Правильное использование

Общие реквизиты без разделения данных предназначены для добавления **сквозного функционала**, который:
- **НЕ является** частью бизнес-логики прикладных объектов
- Решает задачи **конфигурации в целом**
- Требует хранения данных **непосредственно в самих объектах** (а не в связанных регистрах)

**Примеры корректного использования:**
- Признак для версионирования объектов
- Служебные реквизиты для обмена данными
- Технические метки для подсистем безопасности

### 2.2. Неправильное использование

**НЕ предназначены** для "удобства" добавления одинаковых реквизитов в прикладные объекты.

| Реквизит | Почему неправильно |
|----------|-------------------|
| `Ответственный` | Это бизнес-логика конкретного объекта |
| `Комментарий` | Это бизнес-логика конкретного объекта |
| `Организация` | Это бизнес-логика конкретного объекта |

### 2.3. Права доступа

Права доступа к общим реквизитам настраиваются **отдельно** от прав на объекты метаданных, в которые они добавлены.

**Важно:** При добавлении общего реквизита необходимо настроить права на него во всех ролях, иначе пользователи могут потерять доступ к данным.

---

## 3. Общие реквизиты-разделители

Порядок следования в дереве метаданных общих реквизитов с `Разделение данных = Разделять` **важен**.

**Правило:** Порядок подбирается исходя из требуемого порядка установки **параметров сеанса**, которые связаны с этими разделителями.

| Порядок | Влияние |
|---------|---------|
| Первый разделитель | Устанавливается первым при начале сеанса |
| Последующие | Устанавливаются в порядке следования |
