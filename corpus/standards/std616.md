# #std616 Формы списков

> Область применения: управляемое приложение.
>
> Раздел ИТС: Проектирование интерфейсов для 8.2 / Оформление форм списков
>
> Источник: https://its.1c.ru/db/v8std/content/616/hdoc
>
> Проверено по источнику: 2026-10-07

- Состав и порядок колонок должен определяется прогнозируемым сценарием заполнения.

- Отбирайте и группируйте колонки в несколько этажей так, чтобы можно было обойтись без горизонтальной полосы прокрутки.<br>

    <span style="color: #536ac2">*При этом нужно учитывать, что в многоэтажных списках труднее воспринимать информацию при беглом чтении.*</span>
- Фиксируйте колонки там, где это уместно.<br>

    Например, «№» и «Номенклатура» в списках документов.<br>

    При конфигурировании можно вставлять в таблицы динамических списков колонки «с запасом», делая их по умолчанию невидимыми, чтобы пользователь со временем мог оптимально настроить список по себя. Эту рекомендацию не следует применять для табличных частей.
- Рекомендуется по умолчанию делать активной колонкой ту, поиск по которой будет наиболее вероятным.<br>

    <span style="color: #536ac2">*Например, для табличной части списка товаров это будет колонка «Товар».*</span>
- Не рекомендуется использовать режим выделения строки – строка.
