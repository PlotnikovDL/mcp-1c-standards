# #std783 Транзакции: правила использования

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Особенности транзакций в 1С:Предприятии

| Особенность | Описание |
|-------------|----------|
| Нет вложенных транзакций | Вложенные вызовы `НачатьТранзакцию` не создают новую транзакцию |
| Исключение блокирует фиксацию | После исключения транзакция не может быть зафиксирована (даже если исключение обработано) |
| Неявные транзакции | Платформа автоматически начинает транзакцию при любой записи в БД |

---

## 1.1. Парность вызовов

Все вызовы `НачатьТранзакцию` должны быть парными с `ЗафиксироватьТранзакцию` или `ОтменитьТранзакцию`.

## 1.2. Один метод

Начало и фиксация (отмена) транзакции должны быть **в одном методе**.

❌ **Неправильно:**
```1c
Процедура ЗаписатьДанныеВИБ()
    НачатьТранзакцию();
    ЗаписатьДокумент();  // фиксация в другом методе!
КонецПроцедуры;
```

---

## 1.3. Обработка исключений

### Правила размещения

| Элемент | Где размещать |
|---------|---------------|
| `НачатьТранзакцию` | **До** `Попытка`, непосредственно перед ней |
| Все действия после `НачатьТранзакцию` | В **одном** блоке `Попытка` |
| `ЗафиксироватьТранзакцию` | **Последним** в `Попытка`, перед `Исключение` |
| `ОтменитьТранзакцию` | **Первым** в блоке `Исключение` |
| `ВызватьИсключение` | В конце `Исключение` (для вложенных транзакций) |

### ✅ Правильный шаблон

```1c
НачатьТранзакцию();
Попытка
    БлокировкаДанных = Новый БлокировкаДанных;
    ЭлементБлокировки = БлокировкаДанных.Добавить("Документ.ПриходнаяНакладная");
    ЭлементБлокировки.УстановитьЗначение("Ссылка", СсылкаДляОбработки);
    ЭлементБлокировки.Режим = РежимБлокировкиДанных.Исключительный;
    БлокировкаДанных.Заблокировать();

    // ... чтение или запись данных
    ДокументОбъект.Записать();

    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();

    ЗаписьЖурналаРегистрации(НСтр("ru = 'Выполнение операции'"),
        УровеньЖурналаРегистрации.Ошибка,,,
        ОбработкаОшибок.ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));

    ВызватьИсключение; // если есть внешняя транзакция
КонецПопытки;
```

## 1.4. Когда НЕ нужна явная транзакция

### 1.4.1. Только запись объекта

Не усложняйте код, если кроме записи других действий с БД нет — платформа сама откроет транзакцию.

✅ **Правильно:**
```1c
Попытка
    ДокументОбъект = Документы.ПриходнаяНакладная.СоздатьДокумент();
    // ... заполнение
    ДокументОбъект.Записать();
Исключение
    // ... обработка
КонецПопытки;
```

❌ **Неправильно:** (избыточная транзакция)
```1c
НачатьТранзакцию();
Попытка
    ДокументОбъект = Документы.ПриходнаяНакладная.СоздатьДокумент();
    ДокументОбъект.Записать();
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
КонецПопытки;
```

### 1.4.2. Методы внутри транзакции

В `ПередЗаписью`, `ОбработкаПроведения` и т.п. явная транзакция **не нужна** — метод уже вызывается в транзакции.

### 1.4.4. Обращение к БД после исключения

⚠️ В активной транзакции после исключения **нельзя** обращаться к БД — вызовет «В этой транзакции уже происходили ошибки».

Учитывайте неявные обращения (например, получение представления ссылки).

## 2. Ограничение длины транзакции

### 2.1. Принцип неделимости

В одной транзакции — только **неделимые** с точки зрения бизнес-логики действия.

**Пример:** Проведение документа — документ + движения. Если движение не записалось → откат всего.

### 2.2. Избегайте длинных транзакций

| Параметр | Рекомендация |
|----------|--------------|
| Максимальная длительность | **20 секунд** (таймаут блокировки по умолчанию) |
| Большие данные | Разбивать на **порции** |

**Ресурсы, занимаемые транзакцией:**
- Журнал транзакций (для отката)
- Блокировки (до конца транзакции)
- Оперативная память сервера
- Ресурсы бизнес-логики

### 2.3. Минимум действий в транзакции

| Действие | Где выполнять |
|----------|---------------|
| Сложные расчёты | **До** транзакции |
| Проверка заполнения | **Вне** транзакции (#std463) |
| Запросы без блокировки | **До** транзакции |
| Внешние ресурсы (сеть, веб-сервисы) | **Вне** транзакции |

❌ **Не вызывайте в транзакции:** сетевые папки, интернет-сайты, почту, FTP, HTTP, веб-сервисы.

## 3. Обязательное использование транзакции

### 3.1. Отключение итогов

При отключении итогов для ускорения записи — **оборачивайте в транзакцию**.

❌ **Неправильно:**
```1c
РегистрыСведений.КурсыВалют.УстановитьИспользованиеИтогов(Ложь);
НаборЗаписей.Записать();
РегистрыСведений.КурсыВалют.УстановитьИспользованиеИтогов(Истина);
РегистрыСведений.КурсыВалют.ПересчитатьИтоги();
```

✅ **Правильно:**
```1c
НачатьТранзакцию();
Попытка
    РегистрыСведений.КурсыВалют.УстановитьИспользованиеИтогов(Ложь);
    НаборЗаписей.Записать();
    РегистрыСведений.КурсыВалют.УстановитьИспользованиеИтогов(Истина);
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;

РегистрыСведений.КурсыВалют.ПересчитатьИтоги();
```

## Сводка

| Правило | Описание |
|---------|----------|
| Парность | `НачатьТранзакцию` ↔ `ЗафиксироватьТранзакцию`/`ОтменитьТранзакцию` |
| Один метод | Начало и конец в одном методе |
| `ОтменитьТранзакцию` первым | В блоке `Исключение` — первой строкой |
| Не усложнять | Для простой записи транзакция не нужна |
| До 20 секунд | Длинные транзакции блокируют других |
| Минимум действий | Расчёты и проверки — вне транзакции |
