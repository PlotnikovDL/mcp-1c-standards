# #std725 Оптимизация использования оперативной памяти

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

*Методическая рекомендация (полезный совет)*

---

## 1. Общий принцип

**Не следует** разрабатывать решения исходя из неограниченного объема оперативной памяти. Для многопользовательских систем любое неэффективное использование памяти может катастрофически сказаться на работоспособности.

**Рекомендация:** избегать формирования больших структур данных в памяти. Если объём данных не ограничен — ограничивать искусственно, обрабатывая данные **порциями** и сохраняя результаты в базу или файлы.

---

## 2. Порционная обработка данных

При потенциально неограниченных выборках данных из ИБ следует получать данные **порциями фиксированного размера**.

### ❌ Неправильно — выгрузка в таблицу значений

```1c
Запрос = Новый Запрос;
Запрос.Текст =
  "ВЫБРАТЬ
  | Номенклатура.Ссылка,
  | Номенклатура.Наименование,
  | Номенклатура.ВидНоменклатуры
  |ИЗ
  | Справочник.Номенклатура КАК Номенклатура";

// Выгрузка всего справочника в таблицу значений
Номенклатура = Запрос.Выполнить().Выгрузить();
```

### ❌ Неправильно — обход без ограничения

```1c
РезультатЗапроса = Запрос.Выполнить();
// Результат запроса считывается в память целиком
ВыборкаДетальныеЗаписи = РезультатЗапроса.Выбрать();
Пока ВыборкаДетальныеЗаписи.Следующий() Цикл
  // ...
КонецЦикла;
```

> *Примечание: В 32-битной версии при превышении размера памяти данные записываются на диск, затем считываются в процессе вызовов `Выборка.Следующий()`.*

### ✅ Правильно — порционная обработка с ПЕРВЫЕ

```1c
Пока Истина Цикл
  Запрос = Новый Запрос;
  Запрос.Текст =
    "ВЫБРАТЬ ПЕРВЫЕ 1000
    | Номенклатура.Ссылка,
    | Номенклатура.Наименование,
    | Номенклатура.ВидНоменклатуры
    |ИЗ
    | Справочник.Номенклатура КАК Номенклатура
    |ГДЕ
    | <условие выборки необработанных записей>";

  РезультатЗапроса = Запрос.Выполнить();
  Если РезультатЗапроса.Пустой() Тогда
    Прервать;
  КонецЕсли;

  // Обход порции результата запроса
  ВыборкаДетальныеЗаписи = РезультатЗапроса.Выбрать();
  Пока ВыборкаДетальныеЗаписи.Следующий() Цикл
    // Обработка элемента выборки
    // ...
  КонецЦикла;

КонецЦикла;
```

### ✅ Правильно — использование метода Выбрать()

```1c
Выборка = Справочники.Номенклатура.Выбрать(..., Отбор);
Пока Выборка.Следующий() Цикл
  // Обработка элемента выборки
КонецЦикла;
```

Платформа 1С:Предприятие выполняет получение данных из базы порциями фиксированного размера.

> Также число элементов выборки автоматически ограничивает платформа в запросах **динамических списков**.

## 3. Работа с большими файлами

**Недопустимо** работать с большими XML документами с помощью объектов для обработки файлов целиком:

| Объект | Проблема |
|--------|----------|
| `ТекстовыйДокумент` | Загружает весь файл в память |
| `ДокументDOM` | Загружает весь XML в память |
| `ДокументHTML` | Загружает весь HTML в память |
| `ФабрикаXDTO.ПрочитатьXML()` | Загружает весь XML в память |

**Исключение:** отдельные случаи, когда необходим произвольный доступ к конкретной части файла.

### ✅ Правильно — последовательное чтение/запись

Использовать объекты для последовательной обработки:

| Чтение | Запись |
|--------|--------|
| `ЧтениеXML` | `ЗаписьXML` |
| `ЧтениеТекста` | `ЗаписьТекста` |

**Для XDTO:** зачитывать XML-файл последовательно с помощью `ЧтениеXML`, а отдельные фрагменты (теги) десериализовывать с помощью фабрики XDTO.

## 4. Утечки памяти — циклические ссылки

К утечкам памяти приводит создание **циклических ссылок** — память выделяется и не освобождается.

### Пример циклической ссылки

```1c
Данные = Новый Структура;
Данные.Вставить("Ключ", Данные); // Ссылка на саму себя!
```

### Решение — разрыв ссылок

Когда объект становится не нужен:

```1c
Данные.Ключ = Неопределено;
```

### Выявление утечек

Для выявления утечек памяти использовать **технологический журнал** — включить в `logcfg.xml` элемент `<leaks>`.

---

## 5. Модули с повторным использованием

**Чрезмерное** (неоправданное) применение общих модулей с повторным использованием возвращаемых значений также может приводить к **излишнему потреблению памяти**.

---

## Сводка

| Проблема | Решение |
|----------|---------|
| Большие выборки из БД | `ВЫБРАТЬ ПЕРВЫЕ N` или `Справочники.*.Выбрать()` |
| Большие XML/текстовые файлы | `ЧтениеXML`, `ЧтениеТекста` |
| Циклические ссылки | Очищать ссылки (`= Неопределено`) |
| Избыточное кэширование | Ограничить модули ПовтИсп |

| Не использовать для больших файлов | Использовать вместо |
|------------------------------------|---------------------|
| `ТекстовыйДокумент` | `ЧтениеТекста` / `ЗаписьТекста` |
| `ДокументDOM` | `ЧтениеXML` / `ЗаписьXML` |
| `ФабрикаXDTO.ПрочитатьXML()` | Последовательное чтение + XDTO по фрагментам |
