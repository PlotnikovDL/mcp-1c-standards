# #std438 Проверка на пустой результат выполнения запроса

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.
>
> Раздел ИТС: Реализация обработки данных / Работа с запросами
>
> Источник: https://its.1c.ru/db/v8std/content/438/hdoc
>
> Проверено по источнику: 2026-10-07

<a id="1"></a>1\. Проверку того, что результат выполнения запроса не содержит строк следует выполнять с помощью метода **Пустой**. Поскольку на получение выборки из результата запроса (выгрузка его в таблицу значений) будет затрачиваться дополнительное время. <br>

<br>

Неправильно:

```bsl
Выборка = Запрос.Выполнить().Выбрать();
Если Выборка.Следующий() Тогда
  Возврат Истина;
Иначе
  Возврат Ложь;
КонецЕсли;
```

Правильно:

```bsl
Возврат НЕ Запрос.Выполнить().Пустой()
```

<table><tbody><tr><td> <p style="text-align: right"><em>Методическая рекомендация (полезный совет)</em></p> <p><a id="2" name="2"></a>2. В то же время если требуется выбрать (или выгрузить) результат запроса, то предварительный вызов метода <strong>Пустой</strong> не обязателен.<br>Например, вместо:</p> <pre data-code-id="code-0003">РезультатЗапроса = Запрос.Выполнить();&#10;Если НЕ РезультатЗапроса.Пустой() Тогда // избыточный вызов&#10;  Выборка = РезультатЗапроса.Выбрать();&#10;  Пока Выборка.Следующий() Цикл&#10;  ...</pre> <p>достаточно:</p> <pre data-code-id="code-0004">Выборка = Запрос.Выполнить().Выбрать();&#10;Пока Выборка.Следующий() Цикл&#10;...</pre></td></tr></tbody></table>
