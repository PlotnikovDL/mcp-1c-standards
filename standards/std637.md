# #std637 Настройка обмена данными для классификаторов между различными информационными базами

> Область применения: управляемое приложение, мобильное приложение.

---

## 1. Что такое классификаторы

К классификаторам относятся справочники и регистры сведений, которые содержат **условно-постоянную информацию**, одинаковую для всех совместно используемых информационных баз.

**Примеры классификаторов:**
- Классификатор банков
- Страны мира
- Валюты
- Общероссийский классификатор единиц измерения (ОКЕИ)
- Адресный классификатор

---

## 2. Классификаторы объектного типа (справочники)

Данные классификаторов объектного типа (страны мира, ОКЕИ и т.п.) должны сопоставляться:

1. **Сначала** — по уникальным идентификаторам ссылок
2. **Затем** (если не найдено) — по полям поиска (автоматическое сопоставление)

### Настройка в «Конвертации данных»

В правиле конвертации объекта (ПКО) классификатора установить признаки:

| Признак | Описание |
|---------|----------|
| «Искать объект приёмника по внутреннему идентификатору объекта источника» | Первичный поиск по GUID |
| «Продолжить поиск по полям поиска, если по идентификатору объект приёмник не найден» | Резервный поиск по реквизитам |

### Дополнительные настройки

- Указать **правила конвертации свойств (ПКС)**, которые используются в качестве полей поиска
  - Пример: «БИК» для классификатора банков
- При необходимости определить код обработчика ПКО **«Поля поиска»** для сложного сценария идентификации

### ⚠️ Риск дублирования

Если не настроить поиск по полям — данные классификаторов могут **продублироваться**, так как у одинаковых с прикладной точки зрения элементов справочника в разных базах, как правило, **различные** уникальные идентификаторы ссылок.

---

## 3. Классификаторы в виде наборов записей (регистры сведений)

Данные классификаторов, представленные наборами записей (например, адресный классификатор), **в обмене участвовать не должны**.

**Причина:** предотвращение избыточной миграции данных при обмене.

**Решение:** данные таких классификаторов должны заполняться и поддерживаться в актуальном состоянии **отдельно в каждой информационной базе**.

---

## Сводка

| Тип классификатора | Участие в обмене | Способ сопоставления |
|--------------------|------------------|----------------------|
| Объектный (справочники) | ✅ Да | По GUID → по полям поиска |
| Наборы записей (регистры сведений) | ❌ Нет | Заполнять отдельно в каждой базе |

| Настройка ПКО | Назначение |
|---------------|------------|
| Поиск по внутреннему идентификатору | Первичное сопоставление по GUID |
| Продолжить поиск по полям | Резервное сопоставление по реквизитам |
| Поля поиска (ПКС) | Реквизиты для сопоставления (БИК, код и т.п.) |
