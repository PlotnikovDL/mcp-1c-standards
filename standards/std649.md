# #std649 Реквизиты

> Область применения: управляемое приложение.
>
> Раздел ИТС: Проектирование интерфейсов для 8.2 / Оформление элементов
>
> Источник: https://its.1c.ru/db/v8std/content/649/hdoc
>
> Проверено по источнику: 2026-10-07

> <br>
>
> • Рекомендуется всегда оставлять на форме стандартные поля, такие как наименование, номер и дата (для документов и задач).
>
>
>
> <br>
>
> • Если для реквизита предусмотрен выбор из списка, а в списке имеется только один вариант, его следует подставлять по умолчанию.
>
>
>
> <br>
>
> <span style="color: #00008b">Примеры: одно значение ставки НДС (18%), один договор по контрагенту, заказ.</span>
>
>
>
> • При создании на основании необходимо заполнять все наследуемые реквизиты.<br>
