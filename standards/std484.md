# #std484 Общие сведения о выпуске конфигураций

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Основные понятия

Конфигурации выпускаются **версиями** и **редакциями**.

---

## 2. Версия

**Версия** — исправление текущих ошибок и внесение незначительных усовершенствований.

| Требование | Описание |
|------------|----------|
| Переход с предыдущей версии | **Обязателен** с сохранением данных |
| Изменения | Незначительные усовершенствования, исправление ошибок |

---

## 3. Редакция

**Редакция** — внесение существенных изменений в структуру учёта, требующих преобразования данных.

| Характеристика | Описание |
|----------------|----------|
| Формальный признак | Необходимость переноса данных путём конвертации (не обязательный) |
| Переход с сохранением данных | **Желателен** |
| Если переход невозможен | Описать процедуру перехода (начало работы, перенос начальных остатков и т.д.) |

---

## 4. Сравнительная таблица

| Параметр | Версия | Редакция |
|----------|--------|----------|
| Изменения | Незначительные | Существенные |
| Структура учёта | Сохраняется | Может измениться |
| Переход с сохранением данных | Обязателен | Желателен |
| Конвертация данных | Не требуется | Может потребоваться |
