# #std434 Использование ключевых слов "ОБЪЕДИНИТЬ" и "ОБЪЕДИНИТЬ ВСЕ" в запросах

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.
>
> Раздел ИТС: Реализация обработки данных / Работа с запросами
>
> Источник: https://its.1c.ru/db/v8std/content/434/hdoc
>
> Проверено по источнику: 2026-10-07

В общем случае, при объединении в запросе результатов нескольких запросов следует использовать конструкцию **ОБЪЕДИНИТЬ ВСЕ**, а не **ОБЪЕДИНИТЬ**. Поскольку во втором варианте, при объединении запросов полностью одинаковые строки заменяются одной, на что затрачивается дополнительное время, даже в случаях, когда одинаковых строк в запросах заведомо быть не может.

Исключением являются ситуации, когда выполнение замены нескольких одинаковых строк одной является необходимым условием выполнения запроса. <br>

<br>

Правильно:

```bsl
ВЫБРАТЬ
ПоступлениеТоваровУслуг.Ссылка
ИЗ
Документ.ПоступлениеТоваровУслуг КАК ПоступлениеТоваровУслуг

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ
РеализацияТоваровУслуг.Ссылка
ИЗ
Документ.РеализацияТоваровУслуг КАК РеализацияТоваровУслуг
```

Неправильно:

```bsl
ВЫБРАТЬ
ПоступлениеТоваровУслуг.Ссылка
ИЗ
Документ.ПоступлениеТоваровУслуг КАК ПоступлениеТоваровУслуг

ОБЪЕДИНИТЬ

ВЫБРАТЬ
РеализацияТоваровУслуг.Ссылка
ИЗ
Документ.РеализацияТоваровУслуг КАК РеализацияТоваровУслуг
```
