# #std759 Несущественные предупреждения проверки конфигурации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Предупреждения, не требующие исправления

Следующие предупреждения проверки конфигурации (**Конфигурация → Проверка конфигурации…**) **не являются существенными** для работоспособности прикладных решений и **не подлежат обязательному исправлению**:

| Предупреждение | Где возникает |
|----------------|---------------|
| Пустой обработчик | Обработчики оповещений в программных модулях |
| Неразрешимые ссылки на объекты метаданных | В формах и в справке |
| Неразрешимые ссылки на картинки | В формах |
| Неправильные пути к данным | В формах |

**Причина:** Методика поиска и исправления подобных мест отсутствует.

---

## 2. Флажок «Поиск использования синхронных вызовов»

⚠️ При регламентной проверке конфигурации **не следует включать** флажок **«Поиск использования синхронных вызовов»**.

**Причина:** В результатах проверки выводятся, в том числе, **корректные** места вызовов в коде, который не исполняется в веб-клиенте (например, серверный код).

---

## 3. Сводная таблица

| Предупреждение | Исправлять? |
|----------------|-------------|
| Пустой обработчик | Необязательно |
| Неразрешимые ссылки на метаданные | Необязательно |
| Неразрешимые ссылки на картинки | Необязательно |
| Неправильные пути к данным | Необязательно |
| Синхронные вызовы (флажок) | Не включать при регламентной проверке |
