# #std632 Использование констант

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Основное правило

✅ Выполнять запись константы **вне транзакций**.

Запись константы может стать **«узким» местом** при конкурентной работе.

---

## 2. Проблема блокировок

На время записи значения в константу работа **других сеансов приостанавливается**, если они одновременно выполняют запись этой же константы.

### 2.1. Пример неправильного использования

```1c
// ⛔ Неправильно — запись константы внутри транзакции проведения
Процедура ОбработкаПроведения(Отказ, РежимПроведения)
    ТекущееЗначение = Константы.СчетчикПроведенныхДокументов.Получить();
    Константы.СчетчикПроведенныхДокументов.Установить(ТекущееЗначение + 1);
КонецПроцедуры
```

**Проблема:** При проведении документов параллельно несколькими пользователями возникает взаимная блокировка на константе.

---

## 3. Недопустимые решения

⛔ **Недопустимо** решать проблему блокировок констант следующими методами:

| Метод | Почему нельзя |
|-------|---------------|
| Кеширование в параметрах сеанса | Не решает проблему записи, создаёт проблемы с актуальностью |
| Общие модули с повторным использованием | Не решает проблему записи |

---

## 4. Рекомендации

| Ситуация | Решение |
|----------|---------|
| Счётчики, инкременты | Использовать регистры сведений вместо констант |
| Редко изменяемые настройки | Константы допустимы |
| Частые записи | Вынести запись за пределы транзакции |
