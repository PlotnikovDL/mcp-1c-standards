# #std465 Обработчик события ПриЗаписи

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Назначение обработчика

В обработчике `ПриЗаписи` модуля объекта (набора записей, значения константы) выполняются:

| Действие | Описание |
|----------|----------|
| Запись связанных данных | Запись данных в других объектах конфигурации |
| Реакция на изменение | Другие действия, связанные с изменением объекта |

---

## 2. Запрет изменения объекта

⛔ **Запрещается** в обработчике `ПриЗаписи` изменять содержимое записываемого объекта.

**Причина:** На момент выполнения обработчика объект **уже записан в БД**.

---

## 3. Проверка ОбменДанными.Загрузка

⚠️ **Обязательно:** Все действия в обработчике `ПриЗаписи` должны выполняться **после проверки** на `ОбменДанными.Загрузка`.

```1c
Процедура ПриЗаписи(Отказ)

    Если ОбменДанными.Загрузка Тогда
        Возврат;
    КонецЕсли;

    // Действия после записи объекта
    // ...

КонецПроцедуры
```

---

## 4. Порядок вызова обработчиков

```
ПередЗаписью (модуль объекта)
    ↓
ПередЗаписью (подписка на событие)
    ↓
[Запись в БД]
    ↓
ПриЗаписи (модуль объекта)  ← текущий обработчик
    ↓
ПриЗаписи (подписка на событие)
```

---

## 5. Сравнение с ПередЗаписью

| Аспект | ПередЗаписью | ПриЗаписи |
|--------|--------------|-----------|
| Момент вызова | До записи в БД | После записи в БД |
| Изменение объекта | ✅ Разрешено | ⛔ Запрещено |
| Типичные задачи | Дозаполнение, проверки | Запись связанных данных |
