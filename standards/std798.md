# #std798 Использование ботов системы взаимодействия

> Область применения: управляемое приложение.

---

## 1. Регламентное задание для ботов

Для работы ботов в конфигурации должно быть предусмотрено **регламентное задание**, которое вызывает метод:

```1c
СистемаВзаимодействия.ВыполнитьОбработкуБотов()
```

### 1.1. Особенности метода ВыполнитьОбработкуБотов()

| Особенность | Описание |
|-------------|----------|
| Работает без учёта разделителей | Обращается к данным регистрации СВ в каждой области разделённой ИБ |
| Системный процесс | Запускается один на каждую область (независимо от количества ботов) |
| WebSocket | Устанавливает соединение с сервером взаимодействия |
| Предопределённые боты | Создаются при первом вызове метода |

---

## 2. Рекомендации для 1cFresh

### 2.1. Предопределённые боты

⛔ В конфигурации **не должно быть** предопределённых ботов системы взаимодействия.

✅ Должны быть предусмотрены **настройки** для включения/отключения использования бота:
- При включении — программно создавать бота
- При выключении — удалять бота

### 2.2. Регламентное задание

| Требование | Описание |
|------------|----------|
| Одно на конфигурацию | Независимо от количества объектов `БотСистемыВзаимодействия` |
| Неразделённое | Не должно включаться в состав любого из разделителей |

⚠️ Несоблюдение правил приводит к **неоправданному расходу ресурсов** как сервера 1С:Предприятие, так и сервера Системы взаимодействия.

---

## 3. Создание ботов

### 3.1. Пользователь системы взаимодействия

При создании бота необходимо указывать пользователя СВ, **не связанного с пользователем информационной базы**.

**Причина:** Иначе пользователь ИБ не сможет работать с Системой взаимодействия.

### 3.2. Несколько экземпляров ботов

При создании нескольких экземпляров ботов, связанных с одним объектом метаданных, необходимо связывать их с **разными пользователями** СВ.

**Причина:** Иначе будет работать только последний созданный экземпляр.

---

## 4. Обработка сообщений

### 4.1. Требование к коду

Код обработки сообщений ботов должен быть написан так, чтобы **не возникало необработанных исключений**.

### 4.2. Механизм очереди сообщений

1. Сообщения от сервера СВ сохраняются в системную таблицу очереди
2. Платформа последовательно вызывает `ОбработкаСообщенияСистемыВзаимодействия` модуля бота
3. Сообщение удаляется из очереди **только после успешной обработки**

### 4.3. Последствия исключений

| Ситуация | Последствие |
|----------|-------------|
| Исключение при обработке | Сообщение не удаляется, попытка повторной обработки |
| Постоянное исключение | Следующие сообщения **никогда не будут обработаны** |

---

## 5. Краткий чек-лист

- [ ] Одно неразделённое регламентное задание на конфигурацию
- [ ] Нет предопределённых ботов (только программное создание)
- [ ] Настройки включения/отключения бота
- [ ] Пользователь СВ для бота не связан с пользователем ИБ
- [ ] Разные пользователи СВ для разных экземпляров бота
- [ ] Обработка всех исключений в коде обработки сообщений
