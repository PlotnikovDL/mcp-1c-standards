# #std542 Доступ к файловой системе из кода конфигурации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Права доступа к файловой системе

### 1.1. На клиенте

Доступ выполняется под правами пользователя, от имени которого запущено приложение (тонкий, толстый или веб-клиент). Как правило — текущий пользователь ОС.

### 1.2. На сервере

| Вариант работы | Права доступа |
|----------------|---------------|
| Клиент-серверная ИБ | Пользователь, от имени которого запущен сервер 1С:Предприятия |
| Файловая база на веб-сервере | Пользователь, от имени которого запущен веб-сервер |

---

## 2. Каталог программы

> Область применения (уточнение): управляемое приложение, обычное приложение.

**Запрещается** записывать файлы в каталог исполняемых файлов 1С:Предприятия (`КаталогПрограммы`).

**Допустимо** использовать `КаталогПрограммы` только для **чтения или запуска** файлов:

```1c
ЗапуститьПриложение(КаталогПрограммы() + "1cv8s.exe");
```

---

## 3. Переносимость файлов

### 3.1. Автоматически формируемые файлы

В именах файлов указывать только **английские буквы и цифры**, кодировка — **UTF-8**.

Это касается:
- Файлов сообщений обмена
- Выгрузки данных
- Электронных документов
- Файлов в архивах (zip)

**Исключение:** формат сторонней системы, на который невозможно повлиять.

### 3.2. Файлы с именами от пользователя

- Разрешить ввод русскоязычных имен
- Дать возможность **транслитерировать** в англоязычное имя
- По умолчанию предлагать англоязычное имя и UTF-8

При использовании БСП для транслитерации: `СтроковыеФункцииКлиентСервер.СтрокаЛатиницей()`

---

## 4. Временные файлы и каталоги

### 4.1. Получение имени временного файла

Использовать метод **`ПолучитьИмяВременногоФайла`** (кроме веб-клиента).

**❌ Неправильно:**

```1c
ИмяПромежуточногоФайла = "C:\Временные файлы 1С\TempFile.xml";
Данные.Записать(ИмяПромежуточногоФайла);
```

**❌ Неправильно** (самостоятельное формирование имени):

```1c
Каталог = КаталогВременныхФайлов();
ИмяФайла = Строка(Новый УникальныйИдентификатор) + ".xml";
ИмяПромежуточногоФайла = Каталог + ИмяФайла;
```

**✅ Правильно:**

```1c
ИмяПромежуточногоФайла = ПолучитьИмяВременногоФайла("xml");
Данные.Записать(ИмяПромежуточногоФайла);
```

**Преимущества `ПолучитьИмяВременногоФайла`:**
- Уникальное имя
- Гарантированный доступ к файлу
- Автоматическое удаление при перезапуске рабочего процесса/клиента
- Удаление через 20 минут после серверного вызова (платформа 8.3.17+)

### 4.2. Временные каталоги

Также использовать `ПолучитьИмяВременногоФайла` для имени каталога. Внутри созданного каталога можно создавать файлы и подкаталоги без ограничений.

### 4.3. Веб-клиент

В веб-клиенте `ПолучитьИмяВременногоФайла` **недоступен**. Использовать:

```1c
Каталог = КаталогВременныхФайлов();
ИмяФайла = Строка(Новый УникальныйИдентификатор) + ".xml";
ИмяПромежуточногоФайла = Каталог + ИмяФайла;
```

При использовании БСП: `ФайловаяСистемаКлиент.СоздатьВременныйКаталог()`

### 4.4. Удаление временных файлов

**Обязательно** удалять временные файлы после использования:

```1c
ИмяПромежуточногоФайла = ПолучитьИмяВременногоФайла("xml");
Данные.Записать(ИмяПромежуточногоФайла);

// Работа с файлом
...

// Удаляем временный файл
Попытка
  УдалитьФайлы(ИмяПромежуточногоФайла);
Исключение
  ЗаписьЖурналаРегистрации(НСтр("ru = 'Мой механизм.Действие'"),
    УровеньЖурналаРегистрации.Ошибка, , ,
    ОбработкаОшибок.ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
КонецПопытки;
```

### 4.5. Временные файлы на сервере

Работу с временными файлами на сервере необходимо **полностью завершать в рамках одного серверного вызова**. При работе с кластером серверов файлы могут стать недоступны при следующем вызове (код может исполняться на другом компьютере).

Для сохранения данных между серверными вызовами использовать **временное хранилище** (`ПоместитьВоВременноеХранилище`, `ПолучитьИзВременногоХранилища`).

### 4.6. Передача между сеансами (редкий случай)

Если нужна передача временных файлов между сеансами:
- Константа для хранения общего пути (доступного всем серверам кластера)
- Регистр сведений для учёта файлов и времени создания
- Регламентное задание для удаления «зависших» файлов

## 5. Передача файлов между клиентом и сервером

### 5.1. Использование временного хранилища

Клиент и сервер — разные компьютеры с разной файловой системой.

**❌ Неправильно:**

```1c
&НаКлиенте
Процедура ОбработатьФайл()
  ИмяФайла = "C:\Файлы для обработки\Загрузка.xml";
  Результат = ПроизвестиОбработкуНаСервере(ИмяФайла);
КонецПроцедуры

&НаСервере
Функция ПроизвестиОбработкуНаСервере(ИмяФайла)
  Чтение = Новый ЧтениеТекста(ИмяФайла); // Файл недоступен на сервере!
  ...
КонецФункции
```

**✅ Правильно:**

```1c
&НаКлиенте
Процедура ОбработатьФайл()
  ИмяФайлаДляОбработки = "C:\Файлы для обработки\Загрузка.xml";
  ОписаниеОповещения = Новый ОписаниеОповещения("ОбработатьФайлЗавершение", ЭтотОбъект);
  НачатьПомещениеФайла(ОписаниеОповещения,, ИмяФайлаДляОбработки, Ложь, УникальныйИдентификатор);
КонецПроцедуры

&НаКлиенте
Процедура ОбработатьФайлЗавершение(Результат, Адрес, ВыбранноеИмяФайла, ДополнительныеПараметры)
  Результат = ПроизвестиОбработкуНаСервере(Адрес);
КонецПроцедуры

&НаСервере
Функция ПроизвестиОбработкуНаСервере(Адрес)
  Данные = ПолучитьИзВременногоХранилища(Адрес);
  ИмяПромежуточногоФайла = ПолучитьИмяВременногоФайла("txt");
  Данные.Записать(ИмяПромежуточногоФайла);

  Чтение = Новый ЧтениеТекста(ИмяПромежуточногоФайла);
  Результат = Чтение.Прочитать();

  УдалитьФайлы(ИмяПромежуточногоФайла);
  Возврат Результат;
КонецФункции
```

### 5.2. Сохранение между серверными вызовами

Для сохранения данных между вызовами использовать `УникальныйИдентификаторФормы`.

**Важно:** при повторном помещении файла **удалять предыдущее значение**:

```1c
// Перед повторным помещением
УдалитьИзВременногоХранилища(Адрес);

НачатьПомещениеФайла(ОписаниеОповещения,, ИмяФайлаДляОбработки, Ложь, УникальныйИдентификатор);
```

### 5.3. При использовании БСП

Использовать `ФайловаяСистемаКлиент.ЗагрузитьФайл()` и `ЗагрузитьФайлы()`:

```1c
ПараметрыЗагрузки = ФайловаяСистемаКлиент.ПараметрыЗагрузкиФайла();
ПараметрыЗагрузки.ИдентификаторФормы = УникальныйИдентификатор;
ПараметрыЗагрузки.Интерактивно = Ложь;

ФайловаяСистемаКлиент.ЗагрузитьФайл(ОписаниеОповещения, ПараметрыЗагрузки, ИмяФайлаДляОбработки);
```

## Сводка

| Задача | Решение |
|--------|---------|
| Имя временного файла | `ПолучитьИмяВременногоФайла()` |
| Имя временного файла (веб-клиент) | `КаталогВременныхФайлов()` + `УникальныйИдентификатор` |
| Кодировка текстовых файлов | UTF-8 |
| Имена автоматических файлов | Только английские буквы и цифры |
| Передача файла на сервер | Временное хранилище |
| Хранение между вызовами | `УникальныйИдентификаторФормы` |

| Запрещено | Причина |
|-----------|---------|
| Запись в `КаталогПрограммы` | Системный каталог |
| Жёстко заданные пути | Нет прав, коллизии в многопользовательском режиме |
| Оставлять временные файлы | Исчерпание места на диске |
| Использовать файлы сервера между вызовами | Кластер может перенаправить на другой сервер |
