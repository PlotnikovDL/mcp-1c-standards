# #std451 Программное создание прикладных объектов

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Использование методов менеджеров

Для программного создания прикладных объектов следует использовать методы соответствующих менеджеров:

- **СоздатьЭлемент**
- **СоздатьДокумент**
- **СоздатьНаборЗаписей**
- и т.д.

Использование конструктора (оператор **Новый**) для прикладных объектов **запрещается**.

**✅ Правильно:**

```1c
ДокументПриходная = Документы.ПоступлениеТоваровУслуг.СоздатьДокумент();
```

**❌ Неправильно:**

```1c
ДокументПриходная = Новый("ДокументОбъект.ПоступлениеТоваровУслуг");
```

---

## 2. Вызов метода Заполнить

При программном создании объекта следует **явно вызывать** метод объекта **Заполнить**. Если данных для заполнения нет — передать значение **Неопределено**.

В этом случае корректно отработают:

- Свойства реквизитов объекта «Значение заполнения»
- Обработчик **ОбработкаЗаполнения**
- Подписки на это событие

— как при интерактивной работе с объектом.

**❌ Неправильно:**

```1c
Папка = Справочники.ПапкиФайлов.СоздатьЭлемент();
// ...
Папка.Записать();
```

**✅ Правильно:**

```1c
Папка = Справочники.ПапкиФайлов.СоздатьЭлемент();
// ...
Папка.Заполнить(Неопределено);
// ...
Папка.Записать();
```

---

## Исключение

Случаи, когда объект полностью загружается из источника:

- Обмен данными
- Восстановление базы из резервной копии (загрузка из XML)

---

## Сводка

| Действие | Рекомендация |
|----------|--------------|
| Создание объекта | Использовать методы менеджера (СоздатьЭлемент и т.д.) |
| Оператор `Новый` для прикладных объектов | ❌ Запрещено |
| После создания | Вызвать `Заполнить(Неопределено)` или `Заполнить(ДанныеЗаполнения)` |
