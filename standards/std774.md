# #std774 Безопасность запуска приложений

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Безопасная строка запуска

При запуске внешней программы строка запуска должна собираться **только из проверенных частей**.

Если часть строки содержит данные из базы, поля ввода или хранилища настроек — **проверить безопасность** перед запуском.

### Опасные символы

**Небезопасными** считаются строки, содержащие:

```
$  `  |  ||  ;  &  &&
```

### Применяется к методам

| Метод | Описание |
|-------|----------|
| `КомандаСистемы()` | Выполнение команды ОС |
| `ЗапуститьПриложение()` | Запуск приложения |
| `НачатьЗапускПриложения()` | Асинхронный запуск |
| `ПерейтиПоНавигационнойСсылке()` | Переход по ссылке |
| COM-объекты `Wscript.Shell`, `Shell.Application` | Запуск через COM |

## 2. API Библиотеки стандартных подсистем

### 2.1. Открытие проводника

```1c
// Windows
ФайловаяСистемаКлиент.ОткрытьПроводник("C:\Users");
ФайловаяСистемаКлиент.ОткрытьПроводник("C:\Program Files\1cv8\common\1cestart.exe");

// Linux
ФайловаяСистемаКлиент.ОткрытьПроводник("/home/");
ФайловаяСистемаКлиент.ОткрытьПроводник("/opt/1C/v8.3/x86_64/1cv8c");
```

### 2.2. Открытие файла в ассоциированной программе

Исключает запуск исполняемых файлов (*.exe, *.bin, *.apk).

```1c
ФайловаяСистемаКлиент.ОткрытьФайл(КаталогДокументов() + "test.pdf");
ФайловаяСистемаКлиент.ОткрытьФайл("D:\test.xlsx");
```

### 2.3. Открытие навигационной ссылки

Веб-страницы, протоколы (mailto:, skype:, tel:), навигационные ссылки ИБ:

```1c
ФайловаяСистемаКлиент.ОткрытьНавигационнуюСсылку("https://1c.ru");
ФайловаяСистемаКлиент.ОткрытьНавигационнуюСсылку("e1cib/navigationpoint/startpage");
ФайловаяСистемаКлиент.ОткрытьНавигационнуюСсылку("mailto:help@1c.ru");
ФайловаяСистемаКлиент.ОткрытьНавигационнуюСсылку("skype:echo123?call");
```

**Не использовать** `file://` для открытия проводника или файла — использовать `ОткрытьПроводник` или `ОткрытьФайл`.

### 2.4. Запуск программы / выполнение команд

Для запуска исполняемых файлов (*.exe, *.bat), системных команд (ping, tracert), команд на сервере, получения кода возврата и потоков вывода:

**На клиенте:**
```1c
ФайловаяСистемаКлиент.ЗапуститьПрограмму("calc");
```

**На сервере с получением результата:**
```1c
ПараметрыЗапускаПрограммы = ФайловаяСистема.ПараметрыЗапускаПрограммы();
ПараметрыЗапускаПрограммы.ДождатьсяЗавершения = Истина;
ПараметрыЗапускаПрограммы.ПолучитьПотокВывода = Истина;
ПараметрыЗапускаПрограммы.ПолучитьПотокОшибок = Истина;

Результат = ФайловаяСистема.ЗапуститьПрограмму(
  "ping 127.0.0.1 -n 5", ПараметрыЗапускаПрограммы);

КодВозврата = Результат.КодВозврата;
ПотокВывода = Результат.ПотокВывода;
ПотокОшибок = Результат.ПотокОшибок;
```

### 2.5. Запрет динамического формирования исполняемых файлов

**Не рекомендуется** программно создавать исполняемые файлы (bat-файлы во временном каталоге).

**Причина:** политики ИБ могут запрещать запуск приложений, кроме разрешённых. Временный каталог целиком в исключениях — угроза безопасности.

**Вместо этого:**
- Формировать строку запуска для `ФайловаяСистема.ЗапуститьПрограмму()`
- Передавать параметры в статический исполняемый файл:
  - Через параметры командной строки: `install.bat /FeatureName "Printing"`
  - Через файл параметров: `install.bat "%temp%\install.ini"`

## 3. Запуск с повышенными правами (UAC)

Для команд, требующих запуск с наивысшими правами (запрос UAC в Windows):

- Реализовать как кнопку или пункт меню на управляемой форме
- Отобразить на кнопке **значок щита** (картинка `ЗначокЩита` из БСП)
