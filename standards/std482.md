# #std482 Заполнение свойств конфигурации информацией о выпуске

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Синоним

Указывается **официальное название** конфигурации, которое будет идентифицировать конфигурацию в:
- Документации
- На коробке с продуктом
- Прайс-листе
- Рекламе
- Информационных и методических материалах

В конце официального названия через запятую указывается слово "редакция" и номер редакции.

**Пример:** `Бухгалтерия предприятия, редакция 1.6`

---

## 2. Имя

Имя образуется по правилам образования имен из синонима.

⚠️ Слово "редакция", номер редакции (и подредакции) — **не указываются**.

**Пример:** `БухгалтерияПредприятия`

---

## 3. Краткая информация

Краткая информация **повторяет синоним**.

---

## 4. Подробная информация

Подробная информация **повторяет синоним**.

---

## 5. Логотип

Для типовых конфигураций фирмы "1С" картинка логотипа **не заполняется**.

---

## 6. Заставка

В качестве заставки устанавливается картинка одного из типов, поддерживаемых системой 1С:Предприятие.

Требования к размеру картинки см. в документации платформы.

---

## 7. Авторские права

Указывается строка вида:

```
Copyright (C) <разработчик>, хххх-хххх. Все права защищены.
```

Для конфигураций на английском языке:

```
Copyright (C) <разработчик>, хххх-хххх. All rights reserved.
```

Вместо `хххх-хххх` указываются конкретные годы выпуска конфигурации.

**Пример:** `Copyright (C) ООО "1С-Софт", 2009-2025. Все права защищены`

---

## 8. Адрес информации о поставщике

Для типовых конфигураций фирмы "1С" указывается:

```
https://www.1c.ru
```

---

## 9. Адрес информации о конфигурации

Для типовых конфигураций фирмы "1С" указывается строка:

```
https://v8.1c.ru/<короткое имя>/
```

Где `<короткое имя>` — англоязычное короткое имя конкретной конфигурации.

**Пример:** `https://v8.1c.ru/trade/`

---

## 10. Поставщик

Для типовых конфигураций фирмы "1С" указывается:

```
Фирма "1С"
```

---

## 11. Версия

Указывается **полный номер версии** конфигурации.

**Пример:** `1.6.4.7`

Подробнее об образовании номера версии см. стандарт #std483.

---

## 12. Адрес каталога обновлений

Для типовых конфигураций фирмы "1С" указывается:

```
https://downloads.v8.1c.ru/tmplts/
```

---

|----------|----------|

| Имя | Из синонима, без редакции |
| Краткая информация | = Синоним |
| Подробная информация | = Синоним |
| Логотип | Не заполняется (для 1С) |
| Заставка | Картинка по требованиям платформы |

| Адрес информации о поставщике | https://www.1c.ru |
| Адрес информации о конфигурации | https://v8.1c.ru/<имя>/ |
