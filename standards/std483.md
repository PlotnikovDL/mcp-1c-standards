# #std483 Нумерация редакций и версий

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Номер редакции

Номер очередной редакции конфигурации начинается со следующего целого номера относительно предыдущей редакции.

Для обозначения редакции обычно номер редакции объединяют через точку с номером подредакции:
- Редакция 1.5
- Редакция 1.6
- и т. д.

**Для новых конфигураций** нумерация начинается с **1.0**.

---

## 2. Нумерация версий

Все версии одной подредакции (включая альфа, ознакомительные, бета и финальные версии) нумеруются **подряд**.

Нумерация версий начинается с **1**.

---

## 3. Полный номер версии конфигурации

Информация о номере редакции, номере подредакции и номере версии объединяются в полный номер версии конфигурации.

Он указывается в свойстве **Версия** конфигурации.

### 3.1. Формат

```
{Р|РР}.{П|ПП}.{З|ЗЗ}.{С|СС}
```

### 3.2. Расшифровка

| Символ | Описание |
|--------|----------|
| Р | Номер редакции (минимум 1 цифра, может занимать больше разрядов) |
| П | Номер подредакции (минимум 1 цифра, может занимать больше разрядов) |
| З | Номер версии (минимум 1 цифра, может занимать больше разрядов) |
| С | Номер сборки (минимум 1 цифра, может занимать больше разрядов) |

### 3.3. Пример

```
1.6.4.7
```

| Компонент | Значение |
|-----------|----------|
| 1 | Редакция 1 |
| 6 | Подредакция 6 |
| 4 | Версия 4 |
| 7 | Сборка 7 |

**Расшифровка:** 7-я сборка, 4-й версии, редакции 1.6
