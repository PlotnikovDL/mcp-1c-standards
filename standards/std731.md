# #std731 Требования к установке и обновлению прикладных решений

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Основа

Подготовка дистрибутивов выполняется в соответствии с главой 30 «Поставка и поддержка конфигурации» Руководства разработчика.

---

## 2. Структура каталогов шаблонов

```
<Каталог шаблонов>\<каталог разработчика>\<каталог конфигурации>\<каталог версии>
```

**Правило:** В каталоге версии вместо точек используются **подчёркивания**.

**Пример:** Версия 11.1.3.6 конфигурации «Управление торговлей»:

```
<Каталог шаблонов>\1C\Trade\11_1_3_6\
```

---

## 3. Файл-манифест 1cv8.mft

В каталоге версии должен быть файл `1cv8.mft`, описывающий:
- Шаблоны конфигурации (`.cf`)
- Демонстрационные информационные базы (`.dt`)

### 3.1. Пример манифеста

```ini
Vendor=Фирма "1С"
Name=УправлениеТорговлей
Version=11.1.3.6
AppVersion=8.3

[Config1]
Catalog=1С:Управление торговлей/Управление торговлей
Destination=1C\Trade
Source=1cv8.cf

[Config2]
Catalog=1С:Управление торговлей/Управление торговлей (демо)
Destination=1C\DemoTrd
Source=1Cv8.dt
```

### 3.2. Параметры манифеста

| Параметр | Описание |
|----------|----------|
| `Vendor` | Название разработчика |
| `Name` | Имя конфигурации (без пробелов) |
| `Version` | Номер версии |
| `AppVersion` | Версия платформы |
| `Catalog` | Путь в дереве шаблонов: `<Группа>/<Название>` |
| `Destination` | Каталог для создания ИБ |
| `Source` | Имя файла шаблона |

---

## 4. Уникальность названий

### 4.1. Строка Catalog

В наименование шаблона (часть до `/`) **включать название разработчика**:

| Вариант | Пример |
|---------|--------|
| В начале | `1С:Управление торговлей` |
| В конце | `Управление торговлей (1С)` |

### 4.2. Строка Destination

```
Destination = <каталог разработчика>\<каталог информационной базы>
```

**Каталог разработчика** — название, адаптированное для файловых каталогов.

**Пример:** `1C\Trade`

### 4.3. Глобальная уникальность

Названия разработчиков должны быть **глобально уникальными**:
- Для наименований шаблонов конфигураций
- Для имён файловых каталогов

Название выбирается **один раз** и используется для всех прикладных решений разработчика.

---

## 5. Дистрибутивы обновлений

Для обновления версий выпускаются отдельные дистрибутивы с файлом обновления (`.cfu`).

### 5.1. Способы обновления

| Способ | Описание |
|--------|----------|
| Конфигуратор | Меню **Конфигурация → Поддержка → Обновить конфигурацию** |
| БСП | Подсистема «Обновление конфигурации» |

---

## 6. Типы файлов

| Расширение | Назначение |
|------------|------------|
| `.cf` | Шаблон конфигурации |
| `.dt` | Выгрузка информационной базы (демо) |
| `.cfu` | Файл обновления конфигурации |
| `.mft` | Файл-манифест |
