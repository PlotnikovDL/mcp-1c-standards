# #std459 Использование значений, влияющих на поведение клиентского приложения

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## Рекомендация

Если поведение ряда форм или команд зависит от одних и тех же значений (параметров, настроек), для минимизации клиент-серверного взаимодействия рекомендуется применять **общие модули с повторным использованием возвращаемых значений** (свойство «На время сеанса»).

**Условие применения:** изменение соответствующего значения в течение сеанса не является критичным.

---

## Возврат всех значений одним вызовом

Функции такого модуля должны за **один вызов** возвращать сразу все значения, которые могут понадобиться.

**Пример:**

```1c
Настройки = НастройкиПодсистемыРегистрации();
ВремяНачала = Настройки.ВремяНачалаРабочегоДня;
ВремяОкончания = Настройки.ВремяОкончанияРабочегоДня;
```

---

## Ограничения применения

Применение клиентских модулей с повторным использованием должно быть **разумно ограничено**:

| Ситуация | Рекомендация |
|----------|--------------|
| Данные для отдельной формы | Размещать в **реквизитах формы**, получать при создании на сервере |
| Данные для команд или многих форм | Использовать модули с повторным использованием |

---

## Запрет

**Не рекомендуется** использовать переменные модуля управляемого приложения и модуля обычного приложения для минимизации клиент-серверного взаимодействия.

---

## Сводка

| Подход | Когда использовать |
|--------|-------------------|
| Реквизиты формы | Данные для одной формы |
| Модуль с повторным использованием | Данные для команд / многих форм |
| Переменные модуля приложения | ❌ Не рекомендуется |
