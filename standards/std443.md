# #std443 Получение предопределенных значений на клиенте

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## Рекомендация

Для получения предопределённых значений в **клиентском коде** (тонкий клиент, веб-клиент), где объекты типа `СправочникМенеджер`, `ПеречислениеМенеджер` и т.п. **недоступны**, предназначена функция глобального контекста **ПредопределенноеЗначение**.

**Поддерживаемые типы:**
- Ссылки на предопределённые элементы справочников
- Планы видов характеристик
- Планы счетов
- Планы видов расчета
- Значения перечислений
- Системные перечисления
- Точки маршрута бизнес-процессов

---

## Пример

```1c
ЮрФизЛицо = ПредопределенноеЗначение("Перечисление.ЮридическоеФизическоеЛицо.ЮридическоеЛицо");
```

---

## При использовании БСП

При использовании **Библиотеки стандартных подсистем** (версии 2.1.4 и выше) рекомендуется использовать функцию **ПредопределенныйЭлемент**:

- `ОбщегоНазначения.ПредопределенныйЭлемент()` — на сервере
- `ОбщегоНазначенияКлиент.ПредопределенныйЭлемент()` — на клиенте

**Преимущество:** возвращает **Неопределено** для несуществующих в ИБ предопределённых элементов.

---

## Кэширование

**Не следует** реализовывать дополнительные механизмы кэширования предопределённых значений на клиенте.

Указанные функции **не ухудшают** клиент-серверное взаимодействие:
- Серверный вызов выполняется только при **первом обращении**
- Результат **автоматически кэшируется**

---

## Сводка

| Функция | Где использовать | Поведение при отсутствии |
|---------|-----------------|-------------------------|
| `ПредопределенноеЗначение()` | Клиент / Сервер | Ошибка |
| `ОбщегоНазначенияКлиент.ПредопределенныйЭлемент()` | Клиент (БСП) | Неопределено |
| `ОбщегоНазначения.ПредопределенныйЭлемент()` | Сервер (БСП) | Неопределено |
