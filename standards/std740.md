# #std740 Безопасное хранение паролей

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Проблема

При разработке подсистем, взаимодействующих с внешними ресурсами (электронная почта, веб-сервисы, FTP и т.п.), возникает необходимость запрашивать и передавать данные аутентификации: **логин и пароль**.

---

## 2. Основной принцип — не хранить пароли

**Не следует** хранить пароли и другую конфиденциальную информацию в информационной базе.

**Уровни защищённости:**
| Тип ИБ | Защищённость |
|--------|--------------|
| Файловая | Минимальная — файл базы может быть скопирован любым пользователем |
| Клиент-серверная | Выше — доступ к БД только у администраторов СУБД |

**Рекомендация:** запрашивать логин и пароль у пользователя и передавать их сразу, **не сохраняя** в информационной базе.

---

## 3. Когда хранение допустимо

В ряде случаев интерактивный запрос невозможен или неудобен:
- Запрос на каждую операцию создаёт дискомфорт
- Взаимодействие с внешними ресурсами выполняется на сервере независимо от работы пользователей

**Допустимо** организовать хранение паролей, **предупредив пользователей** о последствиях.

> Хранение паролей не решает всех проблем безопасности, а лишь **усложняет задачу** для злоумышленника.

### 3.1. Отдельное хранилище

**Не следует** хранить пароли в реквизитах объектов, с которыми ведётся повседневная работа.

Использовать **отдельный объект метаданных** (например, регистр сведений) с безопасным доступом на уровне системы прав.

### 3.2. Безопасное хранилище БСП

При использовании **Библиотеки стандартных подсистем** использовать безопасное хранилище паролей.

**Преимущества:**
| Проблема | Решение в БСП |
|----------|---------------|
| Доступ к реквизиту с паролем | Только в привилегированном режиме |
| «Засветка» паролей | Данные хранятся в закрытом виде |
| Утечка при обмене данными | Исключено из планов обмена |

**API модуля `ОбщегоНазначения`:**
- `ЗаписатьДанныеВБезопасноеХранилище()`
- `ПрочитатьДанныеИзБезопасногоХранилища()`
- `УдалитьДанныеИзБезопасногоХранилища()`

### 3.3. Пароли на форме — только маскировка

**Не следует** хранить пароли в реквизитах формы — извлекать только на сервере, непосредственно перед использованием.

**Причина:** при открытии формы пароль передаётся с сервера на клиент **в открытом виде** → возможен перехват.

**Привилегированный режим:** устанавливать **перед** вызовом функций (не внутри них), чтобы исключить получение паролей в сеансе с любыми правами.

#### Пример: чтение пароля при открытии формы

**В `ПриСозданииНаСервере`:**

```1c
УстановитьПривилегированныйРежим(Истина);
Пароли = ОбщегоНазначения.ПрочитатьДанныеИзБезопасногоХранилища(
  Объект.Ссылка, "Пароль, ПарольSMTP");
УстановитьПривилегированныйРежим(Ложь);

// Маскировка: если пароль есть — показываем УникальныйИдентификатор
Пароль = ?(ЗначениеЗаполнено(Пароли.Пароль), ЭтотОбъект.УникальныйИдентификатор, "");
ПарольSMTP = ?(ЗначениеЗаполнено(Пароли.ПарольSMTP), ЭтотОбъект.УникальныйИдентификатор, "");
```

#### Пример: сохранение пароля при записи

**В `ПриЗаписиНаСервере`:**

```1c
Если ПарольИзменен Тогда
  УстановитьПривилегированныйРежим(Истина);
  ОбщегоНазначения.ЗаписатьДанныеВБезопасноеХранилище(ТекущийОбъект.Ссылка, Пароль);
  УстановитьПривилегированныйРежим(Ложь);
  // Затираем реквизит формы
  Пароль = ?(ЗначениеЗаполнено(Пароль), ЭтотОбъект.УникальныйИдентификатор, "");
КонецЕсли;

Если ПарольSMTPИзменен Тогда
  УстановитьПривилегированныйРежим(Истина);
  ОбщегоНазначения.ЗаписатьДанныеВБезопасноеХранилище(
    ТекущийОбъект.Ссылка, ПарольSMTP, "ПарольSMTP");
  УстановитьПривилегированныйРежим(Ложь);
  ПарольSMTP = ?(ЗначениеЗаполнено(ПарольSMTP), ЭтотОбъект.УникальныйИдентификатор, "");
КонецЕсли;
```

**Принцип маскировки:** реквизит формы содержит `УникальныйИдентификатор` (эмуляция наличия пароля), а не сам пароль.

---

## Сводка

| Правило | Описание |
|---------|----------|
| Не хранить в ИБ | Запрашивать и передавать сразу |
| Если нужно хранить | Отдельный объект + права доступа |
| При использовании БСП | `ОбщегоНазначения.*БезопасноеХранилище()` |
| Не хранить в реквизитах формы | Извлекать только на сервере перед использованием |
| Маскировка на форме | `УникальныйИдентификатор` вместо пароля |
| Привилегированный режим | Устанавливать **перед** вызовом, не внутри |
