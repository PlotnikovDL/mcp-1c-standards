# #std730 Ограничение использования поля HTML документа

> Область применения: управляемое приложение.
>
> Раздел ИТС: Разработка пользовательских интерфейсов / Реализация работы формы
>
> Источник: https://its.1c.ru/db/v8std/content/730/hdoc
>
> Проверено по источнику: 2026-10-07

<a id="1"></a>1\. Не следует использовать поля с HTML-документами (свойство **ВидПоля** установлено в **ВидПоляФормы.ПолеHTMLДокумента**) в случаях, когда возможно использование элементов управления платформы 1С:Предприятие. При разработке форм следует стремиться применять только штатные элементы управления, предусмотренные в платформе.

Например, неправильно, размещать на форме отдельные гиперссылки с помощью полей с HTML-документами. <br>

Правильно использовать для этих целей кнопки, надписи с гиперссылками или с форматированными строками.

<a id="2"></a>2\. Допустимый пример использования поля с HTML-документом: вывод в формах различных пользовательских инструкций, встроенной справки, путеводителей с оформлением и картинками, которые предназначены только для просмотра информации.

При этом должно быть самостоятельно обеспечено корректное отображения страниц во всех видах клиентских приложений и на всех веб-браузерах, которые поддерживаются платформой 1С:Предприятие.
