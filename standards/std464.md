# #std464 Обработчик события ПередЗаписью

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Назначение обработчика

В обработчике `ПередЗаписью` модуля объекта (набора записей, значения константы) должны выполняться:

| Действие | Описание |
|----------|----------|
| Заполнение реквизитов | Дозаполнение значений реквизитов объекта |
| Проверка заполнения | Проверка правильности заполнения |
| Связь с внешними данными | Связанность состояния объекта с внешними данными |
| Работа со «старыми» значениями | Обращение к значениям реквизитов, сохранённым в БД (при редактировании) |

---

## 2. Проверка ОбменДанными.Загрузка

⚠️ **Обязательно:** Все действия в обработчике `ПередЗаписью` должны выполняться **после проверки** на `ОбменДанными.Загрузка`.

```1c
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)

    Если ОбменДанными.Загрузка Тогда
        Возврат;
    КонецЕсли;

    // Предпроверки и дозаполнение реквизитов объекта
    // ...

КонецПроцедуры
```

---

## 3. Типичные задачи

| Задача | Пример |
|--------|--------|
| Автозаполнение | Установка даты, автора, организации по умолчанию |
| Вычисляемые поля | Расчёт итогов, хешей, контрольных сумм |
| Нормализация данных | Приведение к верхнему регистру, удаление пробелов |
| Проверки | Валидация данных перед записью |
| Сравнение со «старым» | Определение изменённых реквизитов |

---

## 4. Порядок вызова обработчиков

```
ПередЗаписью (модуль объекта)
    ↓
ПередЗаписью (подписка на событие)
    ↓
[Запись в БД]
    ↓
ПриЗаписи (модуль объекта)
```
