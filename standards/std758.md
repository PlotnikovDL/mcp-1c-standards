# #std758 Псевдонимы источников данных в запросах

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Требования к псевдонимам

Псевдоним источника данных должен быть **осмысленным** — понятно его назначение в контексте запроса.

Требования схожи с [именами переменных в коде](#std454).

### 1.1. Правила именования

| Правило | Пример |
|---------|--------|
| Термины предметной области | `ТоварыНаСкладах`, `ОстаткиНаСкладах` |
| CamelCase без пробелов | `ВсяНоменклатура` |
| Предлоги/местоимения из 1 буквы — прописные | `ТоварыВЯчейках` |
| ⛔ Не начинать с подчеркивания | `_Таблица` — неправильно |
| ⛔ Не один символ | `Т`, `Н` — неправильно |

### 1.2. Не рекомендуется

Имена классов метаданных (`Справочник`, `Документ` и т.д.) — они не описывают назначение в конкретном запросе.

---

## 2. Пример

❌ **Неправильно:**

```1c
ВЫБРАТЬ
    Таблица1.Ссылка КАК Товар,
    ЕстьNULL(Таблица2.КоличествоОстаток, 0) КАК Остаток
ИЗ
    Справочник.Номенклатура КАК Таблица1
    ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки КАК Таблица2
    ПО Таблица1.Ссылка = Таблица2.Номенклатура
```

✅ **Правильно:**

```1c
ВЫБРАТЬ
    ВсяНоменклатура.Ссылка КАК Товар,
    ЕстьNULL(ОстаткиНаСкладах.КоличествоОстаток, 0) КАК Остаток
ИЗ
    Справочник.Номенклатура КАК ВсяНоменклатура
    ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки КАК ОстаткиНаСкладах
    ПО ВсяНоменклатура.Ссылка = ОстаткиНаСкладах.Номенклатура
```

---

## 3. Исключение: универсальные механизмы

При разработке **универсальных механизмов** для произвольных таблиц допустимы универсальные псевдонимы.

**Пример:**

```1c
"ВЫБРАТЬ
    Таблица.Наименование КАК Наименование,
    Таблица.Код КАК Код
ИЗ
    &Таблица КАК Таблица";

ТекстЗапроса = СтрЗаменить(ТекстЗапроса, "&Таблица", "Справочник." + ИмяСправочника);
```

---

## 4. Сводка

| Что | Правило |
|-----|---------|
| Осмысленность | Понятно назначение в контексте |
| Формат | CamelCase из терминов предметной области |
| Запрещено | `_`, один символ, `Справочник`/`Документ` |
| Исключение | Универсальные механизмы — допустимо `Таблица` |
