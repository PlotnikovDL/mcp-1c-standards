# #std453 Описание процедур и функций

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Общие требования

Описание процедур и функций выполняется в виде **комментария**.

- В платформе 8.3 комментарий выводится в **контекстной подсказке**
- В EDT используется для **типизации** параметров и возвращаемого значения

---

## 2. Обязательное комментирование

**Обязательно** комментировать процедуры и функции из раздела `ПрограммныйИнтерфейс` — они предназначены для использования другими разработчиками.

---

## 3. Необязательное комментирование

Прочие процедуры (в т.ч. обработчики событий) — комментировать, если:
- Требуется пояснить назначение или особенности работы
- Причины невыполнения действий неочевидны

Если назначение понятно из названия и имён параметров — комментарий **можно не писать**.

---

## 4. Избегать избыточных комментариев

**❌ Неправильно:**

```1c
// Процедура - обработчик события "ПриОткрытии" формы
&НаКлиенте
Процедура ПриОткрытии()

// Функция возвращает статью движения денежных средств по данным документа
Функция СтатьяДвиженияДенежныхСредств(ДанныеДокумента)
```

Эти комментарии **не дают дополнительной информации**.

---

## 5. Структура комментария

### 5.1. Секция «Описание»

- Содержит назначение процедуры/функции
- Должна начинаться с **глагола**: «Возвращает…», «Проверяет…», «Создает…»
- ❌ Не начинать с «Процедура...», «Функция...» или имени процедуры

**❌ Неправильно:**

```1c
// Конструктор объекта WSПрокси.
Функция WSПрокси(ПараметрыПрокси) Экспорт
```

**✅ Правильно:**

```1c
// Создает прокси на основе определения веб-сервиса и связывает
// его с точкой подключения веб-сервиса.
Функция WSПрокси(ПараметрыПрокси) Экспорт
```

### 5.2. Секция «Параметры»

```1c
// Параметры:
//   ИмяПараметра - Тип - описание параметра.
```

**Требования к типу:**
- Использовать **реальные типы платформы** или специальные EDT-типы
- Для составных типов — через запятую: `Строка, Число, Булево`
- Для массивов — ключевое слово **«из»**: `Массив из СправочникСсылка.Номенклатура`
- Для Структуры/ТаблицыЗначений — ссылка на конструктор: `см. МодульСервер.НоваяСтруктура`

**Пример:**

```1c
// Параметры:
//   Адреса - Строка - электронные адреса через запятую. Например, support@mycorp.ru,v8@local.
//   ЗадачаИсполнителя - ЗадачаСсылка.ЗадачаИсполнителя
//   ПараметрыЗаполнения - см. ЦенообразованиеСервер.ПараметрыЗаполненияЦен
//   МассивЗадач - Массив из ЗадачаСсылка.ЗадачаИсполнителя
```

### 5.3. Секция «Возвращаемое значение»

```1c
// Возвращаемое значение:
//   Булево - Истина, если роль доступна текущему пользователю.

// Возвращаемое значение:
//   - СправочникСсылка.Пользователи
//   - СправочникСсылка.ВнешниеПользователи
```

### 5.4. Секция «Пример»

Имя функции — **с именем модуля**. Показать вход и выход.

**❌ Неправильно:**

```1c
// Пример:
//   ПодставитьПараметрыВСтроку(ШаблонСтроки, СтрокаЗамены);
```

**✅ Правильно:**

```1c
// Пример:
//   СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(НСтр("ru='%1 пошел в %2'"), "Вася", "Зоопарк") = "Вася пошел в Зоопарк"
```

### 5.5. Секция «Варианты вызова»

Для функций с несколькими типами параметров:

```1c
// Варианты вызова:
//   УниверсальнаяПроцедура(Тип11, Тип21) - описание...
//   УниверсальнаяПроцедура(Тип12, Тип22) - описание...
```

### 5.6. Ссылки на другие объекты

```1c
// См. УправлениеДоступом.ЗаполнитьНаборыЗначенийДоступа
// Параметры:
//   НастройкиФормы - см. ПодключаемыеКомандыПереопределяемый.ПриОпределенииКоманд.НастройкиФормы
```

### 5.7. Устаревшие процедуры

```1c
// Устарела. Следует использовать см. ОбщегоНазначения.РазделениеВключено
Функция ИспользованиеРазделителяСеанса() Экспорт
```

---

## 6. Комментарий и директива компиляции

Сначала комментарий, потом директива:

```1c
// Обрабатывает параметры формы и заполняет реквизиты формы значениями.
//
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
```

---

## 7. Пустые строки

Код процедур и функций должен **отделяться пустыми строками**.

---

## Полный пример

```1c
// Определяет доступность ролей текущему пользователю,
// а также доступность административных прав.
//
// Параметры:
//   ИменаРолей - Строка - имена ролей через запятую.
//
// Возвращаемое значение:
//   Булево - Истина, если хотя бы одна роль доступна или есть админ. права.
//
// Пример:
//   Если РолиДоступны("ИспользованиеРассылокОтчетов,ОтправкаПоПочте") Тогда ...
//
Функция РолиДоступны(ИменаРолей) Экспорт
```

---

## Сводка

| Секция | Ключевое слово | Обязательность |
|--------|----------------|----------------|
| Описание | (без) | Для экспортных — да |
| Параметры | `Параметры:` | Если есть параметры |
| Возвращаемое значение | `Возвращаемое значение:` | Для функций |
| Пример | `Пример:` | Рекомендуется |
| Варианты вызова | `Варианты вызова:` | При необходимости |
| Устарела | `Устарела.` | При необходимости |
