# #std648 Ответственное чтение данных

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Определение

**Ответственное чтение** — любое чтение данных, на основе которого:
- Производятся изменения в информационной базе
- Принимаются решения

---

## 1.1. Когда требуется ответственное чтение

> Уточнение: управляемое приложение, обычное приложение.

Ответственное чтение должно выполняться **в транзакции** с предварительной установкой **управляемых блокировок**.

| Ситуация | Требуется |
|----------|-----------|
| Чтение при проведении для формирования движений | ✅ Да |
| Чтение для передачи в другую систему (Клиент-банк) | ✅ Да |
| Групповая обработка объектов (обновление ИБ) | ✅ Да* |

*Примечание: перед модификацией ссылочных объектов устанавливайте [пессимистичные объектные блокировки](#std490).

### ❌ Неправильно

```1c
// 1. Прочитать регистр сведений
Запрос = Новый Запрос(
    "ВЫБРАТЬ РАЗРЕШЕННЫЕ
    |  ЗаметкиПоПредмету.КоличествоЗаметок КАК КоличествоЗаметок
    |ИЗ
    |  РегистрСведений.ЗаметкиПоПредмету КАК ЗаметкиПоПредмету
    |ГДЕ
    |  ЗаметкиПоПредмету.Предмет = &Предмет");
Запрос.УстановитьПараметр("Предмет", ПредметЗаметок);
Выборка = Запрос.Выполнить().Выбрать();

КоличествоЗаметок = 0;
Если Выборка.Следующий() Тогда
    КоличествоЗаметок = Выборка.КоличествоЗаметок;
КонецЕсли;

// 2. Записать в регистр сведений
НаборЗаписей = РегистрыСведений.ЗаметкиПоПредмету.СоздатьНаборЗаписей();
НаборЗаписей.Отбор.Предмет.Установить(ПредметЗаметок);
НоваяЗапись = НаборЗаписей.Добавить();
НоваяЗапись.Предмет = ПредметЗаметок;
НоваяЗапись.КоличествоЗаметок = КоличествоЗаметок + 1;
НаборЗаписей.Записать();
```

### ✅ Правильно

```1c
// 1. Начать транзакцию для пакета из двух операций чтения и записи
НачатьТранзакцию();

Попытка
    // 2. Установить исключительную блокировку на диапазон записей,
    // чтобы гарантировать неизменность данных между чтением и записью
    БлокировкаДанных = Новый БлокировкаДанных;
    ЭлементБлокировкиДанных = БлокировкаДанных.Добавить("РегистрСведений.ЗаметкиПоПредмету");
    ЭлементБлокировкиДанных.УстановитьЗначение("Предмет", ПредметЗаметок);
    ЭлементБлокировкиДанных.Режим = РежимБлокировкиДанных.Исключительный;
    БлокировкаДанных.Заблокировать();

    // 3. Прочитать регистр сведений
    Запрос = Новый Запрос(
        "ВЫБРАТЬ РАЗРЕШЕННЫЕ
        |  ЗаметкиПоПредмету.КоличествоЗаметок КАК КоличествоЗаметок
        |ИЗ
        |  РегистрСведений.ЗаметкиПоПредмету КАК ЗаметкиПоПредмету
        |ГДЕ
        |  ЗаметкиПоПредмету.Предмет = &Предмет");
    Запрос.УстановитьПараметр("Предмет", ПредметЗаметок);
    Выборка = Запрос.Выполнить().Выбрать();

    КоличествоЗаметок = 0;
    Если Выборка.Следующий() Тогда
        КоличествоЗаметок = Выборка.КоличествоЗаметок;
    КонецЕсли;

    // 4. Записать в регистр сведений
    НаборЗаписей = РегистрыСведений.ЗаметкиПоПредмету.СоздатьНаборЗаписей();
    НаборЗаписей.Отбор.Предмет.Установить(ПредметЗаметок);
    НоваяЗапись = НаборЗаписей.Добавить();
    НоваяЗапись.Предмет = ПредметЗаметок;
    НоваяЗапись.КоличествоЗаметок = КоличествоЗаметок + 1;
    НаборЗаписей.Записать();

    ЗафиксироватьТранзакцию();

    // 5. При ошибке — отменить транзакцию и записать в журнал
    ОтменитьТранзакцию();
```

## 1.2. Когда ответственное чтение НЕ требуется

### По характеру задачи

| Ситуация | Причина |
|----------|---------|
| Динамические списки | Отображение, не изменение |
| Поиск данных | Отображение, не изменение |
| Большинство отчётов | Отображение, не изменение |

### По отсутствию конкуренции

| Ситуация | Причина |
|----------|---------|
| Условно постоянная информация | `ВалютаРегламентированногоУчета`, учётная политика |
| Монопольный режим | Обновление ИБ, первоначальное заполнение |
| Персональные данные пользователя | Только один пользователь имеет доступ |
| Мобильное приложение | Конкурентная работа исключена |

## 1.3. Системные транзакции

В обработчиках модификации данных код уже выполняется в **системной транзакции** платформы — явно открывать новую **не требуется**.

Обработчики, выполняющиеся в системной транзакции:
- **ПередЗаписью** (#std464)
- **ПриЗаписи** (#std465)
- **ПередУдалением** (#std752)

## 2. Выбор типа блокировки

> Уточнение: управляемое приложение, обычное приложение.

### 2.1. Исключительная блокировка

Используйте при чтении данных **с последующим изменением**.

⚠️ Без исключительной блокировки возможна **взаимоблокировка** (deadlock).

```1c
// 1. Исключительная блокировка для чтения с изменением
Блокировка = Новый БлокировкаДанных;
ЭлементБлокировки = Блокировка.Добавить("Справочник.Приказы");
ЭлементБлокировки.УстановитьЗначение("Ссылка", ПриказСсылка);
ЭлементБлокировки.Режим = РежимБлокировкиДанных.Исключительный; // по умолчанию
Блокировка.Заблокировать();

// 2. Получить объект
Объект = ПриказСсылка.ПолучитьОбъект();
Если Объект = Неопределено Тогда // может быть удалён в другом сеансе
    Возврат;
КонецЕсли;

// 3. Пессимистичная блокировка объекта
ЗаблокироватьДанныеДляРедактирования(ПриказСсылка);

// 4. Изменить и записать
Объект.Реквизит = ...
Объект.Записать();
```

### 2.2. Разделяемая блокировка

Используйте при чтении данных **без их изменения** (например, для формирования движений).

| Данные | Тип блокировки |
|--------|----------------|
| Читаемые (без изменения) | Разделяемая |
| Изменяемые | Исключительная |

```1c
// 1. Разделяемая блокировка для чтения нескольких связанных объектов
Блокировка = Новый БлокировкаДанных;
ЭлементБлокировки = Блокировка.Добавить("Справочник.Приказы");
ЭлементБлокировки.УстановитьЗначение("Ссылка", ПриказСсылка);
ЭлементБлокировки.Режим = РежимБлокировкиДанных.Разделяемый;
Блокировка.Заблокировать();

// 2. Прочитать первый объект — приказ
ПриказОбъект = ПриказСсылка.ПолучитьОбъект();

// 3. Прочитать второй объект — пользователя (автора приказа)
Блокировка = Новый БлокировкаДанных;
ЭлементБлокировки = Блокировка.Добавить("Справочник.Пользователи");
ЭлементБлокировки.УстановитьЗначение("Ссылка", ПриказОбъект.Автор);
ЭлементБлокировки.Режим = РежимБлокировкиДанных.Разделяемый;
Блокировка.Заблокировать();

АвторПриказа = ПриказОбъект.Автор.ПолучитьОбъект();
```

## Сводка

| Правило | Описание |
|---------|----------|
| Ответственное чтение | Чтение для изменения или принятия решений |
| Транзакция + блокировка | Обязательно перед ответственным чтением |
| Исключительная блокировка | При чтении с последующим изменением |
| Разделяемая блокировка | При чтении без изменения |
| Системная транзакция | В обработчиках ПередЗаписью, ПриЗаписи, ПередУдалением |
