# #std486 Использование модуля объекта, модуля менеджера и общих модулей

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

> ℹ️ Методическая рекомендация (полезный совет)

---

## 1. Модуль объекта

**Модуль объекта** предназначен для реализации поведения **отдельного экземпляра** объекта (`СправочникОбъект`, `ДокументОбъект` и т.п.).

В модуле объекта размещаются процедуры и функции, которые работают с данными объекта (`ЭтотОбъект` и переменные модуля объекта), в том числе когда он **ещё не записан** в информационную базу.

**Примеры:**

- Обработчики событий объекта
- Процедуры заполнения экземпляра объекта

**Важно:** для вызова экспортных процедур модуля объекта из других модулей может потребоваться предварительно получить экземпляр объекта с помощью метода `ПолучитьОбъект`. При этом происходит **загрузка объекта целиком** (вместе с табличными частями), что достаточно ресурсоёмко.

> См. также: Чтение отдельных реквизитов объекта из базы данных (#std496)

---

## 2. Модуль менеджера

**Модуль менеджера** объекта предназначен для размещения «статической» функциональности, которая логически связана с объектом метаданных, но **не зависит от состояния** конкретного экземпляра объекта данных.

**Примеры процедур и функций:**

- Относящиеся к **совокупности объектов**:
  - Функции для вывода на печать списка объектов
  - Функции, возвращающие информацию, общую для всех экземпляров
  - Процедуры обновления данных ИБ

- Работающие с объектом **по ссылке**:
  - Функции для получения печатной формы по ссылке
  - Процедуры формирования движений по ссылке

**Важно:** для выполнения функций модуля менеджера **не должен требоваться** экземпляр объекта данных (`СправочникОбъект`, `ДокументОбъект` и т.п.).

---

## 3. Общий модуль

Если функциональность **невозможно однозначно отнести** к тому или иному объекту метаданных (она логически общая для нескольких объектов), её следует размещать в **общем модуле**.

---

## Сводка

| Тип модуля | Назначение | Входные данные |
|------------|------------|----------------|
| **Модуль объекта** | Поведение экземпляра | `ЭтотОбъект` (может быть не записан) |
| **Модуль менеджера** | Статическая функциональность объекта | Ссылка или без параметров |
| **Общий модуль** | Функциональность нескольких объектов | Любые |
