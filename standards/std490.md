# #std490 Блокировка данных объекта для редактирования из кода

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Зачем блокировать объект

### 1.1. Требование

Перед изменением **существующего** объекта из кода — **заблокируйте** его.

**Цели блокировки:**
- Проверить, не заблокирован ли объект другими
- Предотвратить изменение другими сеансами (или другими экземплярами объекта в этом же сеансе)

**Без блокировки:** Пользователь может не сохранить свои изменения, если данные конкурентно изменены в другом сеансе.

### Важно понимать

Блокировка данных для редактирования **не запрещает** запись в других сеансах — она лишь не позволяет **одновременно** установить блокировку на одни и те же данные.

Это **пессимистическая** блокировка для конкурентной работы пользователей (отличается от транзакционных блокировок).

---

## 1.2. Как блокировать

Используйте:
- Метод объекта: `Заблокировать()`
- Глобальный метод: `ЗаблокироватьДанныеДляРедактирования(Ссылка)`

### Пример 1: Блокировка с выводом ошибки пользователю

```1c
ФайлОбъект = ДанныеФайла.Ссылка.ПолучитьОбъект();
// Блокируем объект; при неудаче — исключение с сообщением пользователю
ФайлОбъект.Заблокировать();
// Изменяем и записываем
ФайлОбъект.Редактирует = Справочники.Пользователи.ПустаяСсылка();
ФайлОбъект.Записать();
```

Или через глобальный метод:

```1c
ФайлОбъект = ДанныеФайла.Ссылка.ПолучитьОбъект();
ЗаблокироватьДанныеДляРедактирования(ДанныеФайла.Ссылка);
ФайлОбъект.Редактирует = Справочники.Пользователи.ПустаяСсылка();
ФайлОбъект.Записать();
```

### Пример 2: Пропуск объекта при блокировке (для фоновых заданий)

```1c
ФайлОбъект = ТекущаяВерсия.ПолучитьОбъект();
УстановитьПолноеНаименование = Истина;

Попытка
    ФайлОбъект.Заблокировать();
Исключение
    // Заблокирован — не изменяем, повторим позже
    УстановитьПолноеНаименование = Ложь;
    ЗаписьЖурналаРегистрации(НСтр("ru = 'Фоновое обновление имен файлов'", Метаданные.ОсновнойЯзык.КодЯзыка),
        УровеньЖурналаРегистрации.Предупреждение,, ФайлОбъект,
        ОбработкаОшибок.ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
КонецПопытки;

Если УстановитьПолноеНаименование Тогда
    ФайлОбъект.ПолноеНаименование = ПолноеНаименование;
    ФайлОбъект.Записать();
КонецЕсли;
```

---

## 1.3. Формы

При редактировании в формах платформа **автоматически** блокирует объект, указанный как **основной реквизит формы**.

---

## 2. Когда НЕ проверять блокировку

| Ситуация | Причина |
|----------|---------|
| Загрузка данных при обмене | Приоритет выше интерактивных действий |
| Обновление/первоначальное заполнение ИБ | Гарантированно монопольный режим |

---

## Сводка

| Правило | Описание |
|---------|----------|
| Блокировать перед изменением | `Заблокировать()` или `ЗаблокироватьДанныеДляРедактирования()` |
| Обработка отказа | Сообщение пользователю или пропуск с логированием |
| Формы | Платформа блокирует автоматически |
| Обмен данными | Блокировка не нужна |
