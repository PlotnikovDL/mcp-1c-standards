# #std444 Перенос выражений

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Максимальная длина строки

При длине строки более **120 символов** следует использовать переносы.

Строки длиннее 120 символов — только если перенос невозможен.

---

## 2. Арифметические выражения

- В одной строке может быть несколько операндов
- **Знаки операции — в начале строки** (не в конце предыдущей)
- Стандартный отступ или выравнивание по первому операнду

**Пример:**

```1c
СуммаДокумента = СуммаБезСкидки
               + СуммаРучнойСкидки
               + СуммаАвтоматическойСкидки;
```

**Или со стандартным отступом:**

```1c
СуммаДокумента = СуммаБезСкидки
    + СуммаРучнойСкидки
    + СуммаАвтоматическойСкидки;
```

## 3. Строковые константы

### 3.1. Многострочные строки с символом `|`

```1c
ТекстЗапроса =
"ВЫБРАТЬ РАЗРЕШЕННЫЕ
| ЗаметкиПоПредмету.КоличествоЗаметок КАК КоличествоЗаметок
|ИЗ
| РегистрСведений.ЗаметкиПоПредмету КАК ЗаметкиПоПредмету
|ГДЕ
| ЗаметкиПоПредмету.Предмет = &Предмет";
```

**Важно:** Не переносить строки с сообщениями пользователю (`СообщениеПользователю`).

### 3.2. Конкатенация коротких строк

Знак `+` — **в начале строки** (как в арифметических выражениях):

```1c
ПоляОтбора = "Номенклатура,Характеристика,Склад"
    + ДополнительныеПоляОтбора;
```

### 3.3. Конкатенация длинных строк (запросы)

Знак `+` можно писать **в конце строки**, чтобы не ломать форматирование:

```1c
ТекстЗапроса = ТекстЗапроса +
"ВЫБРАТЬ
| Номенклатура.Ссылка КАК Ссылка
|ИЗ
| Справочник.Номенклатура КАК Номенклатура";
```

## 4. Параметры процедур и функций

- Выравнивание по первому параметру или стандартный отступ
- Закрывающая скобка и `;` — на той же строке, что и последний параметр

**Пример (выравнивание по первому параметру):**

```1c
ИменаДокументов.Добавить(Метаданные.Документы.СтрокаВыпискиРасход.Имя,
                         Метаданные.Документы.СтрокаВыпискиРасход.Синоним);
```

**Пример (стандартный отступ):**

```1c
ИменаДокументов.Добавить(Метаданные.Документы.СтрокаВыпискиРасход.Имя,
    Метаданные.Документы.СтрокаВыпискиРасход.Синоним);
```

---

## 5. Логические условия в Если...КонецЕсли

- Каждое условие с новой строки, если > 120 символов
- **И, ИЛИ — в начале строки** (не в конце предыдущей)
- Стандартный отступ или выравнивание по первому условию

**Пример:**

```1c
Если (ВидОперации = Перечисления.ВидыОперацийПоступлениеМПЗ.ПоступлениеРозница)
    ИЛИ (ВидОперации = Перечисления.ВидыОперацийПоступлениеМПЗ.ПоступлениеРозницаКомиссия) Тогда
    Возврат Истина;
КонецЕсли;
```

**Сложное условие:**

```1c
Если ((СтруктураМодуля[Индекс].Блок = Перечисления.ТипыБлоковМодулей.ЗаголовокПроцедуры)
    ИЛИ (СтруктураМодуля[Индекс].Блок = Перечисления.ТипыБлоковМодулей.ЗаголовокФункции))
    И (Найти(ВРЕГ(СтруктураМодуля[Индекс].Текст), КлючБлока) > 0) Тогда
```

## 6. Автоформатирование

В конфигураторе: **Текст → Блок → Форматировать**

---

## Сводка

| Элемент | Правило |
|---------|---------|
| Макс. длина строки | **120 символов** |
| Знаки `+`, `-`, `*`, `/` | В начале новой строки |
| `И`, `ИЛИ` | В начале новой строки |
| Многострочные строки | Символ `\|` |
| Конкатенация запросов | `+` в конце строки допустим |
| Параметры функций | Выравнивание или стандартный отступ |
| `)` и `;` | На строке последнего параметра |
