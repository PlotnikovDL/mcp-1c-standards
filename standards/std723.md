# #std723 Особенности разработки конфигураций для ОС Linux и macOS

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Общий принцип

В большинстве случаев **специальных мер не требуется** для обеспечения работы конфигурации на Linux и macOS.

---

## 2. Использование кроссплатформенных механизмов

### 2.1. Замена COM-технологии

| Вместо COM | Использовать |
|------------|--------------|
| `v83.ComConnector` для администрирования кластера | Сервер администрирования (ras) и утилита (rac) |
| COM-объекты для путей к каталогам | `РабочийКаталогДанныхПользователя`, `КаталогДокументов`, `КаталогВременныхФайлов` |
| Другие COM-объекты | Технология Native API (внешние компоненты) |

⚠️ В macOS утилиты rac и ras **недоступны**.

### 2.2. Внешние компоненты

Внешние компоненты (клиентские и серверные) следует разрабатывать с использованием технологии **Native API**.

Это обеспечивает:
- Кроссплатформенность (Linux, macOS, Windows)
- Работу в веб-клиенте

### 2.3. Работа с почтой

| Вместо | Использовать |
|--------|--------------|
| Объект `Почта` | Объект `ИнтернетПочта` |
| — | Внешние компоненты для Linux/macOS |

### 2.4. Форматы изображений

| Заменить | На |
|----------|---|
| WMF (метафайл Windows) | PNG, JPG |
| EMF (метафайл Windows) | PNG, JPG |

### 2.5. Работа с файловой системой

#### 2.5.1. Регистрозависимость

В Linux имена файлов **регистрозависимые**. Во всех местах кода имя файла должно указываться **в одном регистре**.

#### 2.5.2. Разделители и маски

| Не использовать | Использовать |
|-----------------|--------------|
| `"/"` или `"\"` | `ПолучитьРазделительПути()` |
| `"*.*"` | `ПолучитьМаскуВсеФайлы()` |

При использовании БСП — функции из `ОбщегоНазначения` и `ОбщегоНазначенияКлиент`.

---

## 3. Второстепенные функции

Для второстепенных (сервисных) функций **допустимо отключать** работу в Linux и macOS.

**Примеры второстепенных функций:**
- Синхронизация через прямое подключение
- Импорт почты из сторонних клиентов

### 3.1. Способы ограничения

| Способ | Описание |
|--------|----------|
| Скрытие команд | Убрать из командного интерфейса |
| Сообщение | «<Операция> доступна только при работе в ОС Windows» |

### 3.2. Пример кода

```1c
&НаКлиенте
Процедура ОбработкаКоманды(ПараметрКоманды, ПараметрыВыполненияКоманды)

    Информация = Новый СистемнаяИнформация;

    Если Информация.ТипПлатформы <> ТипПлатформы.Windows_x86
        И Информация.ТипПлатформы <> ТипПлатформы.Windows_x86_64 Тогда

        ПоказатьПредупреждение(,
            НСтр("ru = 'Печать в Microsoft Word доступна только при работе в ОС Windows.'"));
        Возврат;

    КонецЕсли;

    // ...

КонецПроцедуры
```

### 3.3. Функции БСП для определения ОС

При использовании БСП — функции из `ОбщегоНазначения` и `ОбщегоНазначенияКлиент`:

| Функция | Назначение |
|---------|------------|
| `ЭтоLinuxКлиент()` | Проверка Linux |
| `ЭтоMacOSКлиент()` | Проверка macOS |
| `ЭтоWindowsКлиент()` | Проверка Windows |

## 4. Сводная таблица замен

| Windows-специфика | Кроссплатформенная альтернатива |
|-------------------|--------------------------------|
| `COMОбъект` | Native API, встроенные методы платформы |
| `v83.ComConnector` | ras/rac |
| `Почта` | `ИнтернетПочта` |
| WMF/EMF | PNG/JPG |
| `"/"`, `"\"` | `ПолучитьРазделительПути()` |
| `"*.*"` | `ПолучитьМаскуВсеФайлы()` |
| Жёсткие пути к каталогам | `РабочийКаталогДанныхПользователя()`, `КаталогДокументов()`, `КаталогВременныхФайлов()` |
