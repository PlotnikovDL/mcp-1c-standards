# #std679 Ограничение на установку признака «Вызов сервера» у общих модулей

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Принцип минимальных привилегий

**Не следует** всем общим модулям с признаком **Сервер** принудительно устанавливать флажок **Вызов сервера**.

В модулях с признаком **Вызов сервера** размещать только процедуры и функции, которые:
- Действительно предназначены для вызова из клиентского кода
- Гарантируют выполнение только разрешённых пользователю действий
- Передают на клиент только те данные, которые разрешены пользователю

### Пример

Серверная функция расчёта должна передавать на клиент **окончательный результат**, но не исходные или промежуточные данные, которые могут быть недоступны текущему пользователю.

### Особое внимание

Процедуры и функции, использующие:
- `УстановитьПривилегированныйРежим(Истина)`
- Размещённые в модулях с признаком **Привилегированный**

### Правило размещения

| Назначение процедуры | Куда размещать |
|----------------------|----------------|
| Для вызова с клиента | Модуль с **Вызов сервера** |
| Только для сервера | Модуль **без** признака **Вызов сервера** |

---

## 2. Работа с объектами в управляемом режиме

### 2.1. Объекты только на сервере

В управляемом режиме работа с экземплярами объектов (`СправочникОбъект`, `ДокументОбъект` и т.д.) выполняется **на стороне сервера**. Возможность работы с ними на клиенте не гарантируется.

**Не следует** в толстом клиенте (управляемое приложение) создавать или получать объекты:

| Где | Почему нельзя |
|-----|---------------|
| В клиентских общих модулях (через `#Если ТолстыйКлиентУправляемоеПриложение`) | Код модулей объектов выполнится на клиенте |
| В обычных формах при запуске в управляемом режиме | Избыточные серверные вызовы |

**Цель:** избежать выполнения кода модулей объектов и подписок на события на клиенте, а также избыточных серверных вызовов.

### 2.2. Настройка конфигурации

Если конфигурация **не рассчитана** на работу в толстом клиенте (управляемое приложение):

Снять флажок **Толстый клиент (управляемое приложение, режим клиент-сервер)** — для избежания ложных сообщений об ошибках при проверке конфигурации.

---

## Сводка

| Правило | Описание |
|---------|----------|
| Не ставить **Вызов сервера** всем модулям | Только тем, что реально вызываются с клиента |
| Возвращать только итоговый результат | Не передавать исходные/промежуточные данные |
| Привилегированный код | Особый контроль, минимизация |
| Объекты в управляемом режиме | Работать только на сервере |
| Толстый клиент | Не создавать объекты в клиентском коде |
