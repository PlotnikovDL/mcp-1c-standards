# #std556 Начальные действия при работе конфигурации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Общие требования

В конфигурации должен быть предусмотрен механизм, который автоматически:

| Событие | Действие |
|---------|----------|
| Первый запуск конфигурации | Первоначальное заполнение ИБ минимально необходимыми данными |
| Первый запуск нового релиза | Обновление данных ИБ (миграция) |

При использовании **Библиотеки стандартных подсистем** — применять подсистему **«Обновление версии ИБ»**.

---

## 2. Первоначальное заполнение (рекомендация)

Первоначальное заполнение ИБ может быть разделено:

| Тип | Описание |
|-----|----------|
| **Обязательное** | Без этих данных конфигурация не будет работать |
| **Необязательное** | Облегчает начало эксплуатации, но не критично |

---

## 3. Информирование администратора (рекомендация)

По результатам обработки ИБ рекомендуется выводить:
- При первом запуске — **описание конфигурации**
- При обновлении — **описание изменений в версии**

---

## 4. Контроль ошибок

Ситуации, когда обработка не проведена в требуемом объёме, **должны контролироваться**:

- Пользователю выводится **предупреждение** о проблемной ситуации
- Подробный протокол — в **журнал регистрации**

---

## 5. Работа в РИБ (распределённая ИБ)

### 5.1. Требования к логике обновления в подчинённых узлах

Обновление данных должно:
- Выполняться **после загрузки** уже обновлённых данных из главного узла
- **Исключать повторную обработку** одних и тех же данных
- **Исключать повторное создание** новых данных
- Корректно отрабатывать при повторном запуске

### 5.2. Последствия нарушения

| Проблема | Последствие |
|----------|-------------|
| Безусловное создание данных | Многократное создание в каждом узле и размножение при обмене |
| Безусловное изменение данных | Регистрация к выгрузке обратно в главный узел, избыточная нагрузка на канал |

### 5.3. Пример кода

**Неправильно** — безусловное создание:

```1c
ПрофильОбъект = Справочники.ПрофилиГруппДоступа.СоздатьЭлемент();
ПрофильОбъект.Наименование = НСтр("ru = 'Бухгалтер'");
ПрофильОбъект.Предустановленный = Истина;
ПрофильОбъект.Записать();
```

**Правильно** — проверка перед созданием:

```1c
НаименованиеПрофиля = НСтр("ru = 'Бухгалтер'");

Запрос = Новый Запрос(
    "ВЫБРАТЬ
    | ИСТИНА
    |ИЗ
    | Справочник.ПрофилиГруппДоступа КАК ПрофилиГруппДоступа
    |ГДЕ
    | ПрофилиГруппДоступа.Наименование = &Наименование И
    | ПрофилиГруппДоступа.Предустановленный = ИСТИНА");

Запрос.УстановитьПараметр("Наименование", НаименованиеПрофиля);

// Если элемента нет, только тогда нужно создать новый
Если Запрос.Выполнить().Пустой() Тогда
    ПрофильОбъект = Справочники.ПрофилиГруппДоступа.СоздатьЭлемент();
    ПрофильОбъект.Наименование = НаименованиеПрофиля;
    ПрофильОбъект.Предустановленный = Истина;
    ПрофильОбъект.Записать();
КонецЕсли;
```
