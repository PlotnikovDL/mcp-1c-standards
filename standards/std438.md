# #std438 Проверка на пустой результат выполнения запроса

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Метод Пустой()

Проверку отсутствия строк в результате запроса выполняйте методом **Пустой()**.

Получение выборки или выгрузка в таблицу значений занимает **дополнительное время**.

### Пример

❌ **Неправильно** (избыточное получение выборки):

```1c
Выборка = Запрос.Выполнить().Выбрать();
Если Выборка.Следующий() Тогда
    Возврат Истина;
Иначе
    Возврат Ложь;
КонецЕсли;
```

✅ **Правильно** (метод Пустой):

```1c
Возврат НЕ Запрос.Выполнить().Пустой()
```

---

## 2. Когда Пустой() не нужен (рекомендация)

Если требуется **выбрать или выгрузить** результат запроса — предварительный вызов `Пустой()` **избыточен**.

❌ **Избыточно:**

```1c
РезультатЗапроса = Запрос.Выполнить();
Если НЕ РезультатЗапроса.Пустой() Тогда  // лишний вызов
    Выборка = РезультатЗапроса.Выбрать();
    Пока Выборка.Следующий() Цикл
        ...
```

✅ **Правильно:**

```1c
Выборка = Запрос.Выполнить().Выбрать();
Пока Выборка.Следующий() Цикл
    ...
```

---

## 3. Сводка

| Задача | Решение |
|--------|---------|
| Только проверить наличие данных | `Запрос.Выполнить().Пустой()` |
| Обработать данные | Сразу `Выбрать()` / `Выгрузить()` без предварительной проверки |
