# #std782 Массовая конкатенация строк

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## Рекомендация

При **массовых** операциях конкатенации строк следует использовать методы платформы **СтрРазделить** и **СтрСоединить**.

Такая обработка данных:
- **Быстрее** выполняется
- **Снижает потребление** оперативной памяти

---

## Примеры

**❌ Неправильно:**

```1c
Для НомерКолонки = 1 По Макет.ШиринаТаблицы Цикл
    ИзвлеченныйТекст = ИзвлеченныйТекст + Символы.ПС + ТекстОбласти;
    // …
КонецЦикла;
```

**✅ Правильно:**

```1c
ИзвлеченныеТексты = Новый Массив;
Для НомерКолонки = 1 По Макет.ШиринаТаблицы Цикл
    ИзвлеченныеТексты.Добавить(ТекстОбласти);
    // …
КонецЦикла;
ИзвлеченныйТекст = СтрСоединить(ИзвлеченныеТексты, Символы.ПС);
```

---

## Когда применять

Следует ориентироваться на **1000 операций и более**.

При увеличении длины строк порог может быть ещё меньше — чем строки длиннее, тем операции выполняются дольше.

**Особое внимание:**
- Конкатенация в циклах
- Универсальные механизмы на больших объёмах данных

**Не следует** отказываться от обычной конкатенации в остальных случаях — это снижает читаемость кода.

---

## Сводка

| Способ | Производительность | Память | Когда использовать |
|--------|-------------------|--------|-------------------|
| `Строка + Строка` в цикле | ❌ Медленно | ❌ Много | Единичные операции |
| `Массив` + `СтрСоединить` | ✅ Быстро | ✅ Меньше | 1000+ операций |
