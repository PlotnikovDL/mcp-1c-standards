# #std746 Обработчики событий ОбработкаПолученияПредставления и ОбработкаПолученияПолейПредставления

> Область применения: управляемое приложение, мобильное приложение.

---

## 1. Назначение обработчиков

С помощью обработчиков **модуля менеджера** можно переопределить представление объекта ИБ, которое выводится:
- В полях форм
- В списках

---

## 2. Пример реализации

```1c
Процедура ОбработкаПолученияПолейПредставления(Поля, СтандартнаяОбработка)
    Поля.Добавить("Наименование");
    Поля.Добавить("Дата");
    СтандартнаяОбработка = Ложь;
КонецПроцедуры

Процедура ОбработкаПолученияПредставления(Данные, Представление, СтандартнаяОбработка)
    Наименование = ?(ПустаяСтрока(Данные.Наименование),
        НСтр("ru = 'Без описания'"), Данные.Наименование);
    Дата = Формат(Данные.Дата,
        ?(ПолучитьФункциональнуюОпцию("ИспользоватьДатуИВремяВСрокахЗадач"),
            "ДЛФ=DT", "ДЛФ=D"));
    Представление = СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(
        НСтр("ru = '%1 от %2'"), Наименование, Дата);
    СтандартнаяОбработка = Ложь;
КонецПроцедуры
```

---

## 3. Ограничения производительности

⚠️ Обработчики вызываются **при любой необходимости** получения представления. Избыточные данные или неправильный выбор могут **существенно замедлить** работу системы.

### 3.1. Запрещённые действия

| Действие | Причина |
|----------|---------|
| ⛔ Выполнять запросы | Замедление работы |
| ⛔ Получать объекты ИБ | Чтение всего объекта из БД |
| ⛔ Обращаться к реквизитам ссылочных типов через точку | Читает весь объект целиком |
| ⛔ Использовать `ПолучитьПредставление()` для ссылок | Дополнительные запросы к БД |

---

## 4. Обмен данными

### 4.1. Вызов при обмене

Обработчики могут вызываться при записи и удалении объекта **в режиме обмена данными**. Представление запрашивается для формирования записи в **журнал регистрации**.

### 4.2. Ограничения

⛔ **Недопустимо** обращаться к предопределённым элементам, которые:
- Ещё не загружены в базу
- Уже удалены в ходе обмена данными

**Неправильный пример:**

```1c
// ⛔ Обращение к предопределённому элементу
Процедура ОбработкаПолученияПредставления(Данные, Представление, СтандартнаяОбработка)

    СтандартнаяОбработка = Ложь;
    // ⛔ Предопределённый элемент может не существовать при обмене
    Если Данные.ВидОбразования = Справочники.ВидыОбразованияФизическихЛиц.ПослевузовскоеОбразование Тогда
        Представление = НСтр("ru = 'Послевузовское образование'");
    Иначе
        ...
```

## 5. Толстый клиент

При реализации обработчиков учитывать требования поддержки **толстого клиента** (управляемое приложение, клиент-сервер) — см. #std680.

---

## 6. Сводная таблица

| Аспект | Рекомендация |
|--------|--------------|
| Данные в `ОбработкаПолученияПолейПредставления` | Только минимально необходимые поля |
| Запросы и получение объектов | ⛔ Запрещено |
| Обращение через точку | ⛔ Запрещено |
| Предопределённые элементы | ⛔ Запрещено (могут отсутствовать при обмене) |
| Толстый клиент | Учитывать требования #std680 |
