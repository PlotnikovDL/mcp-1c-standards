# #std765 Элементы форм: требования по локализации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Реквизиты формы с локализуемыми значениями

Нельзя присваивать реквизитам, используемым в элементах формы, строковые значения, не прошедшие локализацию.

**Рекомендации:**
- Использовать **списки значений**, в которых для каждого значения задаётся локализуемое представление
- Использовать **перечисления**, если они используются в таблицах базы данных

### Неправильный подход

> На скриншоте: реквизит формы «Режим» с типом «Строка», при этом в коде используются строковые литералы.

❌ **Неправильно:**

```1c
Если Режим = "Рабочий" Тогда
    Режим = "Демо";
Иначе
    Режим = "Рабочий";
КонецЕсли;
```

### Правильный подход — список значений

> На скриншоте: реквизит «ВариантЗаполнения» с типом «Строка» и настроенным списком выбора. В списке выбора: Значение = «Набор» → Представление = «Как набор», Значение = «Комплект» → Представление = «По комплекту», Значение = «Спецификация» → Представление = «По спецификации».

### Правильный подход — перечисление

> На скриншоте: реквизит «Режим» с типом «ПеречислениеСсылка.Режимы...»

✅ **Правильно:**

```1c
Если Режим = Перечисления.РежимыРаботы.Рабочий Тогда
    Режим = Перечисления.РежимыРаботы.Демо;
Иначе
    Режим = Перечисления.РежимыРаботы.Рабочий;
КонецЕсли;
```

## 2. Заголовки таблиц и групп на формах

> *Методическая рекомендация (полезный совет)*

Для всех таблиц и групп на формах необходимо **указывать заголовки**, и, если эти заголовки не нужно показывать пользователю, в свойствах элемента формы **в явном виде убирать отображение заголовка**.

**Причина:** Если заголовок не указан, при использовании команды **Изменить форму** пользователь увидит заголовки, автоматически сгенерированные из имён элементов формы. Перевести их будет невозможно, потому что такие заголовки попадут в выгрузку на перевод как пустые.

### Неправильно

> На скриншоте: группа «ГруппаШапка» без заголовка. В окне пользовательской настройки формы отображается как «Header» (автосгенерированное имя).

### Правильно

> На скриншоте: группа «ГруппаШапка» с заголовком «Шапка» и снятым флажком «Отображать заголовок». В окне пользовательской настройки формы отображается как «Шапка».

**Инструмент:** Для автоматической расстановки заголовков можно воспользоваться обработкой автоформатирования кода и локализации.

## 3. Уменьшение незначащей информации

Следует уменьшать количество незначащей информации, подлежащей локализации.

### 3.1. Бессмысленные подсказки у групп

Удалять бессмысленные подсказки у групп форм.

**Причины:**
- Удешевление перевода
- Пользователь может увидеть такие подсказки при изменении формы

> На скриншотах: неправильно — у группы «ГруппаШапка» заполнено поле «Подсказка»; правильно — поле «Подсказка» очищено.

### 3.2. Заголовки неотображаемых реквизитов

У реквизитов формы, не размещённых на форме в виде элементов управления, следует **очищать заголовки**, т.к. они не видны пользователю. Как правило, это служебные реквизиты, используемые для технологических целей.

---

## 4. Заголовки колонок динамического списка

Следует задавать заголовок для колонок динамического списка, получающихся в запросе комбинацией других колонок или для которых задан свой псевдоним. **Нельзя опираться на автоматически сгенерированный заголовок** по имени/псевдониму.

### Примеры, когда заголовок следует задавать явно

```1c
ВЫБРАТЬ
    Таблица.Поле1 КАК Поле2
    ВЫРАЗИТЬ(Таблица.Поле1 КАК СТРОКА(100)) КАК Поле3
```

**Причины:**
- Когда поле создаётся в запросе и ему присваивается имя, синоним не «подтягивается» автоматически из метаданных
- Инструмент редактирования текстов интерфейсов не находит заголовок для колонок с псевдонимом
- Имена колонок выводятся пользователю при настройке полей формы (команда **Ещё** → **Изменить форму...**)

> На скриншоте: колонка «ЦенаВалюта» с заголовком «Цена (валютная)», в диалоге «Строки на разных языках» заданы переводы: English = «Price (currency)», Русский = «Цена (валютная)».

---

## 5. Режим выбора из списка

В полях форм со списками выбора следует **всегда устанавливать** свойство **РежимВыбораИзСписка** в значение **Истина**.

В этом случае в поле будет корректно выводиться локализуемое представление, а не значение из списка выбора.

---

## Сводка

| Правило | Описание |
|---------|----------|
| Реквизиты формы | Использовать списки значений с представлениями или перечисления |
| Заголовки групп/таблиц | Задавать явно, скрывать через «Отображать заголовок» |
| Подсказки групп | Удалять бессмысленные |
| Служебные реквизиты | Очищать заголовки неотображаемых реквизитов |
| Колонки динамического списка | Задавать заголовок для вычисляемых/с псевдонимом |
| РежимВыбораИзСписка | Устанавливать в Истина для полей со списками выбора |
