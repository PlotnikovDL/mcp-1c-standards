# #std658 Эффективные условия запросов

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Основное и дополнительное условие

**Основное условие** — максимально ограничивает выборку, использует индексы, части объединены по `И`.

**Дополнительное условие** — объединено с основным по `И`, может быть любой сложности.

### 1.1. Допустимые операции в основном условии

| Поля индекса | Допустимые операции |
|--------------|---------------------|
| Первые и промежуточные | Только `=` и `И` |
| Последнее или единственное | `=`, `>`, `<`, `>=`, `<=`, `ПОДОБНО`, `МЕЖДУ`, `В`, `ИЛИ` (приводимое к `В`) |

⛔ **Нельзя в основном условии:** арифметические операции, функции, отрицания, неравенства (`<>`).

### 1.2. Какие поля индексировать

| Секция | Индексировать |
|--------|---------------|
| `ГДЕ` / виртуальная таблица | Поля основной таблицы выборки |
| `ПО` ЛЕВОГО соединения | Поля **правой** таблицы |
| `ПО` ВНУТРЕННЕГО соединения | Поля таблицы с **большим** количеством записей |

### 1.3. Исключения

- Таблицы с <1000 записей
- Запросы выполняются очень редко

## 2. Оператор ИЛИ

### 2.1. В основном условии

✅ **Правильно** (можно привести к `В`):
```1c
ГДЕ
    Таблица.Поле = &Значение1
    ИЛИ Таблица.Поле = &Значение2
```

❌ **Неправильно** (разные поля):
```1c
ГДЕ
    Таблица.Поле1 = &Значение1
    ИЛИ Таблица.Поле2 = &Значение2
```

**Решение** — `ОБЪЕДИНИТЬ ВСЕ`:
```1c
ВЫБРАТЬ ... ГДЕ Таблица.Поле1 = &Значение1
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ ... ГДЕ Таблица.Поле2 = &Значение2
```

### 2.2. В дополнительном условии

✅ **Правильно:**
```1c
ГДЕ
    Таблица.Поле1 = &Значение1  // Основное (индекс)
    И (Таблица.Поле2 = &Значение2 ИЛИ Таблица.Поле3 = &Значение3)  // Дополнительное
```

---

## 3. Оператор ПОДОБНО

Можно использовать вместо `ПОДСТРОКА` в основном условии.

❌ **Неправильно:**
```1c
ГДЕ ПОДСТРОКА(Таблица.Поле, 1, 6) = "строка"
```

✅ **Правильно:**
```1c
ГДЕ Таблица.Поле ПОДОБНО "строка%"
```

⚠️ Литерал **не должен** начинаться с `_` или `%`.

---

## 4. Оператор МЕЖДУ

Можно использовать вместо функций дат.

❌ **Неправильно:**
```1c
ГДЕ МЕСЯЦ(Таблица.Поле) = 1
```

✅ **Правильно:**
```1c
ГДЕ Таблица.Поле МЕЖДУ &ДатаНачалаМесяца И &ДатаКонцаМесяца
```

---

## 5. Выражение ВЫБОР

Только в **дополнительном** условии.

✅ **Правильно:**
```1c
ГДЕ
    Таблица.Поле1 = &Значение1  // Основное (индекс)
    И ВЫБОР  // Дополнительное
        КОГДА Таблица.Поле2 = &Значение2
            ТОГДА Таблица.Поле3 = &Значение3
        ИНАЧЕ Таблица.Поле4 = &Значение4
    КОНЕЦ
```

---

## 6. Арифметические операции

Только в **дополнительном** условии.

❌ **Неправильно:**
```1c
ГДЕ Таблица.Поле1 - 1 > 0
```

✅ **Правильно:**
```1c
ГДЕ
    Таблица.Поле1 = &Значение1  // Основное
    И Таблица.Поле2 - 1 > 0  // Дополнительное
```

---

## 7. RLS и роли

Не назначайте одному пользователю **несколько ролей** с разным RLS для одного объекта.

**Причина:** Разные RLS объединяются через `ИЛИ` → неоптимальный запрос.

**Решения:**
- Одна роль на один объект
- Одинаковые условия RLS в разных ролях для одного объекта

---

## 8. Сводка

| Что | Основное условие | Дополнительное условие |
|-----|------------------|------------------------|
| `=`, `И` | ✅ | ✅ |
| `>`, `<`, `>=`, `<=` | ✅ (последнее поле) | ✅ |
| `В`, `МЕЖДУ`, `ПОДОБНО` | ✅ (последнее поле) | ✅ |
| `ИЛИ` | ✅ (только если → `В`) | ✅ |
| `<>`, `НЕ` | ❌ | ✅ |
| Функции | ❌ | ✅ |
| Арифметика | ❌ | ✅ |
| `ВЫБОР` | ❌ | ✅ |
