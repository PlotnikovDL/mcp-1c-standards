# #std488 Стандартные роли

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Общие положения

### 1.1. Роли для разграничения прав

Если в конфигурации есть разграничение прав доступа пользователей к данным, то настройку доступа следует выполнять с помощью **ролей**. Роли создаются разработчиком исходя из задачи ограничения доступа пользователей к данным.

### 1.2. Подходы к созданию ролей

**Простейший случай:** роли соответствуют должностным обязанностям (`Директор`, `Бухгалтер`, `Кладовщик` и т.п.).

**Тонкая настройка:** роли соответствуют «мелким» функциям, совокупность которых образует набор прав для категории пользователей. Пользователям назначается комбинация ролей (например, `ЧтениеПроизводственныхДокументов`, `ДобавлениеИзменениеСкладскихДокументов`, `ЧтениеНСИ`).

При использовании БСП — подсистема **«Управление доступом»** для типовых комбинаций ролей (профилей).

## 2. Обязательные роли

В конфигурации должны быть определены **три обязательные роли**:

### 2.1. ПолныеПрава (FullAccess)

Предоставляет неограниченный доступ ко всем «прикладным» данным, но **не даёт** прав на администрирование ИБ в целом.

**Должна:**
- Позволять самостоятельное использование (может быть назначена пользователям)
- Предоставлять неограниченный доступ ко всем данным области (разделённым данным), кроме права интерактивного удаления
- Позволять все административные действия с областью данных

**Включает права:**
- Администрирование данных
- Активные пользователи
- Журнал регистрации
- Монопольный режим
- Тонкий клиент
- Веб-клиент
- Сохранение данных пользователя
- Вывод

**В модели сервиса:** назначается администраторам абонентов (областей данных).

**В локальном режиме:** назначается совместно с ролью `АдминистраторСистемы`.

### 2.2. АдминистраторСистемы (SystemAdministrator)

Предоставляет дополнительные права на администрирование ИБ в целом (обновление конфигурации, работа в конфигураторе и т.п.).

**Должна:**
- Назначаться **только совместно** с ролью `ПолныеПрава`
- Предоставлять неограниченный доступ ко всем неразделённым данным
- Содержать все права доступа к объектам (кроме интерактивного удаления)
- Включать все права к корню конфигурации (`Администрирование`, `Администрирование данных`), **кроме** `Интерактивное открытие внешних отчетов` и `Интерактивное открытие внешних обработок`

### 2.3. ИнтерактивноеОткрытиеВнешнихОтчетовИОбработок (InteractiveOpenExternalReportsAndDataProcessors)

Предоставляет дополнительные права на открытие внешних отчётов и обработок через меню «Файл → Открыть».

**Включает права:**
- Интерактивное открытие внешних отчетов
- Интерактивное открытие внешних обработок

**В локальном режиме:** назначается администраторам, но может быть запрещена для повышения безопасности.

**В модели сервиса:** все три роли назначаются администраторам сервиса.

### 2.4. Основные роли конфигурации

Роли `ПолныеПрава`, `АдминистраторСистемы` и `ИнтерактивноеОткрытиеВнешнихОтчетовИОбработок` должны быть установлены как **основные роли конфигурации** (свойство `ОсновныеРоли`).

### 2.5. Удаление помеченных объектов (рекомендация)

При необходимости дать возможность удаления объектов «неполноправным» пользователям — добавить роль **УдалениеПомеченныхОбъектов** (`DeleteMarkedObjects`). Назначается совместно с остальными ролями.

## 3. Роли для настройки общих прав

Если необходимо настраивать общие права работы с ИБ — создать отдельные роли. Они не предназначены для самостоятельного использования.

Конфигурация должна работать как при наличии, так и при отсутствии любой из этих ролей.

| Роль | Англ. | Права |
|------|-------|-------|
| **Администрирование** | Administration | Администрирование, Администрирование данных, Администрирование расширений конфигурации, Активные пользователи |
| **ВыводНаПринтерФайлБуферОбмена** | OutputToPrinterFileClipboard | Вывод |
| **ЗапускAutomation** | StartAutomation | Automation |
| **ЗапускВебКлиента** | StartWebClient | Веб-клиент |
| **ЗапускВнешнегоСоединения** | StartExternalConnection | Внешнее соединение |
| **ЗапускТолстогоКлиента** | StartThickClient | Толстый клиент |
| **ЗапускТонкогоКлиента** | StartThinClient | Тонкий клиент |
| **ИнтерактивноеОткрытиеВнешнихОтчетовИОбработок** | InteractiveOpenExternalReportsAndDataProcessors | Интерактивное открытие внешних обработок, Интерактивное открытие внешних отчетов |
| **ОбновлениеКонфигурацииБазыДанных** | UpdateDatabaseConfiguration | Обновление конфигурации базы данных |
| **ПросмотрЖурналаРегистрации** | ViewEventLog | Журнал регистрации |
| **РежимТехническогоСпециалиста** | TechnicalSpecialistMode | Режим технического специалиста |
| **СохранениеДанныхПользователя** | SaveUserData | Сохранение данных пользователя |

### 3.12. Особенности роли СохранениеДанныхПользователя

Рекомендуется предоставлять всем категориям пользователей, **за исключением** случаев, когда требуется запретить персональные настройки (внешние/временные пользователи, работа под одной учётной записью).

Конфигурация должна работать без этой роли:
- Код обращения к хранилищам настроек (`ХранилищеОбщихНастроек`, `ХранилищеВариантовОтчетов` и др.) должен быть пропущен
- Интерфейсы для работы с настройками («Запомнить мой выбор» и пр.) не должны быть доступны

При использовании БСП: `ХранилищеОбщихНастроекЗагрузить` и `ХранилищеОбщихНастроекСохранить` модуля `ОбщегоНазначения`.

## 4. Роли только для просмотра

### 4.1. Когда нужны

Для пользователей с временным или постоянным доступом на просмотр всех данных без ограничений (аудитор, собственник, директор).

### 4.2. Роль ТолькоПросмотр (ViewOnly)

В простейшем случае (роли соответствуют должностям) — добавить роль **ТолькоПросмотр**.

**Включает права:**
- Чтение
- Использование
- Просмотр
- Ввод по строке (если применимо)

Для большинства объектов метаданных, кроме технологических данных.

### 4.3. Комбинации ролей на чтение

В конфигурациях с «мелкими» ролями — назначать комбинацию ролей чтения (`ЧтениеПроизводственныхДокументов`, `ЧтениеСкладскихДокументов`, `ЧтениеКассовыхДокументов`).

Для неограниченного доступа — отключать условия RLS.

---

## 5. Запрещённые права

❌ Ни в одной роли (включая `ПолныеПрава` и `АдминистраторСистемы`) **не должно быть**:

- Право интерактивного удаления
- Интерактивное удаление предопределённых данных
- Интерактивная пометка удаления предопределённых данных
- Интерактивное снятие пометки удаления предопределённых данных
- Интерактивное удаление помеченных предопределённых данных

**Право удаления** оставить только в ролях `ПолныеПрава` и `АдминистраторСистемы`.

---

## 6. Стандартные роли в расширениях конфигурации

❌ **Не рекомендуется** заимствовать и изменять роли `АдминистраторСистемы` и `ПолныеПрава`.

✅ **Вместо этого** — добавить собственные роли:

### 6.1. Простейший случай (права одинаковы для всех)

Создать одну роль, включить в основные роли расширения:

```
<ПрефиксРасширения>ОбщиеПрава
```

### 6.2. Права различаются для администратора и пользователей

Создать две роли:

```
<ПрефиксРасширения>ПолныеПрава     (включить в основные роли)
<ПрефиксРасширения>БазовыеПрава
```

### 6.3. Права различаются для администратора, пользователей и внешних пользователей

Создать три роли:

```
<ПрефиксРасширения>ПолныеПрава                      (включить в основные роли)
<ПрефиксРасширения>БазовыеПрава
<ПрефиксРасширения>БазовыеПраваВнешнихПользователей
```

### 6.4. Автоматическое включение в профили (БСП)

| Роль расширения | Включается в профили с ролью |
|-----------------|------------------------------|
| \<Префикс\>ОбщиеПрава | БазовыеПраваБСП, БазовыеПраваВнешнихПользователейБСП, ПолныеПрава |
| \<Префикс\>БазовыеПрава | БазовыеПраваБСП |
| \<Префикс\>БазовыеПраваВнешнихПользователей | БазовыеПраваВнешнихПользователейБСП |
| \<Префикс\>ПолныеПрава | ПолныеПрава |

Дополнительные прикладные роли не включаются автоматически — назначаются программно или интерактивно.

### 6.5. Без использования БСП

Роли расширений назначать пользователям программно или интерактивно.

## Сводка

| Роль | Назначение | Самостоятельное использование |
|------|------------|-------------------------------|
| **ПолныеПрава** | Полный доступ к прикладным данным | ✅ Да |
| **АдминистраторСистемы** | Администрирование ИБ | ❌ Только с ПолныеПрава |
| **ИнтерактивноеОткрытиеВнешнихОтчетовИОбработок** | Открытие внешних обработок | ❌ Только с ПолныеПрава |
| **ТолькоПросмотр** | Просмотр всех данных | ✅ Да |
| **УдалениеПомеченныхОбъектов** | Удаление помеченных | ❌ Совместно с другими |

| Запрещённые права |
|-------------------|
| Интерактивное удаление |
| Интерактивное удаление/пометка/снятие пометки предопределённых данных |
