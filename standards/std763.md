# #std763 Форматирование даты, числа, Булево: требования по локализации

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Функция Формат и НСтр

При использовании функции **Формат** в некоторых случаях следует использовать функцию **НСтр** при создании форматной строки (формат представления или редактирования дат, Булево значения и т.п.).

**Важно:** Форматная строка, задаваемая в свойствах метаданных (форм), подлежит локализации всегда, так же как синоним.

---

### 1.1. Форматирование дат

При выводе дат следует учитывать, что в различных странах приняты различные порядок следования и разделители для составных частей даты.

| Страна | Пример |
|--------|--------|
| Россия | 20.12.2012 |
| США | 12/20/2012 |

**Рекомендация:** Вместо явного задания формата даты использовать **локальный формат даты (ДЛФ)**.

Когда использовать локальный формат не получается и требуется задать произвольный формат (ДФ) или указать представление пустой даты (ДП), нужно применять функцию **НСтр** к форматной строке.

❌ **Неправильно:**

```1c
Формат(ДатаУтверждения, "ДФ=дд.ММ.гггг");
Формат(ДатаУтверждения, "ДФ=ММММ гггг") + " г.";
```

✅ **Правильно:**

```1c
Формат(ДатаУтверждения, "ДЛФ=ДД");
Формат(ДатаУтверждения, НСтр("ru='ДФ=''ММММ гггг ""г.""'''"));
```

---

### 1.2. Форматирование числа

Следует применять функцию **НСтр** к форматной строке в случаях:

- Для числа задаётся нечисловое представление нулевого значения (**ЧН**)
- Указан шаблон форматирования числа (**ЧФ**)
- Переопределяется разделитель дробной части (**ЧРД**)

❌ **Неправильно:**

```1c
Предупреждение(Формат(100, "ЧН=Отсутствует"));
Предупреждение(Формат(100, "ЧФ=""$Ч' / Час'"""));
```

✅ **Правильно:**

```1c
Предупреждение(Формат(100, НСтр("ru = 'ЧН=Отсутствует'")));
Предупреждение(Формат(100, НСтр("ru = 'ЧФ=""$Ч'' / Час''""'"))); // "$100 / Час"
```

---

### 1.3. Форматирование Булево

Для вывода Булево значения пользователю **всегда** применяйте функцию **НСтр** к форматной строке.

❌ **Неправильно:**

```1c
Предупреждение(Формат(Истина, "БЛ=Нет; БИ=Да"));
```

✅ **Правильно:**

```1c
Предупреждение(Формат(Истина, НСтр("ru='БЛ=Нет; БИ=Да'")));
```

---

### 1.4. Запрет параметра «L=»

Не следует переопределять поведение отображения локализации данных по умолчанию — формат отображения операционной системы. При использовании функции **Формат** следует **избегать** использовать параметр `«L=»`.

---

## 2. Формат в полях ввода и отчётах СКД

При задании формата в полях ввода в формах и полях отчётов на базе СКД также рекомендуется **локальный формат даты**.

Использовать другие форматы допустимо, если по сути решаемой задачи локальный формат не подходит — тогда форматная строка будет переводиться при переводе конфигурации.

---

## 3. Представления полей в отчётах СКД

При переопределении стандартных представлений полей в отчётах на базе СКД следует придерживаться тех же правил, что и в коде модулей.

❌ **Неправильно:**

```1c
"N " + ВОтветНаНомер + " от " + Формат(ВОтветНаДата, "ДФ=dd.MM.yyyy")
```

✅ **Правильно:**

```1c
СтрШаблон(
  НСтр("ru = 'N%1 от %2'"),
  ВОтветНаНомер,
  Формат(ВОтветНаДата, "ДЛФ=D"))
```

---

## 4. Сериализация для машиночитаемого формата

Когда требуется передача значения в машиночитаемом виде, вне зависимости от информационной системы и настроек локализации, вместо локализации значения следует выполнить **сериализацию**.

**Общая рекомендация:**
- Сериализация: **XMLСтрока**
- Десериализация: **XMLЗначение** или метод **ПривестиЗначение** объекта **ОписаниеТипов**

**Важно:** Локализацию дат нужно использовать всегда, когда это возможно. Отказываться от локализации допускается только когда технически нецелесообразно (например, при генерации XML-файла для банк-клиента, специфичного для России).

---

### 4.1. Сериализация дат

При разработке собственных форматов передачи данных рекомендуется сериализовать дату в формате ISO: `"ГГГГ-ММ-ДДTЧЧ:ММ:ССZ"`, например `"2009-02-15T00:00:00Z"` (соответствует типу dateTime схемы XML).

❌ **Неправильно:**

```1c
Строка = Формат(Дата, "ДФ=гггг-ММ-ддTЧЧ:мм:сс"); // Сериализация
```

✅ **Правильно:**

```1c
// Сериализация
Строка = XMLСтрока(Дата);
// Или
Строка = ЗаписатьДатуJSON(Дата, ФорматДатыJSON.ISO);

// Десериализация
Дата = XMLЗначение(Тип("Дата"), Строка);
// Или
Дата = ПрочитатьДатуJSON(Строка, ФорматДатыJSON.ISO);
// Или
ОписаниеТипа = Новый ОписаниеТипов("Дата");
Дата = ОписаниеТипа.ПривестиЗначение(Строка);
```

---

### 4.2. Сериализация числа

❌ **Неправильно:**

```1c
// Сериализация
Строка = Строка(Число);
// Или
Строка = Формат(Число);
```

✅ **Правильно:**

```1c
Строка = XMLСтрока(Число);    // Сериализация
Число = XMLЗначение(Тип("Число"), Строка); // Десериализация
```

---

### 4.3. Сериализация Булево

❌ **Неправильно:**

```1c
// Сериализация
Строка = Строка(Булево);
// Или
Строка = Формат(Булево);
// Или
Строка = Формат(Булево, "БЛ=off; БИ=on");
```

✅ **Правильно:**

```1c
// Сериализация
Строка = XMLСтрока(Булево);
// Или
Строка = ?(Булево, "on", "off");

// Десериализация
Булево = XMLЗначение(Тип("Булево"), Строка);
```

---

## Сводка

| Тип данных | Рекомендация |
|------------|--------------|
| Дата (интерфейс) | Локальный формат `ДЛФ`, при необходимости `ДФ` через `НСтр` |
| Дата (сериализация) | `XMLСтрока` или `ЗаписатьДатуJSON` в формате ISO |
| Число (интерфейс) | `НСтр` для `ЧН`, `ЧФ`, `ЧРД` |
| Число (сериализация) | `XMLСтрока` |
| Булево (интерфейс) | Всегда через `НСтр` |
| Булево (сериализация) | `XMLСтрока` или тернарный оператор |

| Правило | Описание |
|---------|----------|
| Локальный формат | Предпочтителен для дат в интерфейсе |
| Параметр «L=» | Не использовать |
| Форматные строки в метаданных | Подлежат локализации как синонимы |
| Сериализация | XMLСтрока/XMLЗначение или JSON-методы |
