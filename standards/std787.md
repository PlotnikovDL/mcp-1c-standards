# #std787 Вычисление количества записей в запросах

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Используйте КОЛИЧЕСТВО, а не СУММА

При вычислении количества записей **всегда** используйте функцию `КОЛИЧЕСТВО`, а не `СУММА`.

### Причина

При количестве записей **10 млн. и более** произойдёт переполнение — разрядность числа по умолчанию в СУБД составляет **7 разрядов**.

✅ **Правильно:**

```1c
КОЛИЧЕСТВО(*)
КОЛИЧЕСТВО(<Поле>)
```

❌ **Неправильно:**

```1c
СУММА(1)
ЕСТЬNULL(СУММА(1), 0)
```

---

## 2. Условный подсчёт с ВЫРАЗИТЬ

Если количество требуется вычислять **условно** и функцию `КОЛИЧЕСТВО` применить невозможно, расширьте разрядность числа с помощью `ВЫРАЗИТЬ` (например, до 17 разрядов).

✅ **Правильно:**

```1c
ВЫБРАТЬ
    КОЛИЧЕСТВО(*) КАК Количество,
    СУММА(ВЫБОР
        КОГДА Номенклатура.ЭтоГруппа
            ТОГДА ВЫРАЗИТЬ(1 КАК ЧИСЛО(17, 0))
        ИНАЧЕ 0
    КОНЕЦ) КАК КоличествоГрупп,
    СУММА(ВЫБОР
        КОГДА НЕ Номенклатура.ЭтоГруппа
            ТОГДА ВЫРАЗИТЬ(1 КАК ЧИСЛО(17, 0))
        ИНАЧЕ 0
    КОНЕЦ) КАК КоличествоЭлементов
ИЗ
    Справочник.Номенклатура КАК Номенклатура
```

❌ **Неправильно:**

```1c
ВЫБРАТЬ
    КОЛИЧЕСТВО(*) КАК Количество,
    СУММА(ВЫБОР
        КОГДА Номенклатура.ЭтоГруппа
            ТОГДА 1
        ИНАЧЕ 0
    КОНЕЦ) КАК КоличествоГрупп,
    СУММА(ВЫБОР
        КОГДА НЕ Номенклатура.ЭтоГруппа
            ТОГДА 1
        ИНАЧЕ 0
    КОНЕЦ) КАК КоличествоЭлементов
ИЗ
    Справочник.Номенклатура КАК Номенклатура
```

---

## 3. Сводка

| Задача | Решение |
|--------|---------|
| Подсчёт всех записей | `КОЛИЧЕСТВО(*)` |
| Подсчёт по полю | `КОЛИЧЕСТВО(<Поле>)` |
| Условный подсчёт | `СУММА(ВЫБОР ... ВЫРАЗИТЬ(1 КАК ЧИСЛО(17,0)) ...)` |
| ⛔ Запрещено | `СУММА(1)` — переполнение при 10+ млн записей |
