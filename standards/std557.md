# #std557 Работа с пользовательскими настройками

> Область применения: управляемое приложение, обычное приложение.

---

## 1. Хранение персональных настроек

### 1.1. Использование хранилища общих настроек

Для хранения персональных настроек пользователя следует использовать **ХранилищеОбщихНастроек**.

```1c
// Чтение настройки
ЗначениеНастройки = ХранилищеОбщихНастроек.Загрузить("НастройкиПрограммы", "ЗадаватьВопросПриВыходе");

// Запись настройки
ХранилищеОбщихНастроек.Сохранить("НастройкиПрограммы", "ЗадаватьВопросПриВыходе", ЗначениеНастройки);
```

⚠️ **Не использовать** для хранения настроек:
- Регистры сведений
- Реквизиты и табличные части справочников
- Внешние файлы
- Другие объекты метаданных

### 1.2. Права доступа

Для работы с пользовательскими настройками требуется право **СохранениеДанныхПользователя**.

### 1.3. Ключи настроек

Для обращения к каждой настройке используется **уникальный строковый ключ**.

| Пример | Описание |
|--------|----------|
| `"ОсновнаяОрганизация"` | Основная организация пользователя |
| `"ОсновнойСклад"` | Основной склад пользователя |

**Объединение настроек в структуру** допустимо, если все обращения к ним выполняются одновременно:

```1c
// Параметры прокси-сервера — одна структура
ПараметрыПрокси = Новый Структура;
ПараметрыПрокси.Вставить("Адрес", "proxy.example.com");
ПараметрыПрокси.Вставить("Порт", 8080);
ПараметрыПрокси.Вставить("Пользователь", "user");
ПараметрыПрокси.Вставить("Пароль", "***");

ХранилищеОбщихНастроек.Сохранить("Интернет", "ПараметрыПрокси", ПараметрыПрокси);
```

## 2. Редактирование настроек

### 2.1. Форма персональных настроек

В конфигурации должно быть **общее место** для редактирования всех пользовательских настроек — как правило, форма «Мои настройки» или «Персональные настройки».

### 2.2. Настройки в рабочих местах

Для удобства поля с отдельными настройками могут быть размещены **непосредственно в рабочих местах**:

**Пример:** Флажок «Больше не показывать подсказки при редактировании файла» — прямо на форме подсказки.

### 2.3. Контроль доступа

Форма персональных настроек и элементы для работы с настройками должны быть доступны только пользователям с правом **СохранениеДанныхПользователя**.

## 3. Особенности работы

### 3.1. Распределённые базы

Настройки **не мигрируют** между узлами информационной базы — они специфичны для определённого узла.

При необходимости передача настроек между узлами реализуется дополнительно средствами встроенного языка.

### 3.2. Переименование и удаление пользователей

Настройки сохраняются в разрезе **строкового имени пользователя**.

| Действие | Последствие | Рекомендация |
|----------|-------------|--------------|
| Переименование пользователя | Прежние настройки теряются | Переносить настройки |
| Удаление пользователя | Настройки остаются в хранилище | Очищать настройки |
| Создание пользователя с тем же именем | Используются настройки удалённого | Очищать настройки при удалении |

### 3.3. Обработка в БСП

При использовании **Библиотеки стандартных подсистем** доступны обработчики в модуле `ПользователиПереопределяемый`:

| Процедура | Назначение |
|-----------|------------|
| `ПриЗаписиПользователяИнформационнойБазы` | Перенос настроек при переименовании |
| `ПослеУдаленияПользователяИнформационнойБазы` | Удаление настроек |

## 4. Краткая справка по API

```1c
// Загрузка настройки
Значение = ХранилищеОбщихНастроек.Загрузить(КлючОбъекта, КлючНастройки);

// Сохранение настройки
ХранилищеОбщихНастроек.Сохранить(КлючОбъекта, КлючНастройки, Значение);

// Удаление настройки
ХранилищеОбщихНастроек.Удалить(КлючОбъекта, КлючНастройки, ИмяПользователя);

// Получение описания настроек
Описание = ХранилищеОбщихНастроек.ПолучитьОписание();
```
