# #std449 Получение представлений для ссылочных значений в табличном документе

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

> ℹ️ Методическая рекомендация (полезный совет)

---

## Общее правило

При формировании табличного документа **запрещено** в качестве параметров ячеек с типом заполнения **Параметр** указывать ссылочные значения, поскольку в этом случае в момент вывода данных будет выполнено **многократное обращение к базе данных** для получения представлений этих значений.

**Следует указывать сами представления**, а не ссылки.

---

## Исключения

### 1. Аналогичные многократные обращения

Исключением могут быть случаи, когда для получения представлений придётся выполнять аналогичное многократное обращение к базе данных.

### 2. Ограничения функции Представление() в запросе

При получении представлений непосредственно в запросе (через поле **Представление** или функцию `Представление(<Имя поля>)`) выполняется **неявное соединение** с таблицей объекта.

Для полей **составного типа** — несколько соединений, для каждого из типов, входящих в состав.

Это может приводить к:

- Увеличению времени выполнения запроса
- Невозможности выполнения в клиент-серверной версии из-за ограничения **Microsoft SQL Server** (не более 256 таблиц в запросе)

В таких случаях допускается получать представления в момент вывода в табличный документ.

---

## Выбор способа

Однозначно рекомендовать какой из способов получения представлений следует выбрать — нельзя. Такой выбор должен делаться разработчиком **самостоятельно**, на основании данных, полученных **экспериментально**.

---

## Сводка

| Способ | Плюсы | Минусы |
|--------|-------|--------|
| Представление в запросе | Один запрос | Неявные соединения, ограничение 256 таблиц |
| Ссылка в параметре ячейки | Простота кода | Многократные обращения к БД при выводе |
| Представление в параметре ячейки | ✅ Оптимально | Требует предварительного получения |
