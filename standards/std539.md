# #std539 Запуск регламентных заданий

> Область применения: управляемое приложение, обычное приложение.

> *Методическая рекомендация (полезный совет)*

---

## 1. Ручной запуск заданий

✅ Рекомендуется предоставлять пользователям **альтернативную возможность** по выполнению регламентных заданий вручную («по кнопке»).

### 1.1. Причины

- Выполнение заданий может быть **выключено** на кластере серверов
- В файловом режиме (ранее) отсутствовала возможность автоматического выполнения

---

## 2. Способы запуска в зависимости от типа задания

### 2.1. Задание изменяет данные для конкретного рабочего места

В форме рабочего места разместить:
- **Дату актуальности** представленных данных
- **Команду** для обновления/обработки

**Примеры:**

| Рабочее место | Информация | Команда |
|---------------|------------|---------|
| Поиск в данных | Дата актуальности индекса | «Обновить» |
| Список входящих писем | Когда принимались последний раз | «Получить почту» |
| Партионный учёт | Когда выполнялось распределение | «Выполнить» |

⚠️ Команда доступна только пользователям с необходимыми **правами**.

### 2.2. Задание влияет на всю ИБ или неизвестное число рабочих мест

Создать **отдельное рабочее место** для запуска таких заданий.

**Примеры:**
- Обновление и перестроение агрегатов
- Установка периода рассчитанных итогов

**БСП:** Форма «Регламентные и фоновые задания».

### 2.3. Задание не изменяет данные (отчёты, рассылки)

Также создать **отдельное рабочее место**.

**Примеры:**
- Рассылка информации об ошибках в журнале регистрации
- Рассылка информации о новых/просроченных задачах
- Периодический запуск внешних обработок для рассылки отчётов

---

## 3. Пример ручного запуска

```1c
&НаСервере
Процедура ЗапуститьРегламентноеЗадание()

    ИмяМетода = Метаданные.РегламентныеЗадания.ОчисткаУстаревшихВерсийОбъектов.ИмяМетода;

    // Проверка, выполняется ли фоновое задание
    Отбор = Новый Структура;
    Отбор.Вставить("ИмяМетода", ИмяМетода);
    Отбор.Вставить("Состояние", СостояниеФоновогоЗадания.Активно);

    ФоновыеЗаданияОчистки = ФоновыеЗадания.ПолучитьФоновыеЗадания(Отбор);

    Если ФоновыеЗаданияОчистки.Количество() = 0 Тогда
        НаименованиеФоновогоЗадания = СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(
            НСтр("ru = 'Запуск вручную: %1'"), РегламентноеЗаданиеМетаданные.Синоним);
        ФоновыеЗадания.Выполнить(ИмяМетода,,, НаименованиеФоновогоЗадания);
    КонецЕсли;

КонецПроцедуры
```

## 4. Блокировка при обновлении ИБ

### 4.1. Рекомендации

- **Файловый режим:** При неудачной попытке установки монопольного режима — предлагать блокировку заданий (ключ `/AllowExecuteScheduledJobs -Off`)
- **В обработчиках:** Проверять режим работы и прерывать задание исключением, если обновление не завершено

### 4.2. БСП

В начале обработчика вызывать:

```1c
ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания();
```
