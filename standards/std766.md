# #std766 Макеты: требования по локализации и поддержке разных языков интерфейса

> Область применения: управляемое приложение, мобильное приложение, обычное приложение.

---

## 1. Двоичные макеты и макеты с изображениями

Как правило, перевод табличных, текстовых и HTML-макетов на другие языки не требует подготовительных действий. **Особые случаи:**

- Двоичные макеты, подлежащие переводу
- HTML-макеты, содержащие изображения на разных языках
- Двоичные макеты печатных форм в форматах офисных документов
- HTML-макеты с инструкциями, включающие скриншоты интерфейса

### Постфикс кода языка

Такой макет необходимо пометить постфиксом в виде подчёркивания и кода языка: **«_ru»**.

❌ **Неправильно:**

```
ПФ_ODT_СчетНаОплату
```

✅ **Правильно:**

```
ПФ_ODT_СчетНаОплату_ru
```

### Получение макета в коде

❌ **Неправильно:**

```1c
... = ПолучитьОбщийМакет("ПФ_ODT_СчетНаОплату");
```

✅ **Правильно:**

```1c
... = ПолучитьОбщийМакет("ПФ_ODT_СчетНаОплату" + "_" + ТекущийЯзык());
```

### Алгоритм получения макета (три этапа)

Для исключения ошибок при частичном переводе конфигурации рекомендуется:

1. Сначала по `ИмяМакета + "_" + ТекущийЯзык()`
2. Если не найден — по `ИмяМакета + "_" + Метаданные.ОсновнойЯзык.КодЯзыка`
3. Если не найден — по переданному имени `ИмяМакета`
4. Установить свойство **КодЯзыка** (табличный документ) или **КодЯзыкаМакета** (текстовый/HTML)

## 2. Формирование печатных форм на заданном языке

При разработке конфигураций с несколькими языками интерфейса может возникнуть задача формировать печатные формы на разных языках в одном сеансе (например, счёт на русском в англоязычном сеансе).

Для получения данных из макета на заданном языке используйте:

| Тип макета | Свойство |
|------------|----------|
| Табличный документ | **КодЯзыка** |
| Текстовый документ | **КодЯзыкаМакета** |
| HTML-макет | **КодЯзыкаМакета** |

✅ **Правильно:**

```1c
Макет = ПолучитьОбщийМакет("ПечатнаяФорма");
Макет.КодЯзыкаМакета = "ru";
HTMLДокумент = Макет.ПолучитьДокументHTML();
```

---

## 3. Регламентированные формы (один язык)

Некоторые печатные формы должны формироваться **строго на одном языке** независимо от текущего языка интерфейса (например, счёт-фактура — налоговый документ установленного образца).

**Требования:**
- Указывать в имени постфикс кода языка
- Устанавливать код языка макета программно
- Такие макеты **не переводятся** на другие языки
- В функции **НСтр()** явно указывать второй параметр

❌ **Неправильно:**

```1c
Макет = ПолучитьМакет("ПФ_MXL_СчетФактура");
...
Область.Текст = НСтр("ru='Заголовок печати';");
```

✅ **Правильно:**

```1c
Макет = ПолучитьМакет("ПФ_MXL_СчетФактура_ru");
Макет.КодЯзыка = Метаданные.Языки.Русский.КодЯзыка;
...
Область.Текст = НСтр("ru='Заголовок печати';", Метаданные.Языки.Русский.КодЯзыка);
```

**При использовании БСП:** функция `УправлениеПечатью.МакетПечатнойФормы("ПФ_MXL_СчетФактура")` автоматически получает форму с постфиксом языка и устанавливает свойство **КодЯзыка**.

## 4. Именованные параметры подстановки

Если в текстах макетов используются именованные параметры подстановки, необходимо соблюдать требования по локализации интерфейсных текстов в коде.

---

## 5. Кодировка макетов

Кодировку в макетах использовать **UTF-8**.

> На скриншоте: макет «Сообщения_ru» с XML-содержимым `<?xml version="1.0" encoding="UTF-8"?>` и сообщениями на русском языке.

---

## 6. Группировка однотипных макетов

По возможности следует группировать однотипные макеты (использовать один макет вместо нескольких).

❌ **Неправильно** — отдельные макеты для каждого сообщения:

```1c
Макет = Обработки.ПереключениеРежимов.ПолучитьМакет("Сообщение");
```

✅ **Правильно** — один макет со всеми сообщениями:

```1c
Макет = Обработки.ПереключениеРежимов.ПолучитьМакет(
    СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку("Сообщения_%1",
    ОбщегоНазначения.КодОсновногоЯзыка()));
```

---

## 7. Внешние компоненты

Внешние компоненты следует размещать в макетах с типом **внешняя компонента**.

**Требования:**
- Обрабатывать метод **SetLocale** для локализации в соответствии с полученным кодом локализации
- Если полученный код локализации отличается от предусмотренного — настраивать окружение на использование **английского языка**

---

## Сводка

| Правило | Описание |
|---------|----------|
| Постфикс языка | `_ru`, `_en` и т.д. для двоичных и HTML-макетов с изображениями |
| Получение макета | Трёхэтапный алгоритм с fallback |
| КодЯзыка/КодЯзыкаМакета | Для формирования на заданном языке |
| Регламентированные формы | Постфикс + НСтр со вторым параметром |
| Кодировка | UTF-8 |
| Группировка | Объединять однотипные макеты |
| Внешние компоненты | Обрабатывать SetLocale |
